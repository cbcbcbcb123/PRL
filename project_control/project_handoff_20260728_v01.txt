====================
五、当前科学路线
====================

已原则同意的新候选路线：

Route H — 3D deformable-cell-model–ECM hybrid

当前生物学对象暂定为：

早期胚胎心室壁局部 patch，而不是成年心肌纤维化。

从血液侧到外侧依次为：

blood lumen
→ explicit endocardial DCM cells
→ deformable cardiac-jelly ECM mesh
→ explicit active myocardial DCM cells
→ compliant surrounding myocardium

SimuCell3D-style DCM 指每个细胞具有独立闭合三角曲面，不是传统 shared-vertex model。

====================
六、心内膜模型
====================

1. 心内膜建立为显式单层 DCM 细胞。
2. 血压 p 施加于心内膜顶面的法向。
3. 壁面剪切 τ_w 施加于心内膜顶面的切向。
4. 血流载荷不得直接施加到 ECM。
5. 心内膜通过细胞骨架、细胞连接和基底黏附向 ECM 传递力。
6. 心内膜同时产生流动感知变量 χ_E。
7. χ_E 可调节 KLF2、Notch、WNT9B、NRG1、fibronectin 和 ADAMTS 类过程。
8. 力学传递和生化机械转导必须分别记账，不能重复计算同一血流输入。

====================
七、ECM 模型
====================

1. ECM 是独立的有限变形网格，不与细胞共享顶点。
2. 保留：
   - ECM areal amount A；
   - remodeling/natural thickness H_ECM；
   - 黏弹内部变量；
   - turnover；
   - KKT 条件；
   - 完整功率 ledger。
3. A 与 H_ECM 不自动等同。
4. 只有明确假设有效密度恒定时，才允许：
   H_ECM = A / rho_ECM
5. 早期 cardiac jelly 的主要基质来源暂设为心肌基底面分泌。
6. 心内膜主要承担流动感知、特定 ECM 调节和降解控制。
7. 进入 cushion 或更晚发育阶段后，才引入 EndoMT 间充质细胞或心脏成纤维细胞。
8. 不得把成熟成纤维细胞设为早期 cardiac jelly 的唯一来源。

====================
八、心肌 DCM 模型
====================

心肌层也必须显式细胞化。

1. 早期胚胎心肌暂设为 1–2 层 DCM 心肌细胞。
2. 每个心肌细胞具有：
   - 独立闭合三角曲面；
   - 体积约束；
   - basal/lateral/opposite-surface identity；
   - 细胞—细胞接触与黏附；
   - 心肌—ECM 基底黏附；
   - 局部肌纤维方向 f_i；
   - 周期性主动激活 T_a,i(t)。

3. 禁止使用各向同性表面张力直接代表心肌收缩，因为它可能只造成细胞变圆或错误的法向挤压。

4. Stage 2 至少采用以下一种心肌主动机制：
   - 沿 f_i 的 anisotropic active preferred metric；
   - 沿 f_i 的 active preferred length；
   - anisotropic active tension T_a(t)。

5. 心肌来源 ECM 必须以细胞基底面通量 j_myo 映射到相邻 ECM 单元，不允许使用没有细胞归属的任意均匀源。

6. 初期只允许把该模型解释为细胞—ECM力路的无量纲机制模型，不得声称已经得到定量生理心肌本构。

7. 若表面 DCM 无法产生合理的纵向缩短、横向增厚和功率平衡，再另行审批心肌细胞内部有限应变模型或内部纤维网络。

====================
九、最低验证门禁
====================

正式 patch 计算前必须依次通过：

A. 单个心肌细胞
- 沿 f_i 缩短；
- 横向合理增厚；
- 体积误差受控；
- 无非物理刚体漂移。

B. 心肌细胞链
- 细胞连接处作用力与反作用力平衡；
- 激活波能够传递；
- 无重叠或非物理脱离。

C. Myocardium–ECM sandwich
- 心肌收缩首先产生切向 ECM 牵引；
- 法向响应来自接触、曲率和不可压缩效应；
- 不得人为加入虚假的法向 q。

D. Endocardium–ECM sandwich
- p 是法向载荷；
- τ_w 是切向载荷；
- 载荷通过心内膜传递；
- χ_E 与机械功分开记录。

E. 完整 patch
- 周边采用 compliant、periodic 或有限位移边界；
- 不采用无生物学依据的全固定边界；
- 坐标、法向和牵引符号一致；
- KKT、resultant 和 power ledger 闭合。
