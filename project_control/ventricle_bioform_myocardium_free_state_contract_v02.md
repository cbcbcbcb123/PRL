# Z1-BIOFORM-MYO-A｜心肌细胞内禀骨架自由态资格合同 v02

## 1. 问题与主张边界

检验一个无邻居、无 ECM、无腔压、无夹持的单心肌 DCM，能否从等体积近球形出发，仅依靠方向性细胞骨架主动应力与各向同性皮质/体积支撑形成稳定的长轴—横轴—厚度轴分离。

通过只表示合成粗粒化机制通过；不表示约 48 hpf 斑马鱼参数已标定、不表示组织形态形成、也不使父 Z1 通过。生物学验证在缺少同期同区域三维单细胞轴长数据时固定为 `blocked_data`。

## 2. 冻结机制

被动项采用项目受控 SimuCell3D 的体积压力、标量总面积弹性、各向同性皮质张力与弯曲。逐边/逐面参考形状及目标末态几何保持关闭：

```text
reference_edge_shape_terms = 0
reference_face_metric_terms = 0
target_geometry_used = false
```

骨架方向基为长轴 `p`、平面横轴 `q`、厚度轴 `r`，主动无迹张量为：

```text
Sigma_cyt = s * [1.00 p⊗p - 0.15 q⊗q - 0.85 r⊗r]
```

鉴于 SimuCell3D 表面没有面内细胞骨架剪切弹性，本阶段只保留张量在界面法向上的形状驱动分量，避免把参数化节点的切向漂移解释成细胞变形：

```text
t_f = n_f * (n_f · Sigma_cyt · n_f)
F_f = alpha(lambda) * A_f * t_f
```

面力均分给顶点后再次投影到面积加权顶点法向；随后只移除离散化造成的刚体净力和净力矩。该修正须将相对净力与净力矩压到 `1e-10` 以下并记录。`alpha` 是数值加载延拓，不是发育时间。

冻结参数由 `preregistration.json` 逐项记录：目标体积 `167.875410364543`，皮质张力 `0.160`，弯曲模量 `0.010`，总面积模量 `0.050`，体积模量 `30.0`，表面阻尼密度 `1.0`，加载坐标 `10`，保持坐标 `400`。这些是合成无量纲参数，不是实验拟合。

## 3. 动态重网格与保存状态

采用 SimuCell3D 原生局部重网格。请求面数 `80/320/1280` 定义初始分辨率，不要求末态节点或面数完全相同；要求每个保存状态均为闭合、流形、Euler 特征数 2 的球拓扑。边长带为初始名义边长的 `[0.45, 1.60]`，本阶段三角形质量分数阈值为 `0.55`，上游默认值仍为 `0.20`。

每条轨迹保存初始、加载 25/50/75/100% 和保持 25/50/75/100% 共 9 个真实求解器状态。每个状态分别保存节点与当时面连接。横轴仅称算法加载/松弛坐标。

## 4. 有界预检

只在请求 320 面、`dt=0.020` 上按顺序运行 `s={0.020,0.040,0.060}`。选择第一个同时满足：

- 末态 `E_pq >= 1.20`、`F_qr >= 1.15`；
- 最大体积误差 `<=0.02`；
- 9 个保存状态最小三角角 `>=15 deg`；
- 所有几何和场量有限。

若均失败即停止，不扩大扫描。选择是合成工程校准，不是实验拟合。

## 6. 验收门

共同数值门：所有 9 个状态有限、闭合流形且球拓扑；最大体积误差 `<=0.02`；保存状态最小三角角 `>=15 deg`；骨架相对净力/净力矩 `<=1e-10`；过阻尼力功—耗散相对残差 `<=1e-12`；主轨迹末态/历史峰值自由节点总力比 `<=0.05`。

机制门：主轨迹 `E_pq>=1.20`、`F_qr>=1.15`；消融末态两个比值均 `<=1.05`，且主轨迹相对消融增量分别 `>=0.15`、`>=0.10`；扰动末态两个比值与主轨迹相对差均 `<=0.05`；旋转轨迹两个比值相对差均 `<=0.02`，逆旋转后的对称 Chamfer RMS/等体积半径 `<=0.02`，主轴与旋转后 `p` 夹角 `<=5 deg`。

离散门：320→1280 面的两个形状比相对变化均 `<=0.05`；80 面只报告趋势。`dt=0.020`→`0.010` 的两个形状比相对变化均 `<=0.02`；`dt=0.040` 只报告趋势。

仅全部门通过时状态为 `passed_synthetic_mechanism`。任一共同数值门失败时，不裁决机制通过。
