# EFE 理论主线与逐 Node 计划 v01

## Goal

建立一个以斑马鱼疾病模型为未来验证对象的 EFE（endocardial fibroelastosis）机械化学理论：异常心搏与血流如何改变未成熟心内膜的机械环境，驱动纤维生成细胞状态与心内膜下胶原—弹性纤维沉积，并通过逐渐形成的高刚度边界层反过来限制心肌收缩、舒张与发育。

论文级目标不是“DCM–FEM 可以模拟 EFE”，而是检验以下候选物理命题：

> 活动心肌、含水心胶、心内膜和血流共同构成一个快—慢耦合系统；当细胞—ECM 机械反馈超过阈值时，正常可逆重塑可能转入自维持的心内膜下纤维弹性包裹状态。

“阈值”“双稳态”“机械记忆”和“自维持”均为待证明命题，在完成零流线、Jacobian、分岔、参数可识别性和盲预测前，只使用“候选状态跃迁”表述。

## Inputs

- 已有三维主动心肌 DCM、三维黏弹 ECM FEM、双向界面和能量—功率账本；
- 既有单周期、多周期和位移/主动加载探针仅作为开发基础，不自动成为 EFE 证据；
- 未来斑马鱼高速成像、细胞谱系、ECM 组成、血流和功能测量；
- EFE 细胞来源的竞争假说：心内膜 EndMT、既有间充质/心外膜来源细胞、两者混合；
- 冻结约束 `project_control/external_scientific_review_constraints_v01.md`。

## 统一尺度、变量与边界

### 快—慢时间

- 快时间 `t`：一个心搏周期 `T_beat`；
- 慢时间 `T`：细胞状态改变、ECM 沉积和发育；
- 时间尺度比 `epsilon_t=T_beat/tau_remodel << 1`。

每个慢时间步只求一个达到周期状态的代表性心搏，再用周期统计量推进慢变量。

### 三层与流体边界

`lumen / endocardial DCM / cardiac-jelly + fibrous ECM FEM / active myocardial DCM / surroundings`

- 心内膜顶端：规定腔压 `p(s,t)` 与壁面剪切 `tau_w(s,t)`；当前不宣称双向 FSI；
- 心内膜基底端：与 ECM 黏附、滑移、脱黏或迁入；
- ECM：正常含水心胶与病理胶原/弹性纤维混合物；
- 心肌：周期主动收缩并向 ECM 输入功。

### 慢变量

- `q_E(s,T)`：心内膜 EndMT/纤维生成状态；
- `q_M(s,T)`：既有间充质来源细胞的活化状态；
- `rho_c(s,T)`：胶原密度；
- `rho_e(s,T)`：弹性纤维密度；
- `A_c(s,T)`：胶原取向张量；
- `F_g(s,T)`：ECM 生长张量；
- `h_EFE(s,T)`：心内膜下病理层厚度。

## Node 0：EFE 最小理论合同

### 科学问题

最少需要哪些自由度、守恒关系和候选反馈，才能区分正常发育、可逆重塑与 EFE 样持续增厚？

### 工作内容

1. 冻结三层几何、法向、界面、正负号、快慢时间和功率端口；
2. 定义正常心胶与病理胶原/弹性纤维的混合能量；
3. 定义周期机械刺激向量：周期应变幅、周期平均应变能、腔压、WSS、OSI、相位差和界面牵引；
4. 写出 `q_E/q_M/rho_c/rho_e/A_c/F_g` 的最小候选演化方程；
5. 注册 EndMT、间充质来源和混合来源三个竞争变体；
6. 给出无反馈、无流、纯弹性、快速松弛、零沉积和零降解极限；
7. 做量纲检查、功率账本和可证伪性检查，不进行参数扫描。

### 阶段输出

- 一份可独立复核的理论合同和方程表；
- Figure 1：三层—血流—细胞状态—ECM 生长反馈示意；
- 一张“可观测量—模型变量—未来实验”映射表；
- Node 1 的预注册输入、输出和失败条件。

### Human Gate 0

只有在人类终审接受科学问题、变量数量、来源假说和证据边界后，才冻结方程并进入 Node 1。

## Node 1：最小三层单元的快速心搏力学

### 最小模型

一个主动心肌细胞或最小心肌 patch + 有限厚度三维 cardiac jelly FEM + 一个心内膜细胞或小型心内膜 patch。心肌基底侧加载 ECM，心内膜顶端承受规定的压力/剪切。

### 科学问题

在没有任何慢性 ECM 沉积时，心搏如何通过心胶向心内膜传递应变、压力、牵引和相位信息？哪些机械读数可能成为 EFE 的触发量？

### 工作包

- N1-A：先完成既有 X1-K 数值门；未通过前只允许解析和制造解，不进行论文级长耦合；
- N1-B：三层作用—反作用、能量、功率和力矩闭合；
- N1-C：心肌收缩幅值、周期、心胶厚度、黏弹时间和双界面连接扫描；
- N1-D：分别改变应变、压力和剪切，避免把“低血流”误写成单一低载荷；
- N1-E：比较单相黏弹、最小孔弹/双相或 HA 水化候选机制；
- N1-F：提取可传给慢模型的周期刺激向量 `M(s)`。

### 阶段输出

- Figure 2：三维变形、应力、牵引、相位和能量流；
- 快速传递函数或无量纲状态图；
- 一条可被 Node 2 使用的周期平均刺激定律，而不是参数表。

### 失败条件

- 结论依赖单一网格、时间步或边界；
- 单相黏弹与替代机制无法区分却宣称材料机制；
- 数值耗散被误当成生物学迟滞；
- 规定的压力/WSS 被表述为双向 FSI。

### Human Gate 1

接受、收窄或否决 `M(s)` 中的候选机械触发量，再决定 Node 2 的细胞状态方程。

## Node 2：局部 EFE 起始与候选状态跃迁

### 最小模型

使用 Node 1 的周期统计量驱动一个局部降阶系统，暂不进行空间大模型：

`dq_E/dT = f_E(M, TGF-beta, BMP, q_E)`

`dq_M/dT = f_M(M, TGF-beta, BMP, q_M)`

`d rho_c/dT = production_c(q_E,q_M) - degradation_c(rho_c)`

`d rho_e/dT = production_e(q_E,q_M) - degradation_e(rho_e)`

材料状态更新后重新求一个代表性心搏，从而闭合机械反馈。

### 科学问题

在什么条件下，短暂异常负荷只产生可逆重塑；在什么条件下，卸载后仍出现持续 ECM 增长？是否真的存在阈值、滞回或机械记忆？

### 工作包

- N2-A：零流线和无反馈基线；
- N2-B：定常点、nullcline、Jacobian 和局部稳定性；
- N2-C：单参数和双参数延续，搜索鞍结、Hopf 或无分岔的连续响应；
- N2-D：加载—卸载、短时—长时预处理和恢复试验；
- N2-E：EndMT、间充质来源和混合来源的可辨识性；
- N2-F：生成盲预测，不用同一数据同时定标和验证。

### 阶段输出

- Figure 3：nullcline、分岔图、加载—卸载轨迹和候选相图；
- “可逆—持续”边界或明确的无临界负结果；
- Node 3 的局部反应项和参数可识别性报告。

### Human Gate 2

只有在分岔和替代模型检查后，才能使用“双稳态”“机械记忆”或“状态跃迁”；否则论文主张降级为连续反馈和时间积分效应。

## Node 3：空间 EFE 边界层的形成与来源竞争

### 最小模型

扩展为有限心肌层—三维 ECM—心内膜细胞层。DCM 表示细胞形态、连接、迁移和离散病灶成核；FEM 表示连续 ECM 应力传播、胶原/弹性纤维混合、生长和取向。

### 科学问题

局部异常为什么会停止、形成斑块或扩展为弥漫性心内膜包裹？病变形态由机械长程耦合、细胞迁移还是 ECM 更新控制？

### 工作包

- N3-A：从均匀状态进行线性稳定性分析，判断是否存在有限波长不稳定；
- N3-B：比较 H1 EndMT、H2 间充质迁入、H3 混合来源；
- N3-C：加入胶原取向、弹性纤维沉积和各向异性生长；
- N3-D：建立病灶成核、扩展、停止、融合和弥漫包裹的状态图；
- N3-E：细胞数、网格、随机种子、组织尺寸和边界条件稳健性；
- N3-F：比较离散 DCM、点状 ABM 和纯连续细胞场，证明 DCM 自由度是否必要。

### 核心无量纲量

`Lambda_enc = E_EFE*h_EFE/(E_myo*h_myo)`：病理层与心肌层面内刚度比。

其余候选量包括机械反馈增益、沉积/降解比、迁移/重塑长度比、心搏 Deborah 数以及剪切—应变刺激比。符号在 Node 0 冻结后不得跨 Node 改义。

### 阶段输出

- Figure 4：三维 EFE 厚度、胶原取向、细胞来源和应力场；
- 局部、斑块和弥漫包裹状态图；
- `Lambda_enc` 与功能受限之间的候选阈值。

### Human Gate 3

确认空间新物理不能由局部 Node 2 简单叠加解释，并选择唯一进入斑马鱼模型的主来源机制或保留多来源竞争。

## Node 4：斑马鱼 EFE 疾病模型与功能预测

### 最小模型

将 Node 3 规律映射到固定发育阶段的斑马鱼心室或局部心室壁几何。第一版使用成像给定的心肌运动、腔压和血流/WSS；只有证据表明反馈不可忽略时才升级双向 FSI。

### 科学问题

EFE 样心内膜下边界层达到什么厚度、刚度和覆盖率后，会限制心肌缩短、舒张、腔体扩张或发育？模型能否在未拟合的个体、时相或干预中给出正确预测？

### 工作包

- N4-A：从 SPIM/OCT/自有成像重建心肌、心胶和心内膜几何；
- N4-B：确认 EFE 命名门——心内膜下定位、胶原与弹性纤维增加、非单纯水肿/心胶异常；
- N4-C：以部分个体/时相标定，以其余数据做盲预测；
- N4-D：比较 EndMT、间充质来源和混合来源的空间签名；
- N4-E：预测 TGF-beta/BMP、力学卸载、血流改变或 ECM 更新干预方向；
- N4-F：量化舒张顺应性、缩短率、相位、腔体体积和发育受限。

### 阶段输出

- Figure 5：斑马鱼模型与实验同坐标的三维场对照；
- Figure 6：未参与拟合的干预或个体盲预测；
- EFE 理论的适用范围、物种差异和失败边界。

### Human Gate 4

人类终审决定是否形成 Nature Physics 主论文、收窄为方法/生物物理论文，或进入实验补强。

## Risks

1. 斑马鱼表型可能不是严格意义的 EFE；此时降级为“EFE-like subendocardial fibrosis”，不得强行命名；
2. EndMT 与间充质来源可能不可由现有数据区分；保留竞争模型，不让力学模拟裁决谱系；
3. 单相黏弹心胶可能无法解释厚度和压力传播；需比较孔弹/双相或水化机制；
4. 候选反馈可能没有分岔；接受连续响应的负结果，不制造临界性；
5. X1-K 当前未通过；在通过前不得进入 ECM/血流长耦合、参数标定或论文级机制 claim；
6. 全 FSI 可能显著扩张工程范围；第一版只用规定压力/WSS。

## Acceptance Criteria

- 五个 Node 形成不可倒置的因果递进：快速力学 → 局部状态 → 空间生长 → 器官功能；
- 每个 Node 都有独立问题、反事实、失败条件、定量输出和人类门；
- Node 2–4 的慢变量来源于 Node 0 合同，并由 Node 1 的快速统计量驱动；
- 不把代码可运行、规定载荷或 EFE-like 几何直接升级为疾病机制证据；
- 最终至少有一个未参与拟合的斑马鱼个体、时相或干预预测。

## Out Of Scope

- 当前不做电生理、心律失常和全身循环；

- 当前不预设唯一细胞谱系来源；
- 当前不执行 Node 1–4 的批量计算或正式投稿图。
