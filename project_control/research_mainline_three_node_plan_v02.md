# 三节点单篇 Nature Physics 主论文研究计划 v02

## 1. 论文中心问题

一个主动收缩的离散细胞系统，如何通过具有有限松弛时间、有限厚度和近不可压缩性的 cardiac jelly，把细胞尺度的周期力转换为组织尺度的时空变形，并最终驱动另一侧心内膜的间距变化和折叠？

论文不是以“建立 DCM–FEM 软件”为中心，而是把 cardiac jelly 视为一种**具有频率选择、空间传递和内部记忆的主动软物质耦合层**。

## 2. 统一中心假说

Cardiac jelly 不是被动填充物，而是由时间尺度、长度尺度和界面约束共同控制的力学滤波层：

- 在细胞尺度，它控制主动功在弹性储能、黏性耗散和界面传力之间的分配；
- 在心肌层尺度，它控制相邻细胞牵引场的叠加、屏蔽、同步和空间相干；
- 在三层尺度，它把心肌层激活转换为心内膜位移、层间距重排及折叠/不折叠状态。

需要寻找的统一物理结果不是“参数变化会改变曲线”，而是：

1. 无量纲状态图；
2. 可跨细胞形态、尺寸和周期的数据坍缩；
3. 单细胞规律向细胞层和三层结构的可预测递进；
4. 能区别固体黏弹、孔弹/流体迁移和纯弹性机制的实验可证伪预测。

## 3. 统一变量、无量纲参数与账本

### 3.1 核心控制参数

| 符号 | 定义 | 物理意义 |
|---|---|---|
| `De=tau_j/T` | jelly 松弛时间/心搏周期 | 快速松弛、竞争区、近弹性极限 |
| `R_mu=mu_ve/mu_eq` | 黏弹支路/平衡支路 | 松弛幅度 |
| `Chi_mj=E_m/E_j` | 心肌/心胶刚度比 | 主动细胞相对介质柔顺性 |
| `Chi_ej=B_e/(mu_j L^3)` | 心内膜弯曲/心胶尺度 | Node 3 折叠竞争 |
| `H=h_j/L` | jelly 厚度/细胞或组织尺度 | 有限厚度与边界影响 |
| `AR=L/W` | 心肌细胞长宽比 | 形态与纤维方向性 |
| `Phi_c=A_contact/A_cell` | 接触面积比例 | 界面覆盖程度 |
| `S=k_t L/mu_j` | 切向连接/基质剪切 | 滑移—锁定竞争 |
| `C=kappa_j/mu_j` | 体积/剪切模量比 | 近不可压缩性 |
| `Lambda=lambda_a/xi_j` | 激活空间波长/传力长度 | Node 2 相干性竞争 |
| `Pi=p/(mu_j)` | 腔内压/心胶剪切尺度 | Node 3 可选压力对照 |

符号在具体几何建立后允许精炼，但不得在 Node 间改变物理含义。

### 3.2 统一观测量

- 细胞：轴向缩短、体积、横向膨胀、曲率、主动功；
- jelly：位移、`J`、应力/应变 p95、总储能、能量密度、内变量记忆、耗散；
- 界面：法向/切向牵引、总力、力矩、滑移、功率；
- 组织层：激活相干长度、牵引相关长度、空间方差、波传播速度；
- 心内膜：层间距 `h(s,t)`、曲率、压缩区、折叠幅度和相位。

### 3.3 统一能量—功率账本

每个 Node 均必须核对：

`W_active + W_pressure = Delta Psi_cell + Delta Psi_jelly + Delta Psi_interface + D_jelly + D_other + W_boundary + epsilon_numerical`

正式定量结果要求给出归一化闭合误差，并使迟滞环与耗散账本相容。仅有“耗散非负”不等于能量闭合。

## 4. Node 1：单细胞—黏弹性 cardiac jelly 物理内核

### 4.1 角色

Node 1 不是方法演示，而是整篇论文的最小物理单元。它必须回答：细胞形态、jelly 松弛、刚度、几何边界和界面条件如何共同决定传力、记忆和耗散？

### 4.2 工作包

#### N1-A 数值与热力学可信度

- ECM 网格至少三级；
- 时间步至少三级；
- 交错耦合容差至少三级；
- 严格主动功—储能—耗散—边界功闭合；
- 多周期至稳定极限环；
- 检查峰值、p95、积分量和周期波形；最大单元应力仅作诊断。

**通过条件：**主读数满足预注册收敛阈值；周期极限环与能量闭合通过。阈值在计算前单独冻结。

#### N1-B 细胞形态库

在等体积条件下建立至少三类形态：

- 低 `AR` 的近球/椭球；
- 中等 `AR` 的胚胎样圆钝形；
- 高 `AR` 的细长/纺锤形。

分别执行两套控制：

1. 等体积、接触比例允许随形态变化；
2. 等体积且固定绝对接触面积或 `Phi_c`。

形态变量至少包括 `AR`、厚度比、表面曲率和纤维方向。真实斑马鱼影像用于定义范围，不把成人 7:1 直接当胚胎基线。

#### N1-C jelly 参数与频率相图

- `De` 覆盖 `0`、`<<1`、`~1`、`>>1`；
- 扫描 `R_mu`、`Chi_mj`、`C`；
- 通过改变周期和材料松弛时间两条独立路径获得相同 `De`，检验数据坍缩；
- 提取几何恢复比、记忆保持比、耗散比例、传力效率和力—缩短环面积。

重点寻找：中间 `De` 的非单调耗散/传力最优区，以及“几何恢复但材料记忆保留”的状态区。

#### N1-D 几何和界面反事实

- jelly 厚度与外延面积；
- 单面、四面包围或受限包围；
- 无黏附、法向黏附+自由滑移、有限切向连接、近锁定；
- 远端固定、弹性支撑和扩大边界距离；
- 接触位置偏置，检查弯曲与力矩。

必须把本构效应与边界/tether 效应分开。

#### N1-E 竞争本构

至少比较：

- 纯弹性；
- 当前单松弛时间固体黏弹；
- 双时间尺度 Prony/广义 Maxwell；
- 最小孔弹或双相替代模型。

目的不是堆模型，而是找出哪些可观测量能区分机制；若当前数据不能区分，论文必须承认证据等价性。

#### N1-F 实验/影像验证

- 影像：固定 hpf 的细胞体积、`AR`、厚度和接触比例分布；
- 材料：jelly 的松弛、迟滞或 `G'、G''`；
- 体外最小验证：可调黏弹 HA/水凝胶上的形态控制心肌细胞或心肌样细胞，测缩短、基质位移、相位和牵引；
- 至少保留一个未参与标定的盲预测工况。

### 4.3 Node 1 阶段输出

- 一张数值/能量可信度图；
- 一张 `AR–De–Chi_mj` 中选取两个主轴的状态图，第三参数作分层或补充；
- 一张边界与竞争本构的反事实图；
- 一组可传递给 Node 2 的缩减规律，例如有效传力核、空间衰减长度和频率响应。

### 4.4 Node 1 人类门

只有同时满足以下条件才进入 Node 2：

1. 不依赖单一网格、时间步或单一形状；
2. 至少形成一条无量纲规律或数据坍缩；
3. 能量闭合与极限环通过；
4. 纯弹性和至少一种替代机制已比较；
5. 给出 Node 2 可直接检验的定量预测，而不是只输出参数表。

## 5. Node 2：心肌细胞层—共享黏弹性 cardiac jelly

### 5.1 角色

Node 2 必须展示新的集体物理：单细胞响应不能简单线性叠加。它回答心肌层的空间相干、异步激活和细胞—细胞连接如何通过共享 jelly 产生长程耦合、屏蔽或放大。

### 5.2 工作包

#### N2-A 组织构型与有限尺寸

- 建立一层具有明确邻接关系的 DCM 心肌细胞；
- 细胞数至少三级，检验有限尺寸和边缘效应；
- 比较周期/对称边界、自由边缘和局部 patch；
- 每个细胞保持独立体积和材料身份；jelly 是连续共享体，不按细胞切块。

#### N2-B 细胞—细胞连接

- 法向/切向连接刚度；
- 连接完整、局部缺失和异质连接；
- 检查层内力守恒、集体刚度和局部应力集中；
- 区分细胞—细胞传力与细胞—jelly 传力。

#### N2-C 激活相干性

- 完全同步；
- 传播波；
- 随机相位或局部失活；
- 改变激活波长、传播速度和 `De`，构建 `Lambda–De` 状态图。

关键读数：牵引相关长度、ECM 传力长度、细胞缩短方差、局部热点、周期耗散和输出功。

#### N2-D 从 Node 1 到 Node 2 的预测检验

- 使用 Node 1 提取的有效单细胞传力核预测稀疏/弱耦合层；
- 测量实际细胞层响应与线性叠加预测的偏差；
- 找出集体效应开始出现的细胞密度、连接强度或 `Lambda` 阈值；
- 形成“独立细胞—协同层—失同步层”的状态边界。

#### N2-E 组织异质性与稳健性

- 细胞形态、激活幅度、纤维方向和连接强度的受控异质性；
- 随机种子重复和统计区间；
- 几何/参数扰动后相图边界是否稳定。

#### N2-F 实验验证

- 形态控制的心肌细胞条带或单层；
- 同步与局部抑制/异步刺激；
- 基质位移或牵引场、激活传播、收缩相位的空间测量；
- 或使用斑马鱼活体心肌层影像提取相位场和细胞形变相关长度。

### 5.3 Node 2 人类门

进入 Node 3 前必须证明：

1. 存在不能由 Node 1 简单叠加解释的集体效应；
2. 该效应可由少数无量纲参数组织；
3. 细胞数、边界和异质性检查通过；
4. 得到可作为 Node 3 心肌侧边界/输入的组织级牵引场与相位场。

## 6. Node 3：心肌层—cardiac jelly—心内膜层

### 6.1 角色

Node 3 是整篇论文的在体结构落点，但不能只是把内膜“加上去”。它要证明 jelly 的频率和空间滤波如何决定心内膜的局部间距、弯曲、压缩和折叠。

### 6.2 工作包

#### N3-A 三层几何和双界面验证

- 心肌层、有限厚度 jelly、单层心内膜；
- 分别定义心肌—jelly与心内膜—jelly连接；
- 双界面作用—反作用、功率和力矩闭合；
- 曲率、层厚和细胞尺度来自固定发育阶段影像范围。

#### N3-B 心内膜力学

- 面内拉伸、细胞体积/面积策略和弯曲刚度；
- 细胞—细胞连接和边缘条件；
- 心内膜网格、细胞数和弯曲/折叠波长收敛；
- 先证明无主动心肌时不会产生伪折叠。

#### N3-C 三层状态图

主参数至少包括：

- `De`：jelly 时间滤波；
- `H`：jelly 厚度；
- `Chi_ej`：心内膜弯曲竞争；
- `S_mj、S_ej`：双界面滑移/锁定；
- `Lambda`：心肌层激活空间尺度。

输出状态：同步跟随、相位滞后、局部压缩、平滑弯曲、周期折叠和接触。

#### N3-D 压力和替代机制

- 无腔压基线；
- 规定的时变腔压作为反事实；
- 比较心肌主动驱动、腔压驱动和二者组合；
- 若孔弹性在 Node 1 无法排除，则在三层中比较其对间距相位和折叠恢复的预测。

#### N3-E 影像/实验验证

- 从高速 SPIM/OCT 或自有影像提取 `h(s,t)`、心肌/心内膜相位、曲率和折叠位置；
- 用部分数据标定，其余心相或个体作盲验证；
- 至少一个扰动：降低收缩、改变 HA/jelly、改变界面连接或压力；
- 模型必须预先给出效应方向和相位预测。

### 6.3 Node 3 人类门

Node 3 通过必须同时满足：

1. 三层结果可追溯到 Node 1 的材料时间尺度和 Node 2 的组织牵引场；
2. 折叠/间距不是网格、边界或压力选择造成的伪影；
3. 至少一个未用于拟合的影像或实验扰动得到正确预测；
4. 明确区分固体黏弹、孔弹和纯弹性解释的证据边界。

## 8. 执行顺序与计算策略

### Phase A — Node 1 加固

1. 先修正动态能量账本和求解效率；
2. 冻结网格/时间步/耦合收敛合同；
3. 运行纯弹性、`De` 极限和多周期基准；
4. 建立细胞形态库；
5. 执行主相图与边界反事实；
6. 比较竞争本构；
7. 形成 Node 1 缩减传力核和 Node 2 预测。

### Phase B — Node 2 集体层

仅在 Node 1 人类门通过后执行。先小细胞数验证，再做有限尺寸、相干性和异质性，不直接启动大规模全参数扫描。

### Phase C — Node 3 三层结构

仅在 Node 2 人类门通过后执行。先无压力三层基线，再加压力和机制竞争。

### Phase D — 验证与稿件收束

统一参数估计、盲预测、Figure 1–5 的逐图人类门、全稿证据审查和投稿定位复核。

## 9. 全局失败条件

出现以下任一情况时必须收窄或改变主张：

- 相图依赖网格、边界或任意参数选择；
- 固体黏弹与孔弹预测无法区分，却宣称确定机制；
- Node 2 可由 Node 1 线性叠加完全解释，没有集体新物理；
- Node 3 折叠只由预设压力或边界直接强迫；
- 无量纲规律不能跨形态、尺寸或周期复现；
- 实验/影像扰动方向与模型盲预测不符；
- 只能证明代码可运行，不能形成普适物理结论。
