# EFE Node 1 N1-1A ECM footprint acceptance

人类终审接受 N1-1A ECM 横向足迹审计及阶段审阅图。

## Accepted disposition

1. `F100`（1.0×）保留为窄域边界对照，不再作为生产几何；
2. `F150`（1.5×）冻结为后续全局响应与周期计算的生产候选；
3. `F200`（2.0×）冻结为最终局部位移、应力与牵引热点的复核尺度；
4. ECM 厚度保持 `0.30`，不得在同一足迹审计中混入厚度效应；
5. N1-1A 计算证据与阶段图通过 Human Gate。

## Authorization boundary

本接受决定不自动授权 N1-2、周期稳态、16/32/64 时间收敛、正式 D1/E1
空间收敛、材料参数筛选、Node 2、实验拟合或双向 FSI。上述工作需要新的
明确授权。
