# 斑马鱼心脏公开实验数据分工图 v01

## 结论

目前没有发现一个公开数据集能在同一条鱼、同一发育阶段和同一坐标系中，同时给出逐细胞三维形态、完整心室周期运动和血流。项目因此采用三个相互独立的实验验证轴，不把不同实验静默拼接成一条“真实轨迹”。

| 验证轴 | 首选公开来源 | 可支持的问题 | 不能支持的问题 | 当前状态 |
|---|---|---|---|---|
| 静态心肌细胞形态与长轴有序度 | Eckert 等，Zenodo `15509350`，72/120 hpf | 膜信号、外层致密心肌表面、物理尺度、表面方向和局部有序度；可作为重新分割入口 | 跳动周期、压力、材料参数、逐细胞实例标签 | 完整主包及72 hpf Fish 4资格均通过；限定为可重新分割 |
| 心室壁动态运动 | Ding 等，Figshare `14813628`，3 dpf | 配准后的 184 状态心肌体数据、心室运动和后续位移场提取 | 与上项为同鱼或同坐标；直接给出材料本构 | 已登记，尚未下载；须在静态形态门后另立合同 |
| 轻量活体周期成像 | Zenodo `5006918`，约 48 hpf | 100 帧 LifeAct-RFP 心脏序列，可用于周期和图像处理流程预检 | 三维逐细胞形态、完整壁厚、压力或血流 | 原包已下载并通过哈希和归档安全检查；尚未用于定量 |
| 血流与红细胞运动 | Zenodo `15033866` | 100 时间步红细胞/流动重建，可用于未来流固耦合外部验证 | 心肌壁位移和细胞形态 | 仅登记，尚未下载 |

## 当前主数据门

F1-R 冻结在 72 hpf 外层致密心肌。Zenodo `15509350` 的论文报告 `Tg(myl7:BFP-CAAX); Tg(-0.2myl7:Lifeact-mNeongreen)`，膜通道用于细胞边界，LifeAct 用于 F-actin；每个发育阶段报告 5 个心脏。成像在麻醉使心脏停止后进行，因此这是一套静态形态数据，不是跳动数据。

数据包目前提供膜强度、组织区域 mask、表面采样点、表面法向、方向和局部 nematic order，但未发现逐细胞实例标签。只要 72 hpf 个体同时通过来源、通道、尺度、格式和边界信号检查，本门可记为“真实数据可重新分割”；不得写成“已取得真实逐细胞网格”。

## 元数据冲突与限制

- 论文描述第二通道为 LifeAct-mNeonGreen；示例 TIFF 的系列名却含 `H2B-mNG`。在作者或原始元数据进一步澄清前，项目将该通道记为 `Marker_X / biological identity unresolved`，不把它静默改名为 F-actin。
- `Mask_Boundary.tif` 是组织区域/背景排除 mask，不是细胞边界实例图。
- 72、120 hpf、48 hpf 和 3 dpf 数据来自不同实验、品系或成像流程；它们只能分别约束形态、运动或流动，不能联合当作同一动物的时序。
- 公开数据资格通过不等于分割、FEM 映射、材料标定、DCM 比较或生物学验证通过。

## 推荐执行次序

1. 完成 72 hpf 原包哈希和归档安全检查，生成真实结构预览并裁决 F1-R。
2. 另立逐细胞分割资格合同：人工抽检边界闭合、尺度、面积/长宽比、方向、邻接和跨样本稳定性。
3. 冻结 `measured / uniform-mean / shuffled` 三组形态—方向映射，再进入 FEM 敏感性分析。
4. 静态形态链通过后，单独获取 3 dpf 动态壁数据并建立运动学验证合同。
5. 只有壁运动和载荷定义均具备后，才讨论材料反演、组织生长、ECM 反馈或流固耦合。
