# 二维椭圆三层主动 FEM 首次可行性执行记录 v01

## 裁决

F0 的**工程可行性为 `passed`**。一次正式单线程 CPU 调用完成 G0/G1 两级网格、每级 41 个规定激活相位；全部预注册数值门和独立重算门通过。斑马鱼几何/材料标定、生物学验证、流固耦合及 DCM—FEM 优势比较均为 `not_run`。

本结果不取代 DCM 主线，也不改变规则 2×2 DCM 静力失败的既有裁决。它只证明当前仓库已经有一条不依赖退役 FEM 源码、可独立装配和复核的小型 FEM 基线。

## 实际模型

- 二维平面应变、三层共形椭圆环；由内向外为心内膜、薄 ECM 和心肌。
- 仅心肌施加局部椭圆切向主动本征应变，峰值 0.03；41 个相位是准静态规定相位，不是生理时间。
- 内外表面无牵引、无腔压；三个 KKT 条件只移除刚体 x/y 平移和转动。
- 所有长度、材料和场量均为无量纲合成量。现有 GFP 栈因尺度、配准和心室分割未冻结，没有参与拟合。

## 科学含义与下一步

本试验说明：连续体 FEM 很适合稳定计算整体壁层变形、层间传力和应力/压力/曲率场；但当前均匀连续体没有离散细胞、细胞间接触或形态随机性，不能检验“不规则单细胞形态的作用”，也不能据此声称比 DCM 更符合斑马鱼心脏。

唯一下一步应是 F1 实验数据资格，而不是继续调合成材料参数：先冻结发育阶段、尺度、心室壁/腔分割、周期配准和可留出的形变观测；之后再建立有限变形、真实几何与明确腔压/外载的 FEM 合同。DCM 与 FEM 只有在共同几何、加载和评价指标下才可比较。
