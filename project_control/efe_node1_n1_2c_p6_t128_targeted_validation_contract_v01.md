# EFE Node 1 N1-2c P6：T128 定向时间验证合同 v01

## 结论与目的

P6 不是用新规则“挽救”P5。P5 已作为严格预登记总门失败的正式历史证据冻结。
P6 是一个前瞻性、增量验证：在完全固定 D0/E0/F150 模型与空间离散的条件下，
增加 T128，回答两个仍未关闭的问题：

1. ECM 黏弹能和 ECM `||Z||` 的峰值相位，在 `dt=1/128 T` 下能否满足
   `<=0.01T` 的离散稳定门；
2. phase 1 三层位移是否满足物理闭合，而不再用两个趋零残差互相归一化。

如果 P6 全部通过，只能声称“固定 D0/E0/F150 基线在 T64→T128 比较下通过时间
离散门”。它不证明空间收敛、参数有效性、EFE 机制、实验一致性或 DCM–FEM 的
必要性。

## 为什么选择 T128

T64 的时间步长为 `0.015625T`，本身大于峰值相位硬门 `0.01T`。对当前冻结的
分段线性时序，峰值通常落在原生时间结点；因此 T64 不能充分解析一个小于自身
步长的相位门。T128 的步长为 `0.0078125T`，首次小于该门，并且不改变模型物理
或空间网格，是最小的定向验证级别。

本合同不自动延伸至 T256。即使 T128 未通过，也必须停在 Human Gate，由人类
终审决定是接受“相位不可辨识/边界敏感”的结论，还是另立合同。

## 冻结输入与唯一允许变量

### 冻结科学输入

- 几何：D0 心肌、E0 ECM、F150 横向 footprint；
- 周期：`T=1`，峰值激活 `0.20`，同一解析余弦波形及相位原点；
- ECM：`mu_ve=0.5`、`eta_ve=0.5`、同一有限应变 SLS 更新；
- 心肌与心内膜：同一面积、弯曲、主动纤维和精确体积约束；
- 界面与支承：同一双界面 tether/contact、周围支承和材料参数；
- 求解器：同一 Picard、KKT、coupling、体积、`min J`、gap 和面质量门；
- 空间离散、物质映射、输出 schema、后处理本构与 P5 完全相同。

唯一允许改变的独立变量是 `steps_per_cycle: 64 -> 128`。

### 冻结数值输入

- 暖启动源：已接受的 T64 transaction engine `cycle_02`；
- 比较级别：T32、T64、T128；T16 只保留为历史背景，不控制 P6 通过判定；
- T128 正式证据必须来自 128 相位步的两个全新事务周期，共 256 个独立通过的
  step transaction；不得把重采样状态计作 T128 求解证据；
- 所有输入脚本、检查点、CSV、NPZ 与 summary 在执行前后记录 SHA-256。

## 前瞻性裁决规则

### 1. 周期内稳定门

T128 cycle 2 相对 cycle 1 必须同时满足现有五条周期门：四条波形和周期末完整
ECM `Z` 均 `<=1e-3`。任一不通过即停止，不追加第三周期。

### 2. T64→T128 全局时间门

沿用 P5 的同名读数和相对差定义：

| 类别 | 门限 |
|---|---:|
| 七条周期波形的密集重采样相对 `L2` 差 | `<=2%` |
| 周期积分 | `<=2%` |
| 峰值幅度 | `<=2%` |
| ECM 周期耗散 | `<=5%` |
| 峰值相位 | `<=0.01T` |

峰值相位使用 4097 点密集线性重采样，并预先规定：

- 相位规范化到 `[0,1)`，`phase=1` 记为 `0`；
- 两相位距离为周期圆距离
  `d(phi_a,phi_b)=min(|phi_a-phi_b|, 1-|phi_a-phi_b|)`；
- 若多个采样点达到同一机器精度内的最大值，选择 `[0,1)` 中最早相位，并将该
  项标记为 `plateau_or_boundary_sensitive`；
- 平台或边界敏感标记不得被解释为精确生物学相位。

P6 的首要定向终点是 ECM 黏弹能和 ECM `||Z||` 两项的 T64→T128 峰值相位差
均 `<=0.01T`；其余全局读数仍须全部通过，防止只修复目标项而损害主解。

### 3. 三维场门

- 在共同物理相位 `0, 0.25, 0.5, 0.75, 1` 比较与 P5 相同的三层位移、ECM
  `J`、主应变、Cauchy 应力、平衡/黏弹能量密度、耗散密度、内部变量 `Z` 和
  两界面牵引；
- 除 phase 1 三层位移外，T64→T128 的场摘要相对差均须 `<=5%`；
- phase 1 三层位移不再进入跨级“趋零量除以趋零量”的相对场门，而由下述独立
  物理闭合门管理；
- 这是一条 P6 前瞻性规则，不改变 P5 已冻结的六条失败记录。

### 4. phase 1 位移物理闭合门

对每个时间级、每一层定义：

`C_layer = p95(||u(1)-u(0)||) / max_t p95(||u(t)-u(0)||)`。

分母下限固定为 `1e-12`；若整周期位移幅值低于该下限，则标记
`closure_not_identifiable`，不得自动判为通过。T64 和 T128 各层必须满足
`C_layer <=1e-3`。同时报告绝对闭合残差及 T32→T64→T128 趋势；单调下降是
支持性证据，但不是为避免舍入噪声而设的额外硬门。

### 5. 安全与求解完整性门

每个 T128 step transaction 必须通过现有门：

- KKT `<=1e-5`，raw coupling `<=1e-4`；
- 体积残差 `<=1e-8`；
- `min J>=0.5`，`min gap>=-1e-12`，最小面面积比 `>=0.05`；
- 唯一事务 PID、排他输出、完整 checkpoint digest 和无缺步序列；
- 若 step 15 或其他任一步失败，立即 fail closed，不以部分周期作科学裁决。

## 执行阶段与停止点

### P0 — T128 入口与回归测试

1. 扩展时间级校验，使 `128` 成为显式允许值；
2. 新建 T128 暖启动与事务周期 wrapper，不改写已冻结的 T64 wrapper；
3. 新增 64→128 重采样、129 相位记录、256 事务计数、排他输出和门限回归测试；
4. 执行相关测试、完整 hybrid 测试和 Ruff；若失败，停在 P0 修复门，不启动长算。

### P1 — T64→T128 审计暖启动

从已接受 T64 cycle 2 构造 129 相位的审计暖启动。暖启动只提供初值，必须保存
源/目标摘要、状态 digest、相位端点闭合和输入指纹。

### P2 — 两个 T128 事务周期

沿用现有 CPU FEniCSx/PETSc 容器执行两个完整周期，共 256 个新事务。不得改用
GPU、FEBio 或其他外部求解器，不追加第三周期。

### P3 — T32/T64/T128 裁决与 Figure 2 v02

1. 按本合同计算 T64→T128 全局、场、闭合、安全和周期内稳定门；
2. 用 T32/T64/T128 估计受保护的观察阶与 Richardson 极限；不满足单调、非近零
   或合理阶范围的项明确标为不可辨识或非单调；
3. 生成新的 Figure 2 v02 数值版本，展示 P5 历史失败、T128 新证据和裁决变化；
4. 图包先标记 `VALIDATED_WORKING_PENDING_USER_CONFIRMATION`，不得自动替代已冻结
   的 Figure 2 v01；
5. 停在 N1-2c T128 Human Gate，等待人类终审。

## 资源预算

已测 T64 两周期共 128 个事务，墙钟时间约 `6112.95 s = 1.70 h`，结果约
`133 MiB`；暖启动约 `5.7 MiB`。据线性事务数估算：

- T128 两周期 256 个事务，中心估计约 `3.4 h`；
- 预留运行窗口 `3–7 h`，以容纳容器与单步波动；
- 新结果预留 `0.3–0.5 GiB`；
- 使用现有 CPU 容器 `dolfinx/dolfinx:v0.11.0`，不启动 GPU worker。

若执行前 CPU 容器、磁盘或源指纹检查不通过，则停止并报告，不修改门限换取运行。

## 可能结果与允许表述

### 全部通过

可在 Human Gate 接受后表述：固定 D0/E0/F150 健康基线的主要全局、场、黏弹
记忆和物理闭合读数在 T64→T128 比较下通过预登记时间门；后续生产步长可另由
精度—成本原则选择。不得外推为空间收敛或 EFE 机制验证。

### 主要读数通过但相位仍失败或不可辨识

保持 N1-2c 严格总门未通过；可报告幅值/波形稳定与峰值相位的边界敏感性或不可
辨识性。不得自动进入 T256。

### 周期、安全或主读数失败

判定 T128 未形成可接受共同极限证据，保留完整负结果并停在 Human Gate；不得
通过追加周期、改门或换求解器绕过。
