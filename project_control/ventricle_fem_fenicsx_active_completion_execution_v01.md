# F6-S0完成：FEniCSx压力与心肌主动张力

加入腔压使腔面积响应增加8.871537个百分点。二者体现压力扩张与主动缩腔的竞争。
组合工况相对零载仍是扩张，因为此处规定的压力效应大于主动缩腔效应；它没有被标成净收缩。

82项汇总门全部passed；每态还复核F/J/总应力/主动应力、自由力、弱压力、规范反力和虚功。
主动虚功差分最大误差1.66e-14，独立主动能量与生产保存值最大差3.36e-17。
