# Z1-TF 三层组织静态成形试验合同 v01

## 问题和裁决范围

检验在不使用参考态膜能时，固定邻接的有限三层组织能否由细胞骨架等效承载、可变形 ECM、腔面压力和两端夹持共同形成方向正确的心肌与心内膜形态。

本试验是合成静态筛查。通过只说明该离散结构具有稳定、可复核的成形方向；不说明比例、压力或材料已经生理标定，也不构成完整 Z4。

## 模型

- 两个 `4×4` 闭合 DCM 细胞层，均由球形网格起步；中间为 `5×5` 可变形 ECM 网格。
- 细胞被动项包括体积、全局面积、恒表面张力和弯曲；`reference_shape_modulus` 必须精确为零，且不得调用参考几何捕获。
- 心肌细胞加入少量长轴极化的内部骨架弹性构件；这些构件有明确端点、参考长度和能量账本，不等同于把全部膜边锁定为某个外形。
- 相邻同层细胞使用固定的分布式黏附连接，并启用当前面接触作为排斥筛查。跨 ECM 的细胞直接接触关闭。
- ECM 网格使用面内边/对角弹簧和离散弯曲项；心肌顶面与心内膜基底面以分布式黏附连接耦合到 ECM。
- 心内膜腔面按当前表面法向施加均匀外压牵引；组织两端使用有限节点区夹持。
- 所有参数均为合成筛查值，并在预登记中按 SI 单位和无量纲比登记。

## 路径和对照

连接和载荷从零连续升至冻结目标后松弛；保存 `0, 0.25, 0.50, 0.75, 1.00` 五个载荷分数的实际状态。该分数是算法延拓坐标，不是物理时间。

运行四个条件：

1. `FULL`：骨架、ECM 黏附支撑、邻接和腔面载荷全部启用；
2. `NO_LUMEN`：腔面载荷为零；
3. `NO_ECM_ATTACH`：细胞—ECM 黏附支撑为零；
4. `NO_CYTOSKELETON`：心肌极化骨架为零。

除被消融项外，其余输入、初始网格、随机种子和边界完全相同。

## 冻结筛查门

- 所有细胞参考态膜模量和已捕获参考边数均为零；
- 全程无非有限值、开边、非流形边和翻面；最终最小三角形角 `>=15 deg`；
- 最终每个细胞相对目标体积误差 `<=5%`；
- `FULL` 中央四个心内膜细胞的中位面内尺度/厚度相对初始值至少增加 `50%`；
- `FULL` 中央四个心肌细胞的中位长轴/横向尺度相对初始值至少增加 `10%`；
- `FULL` 的心内膜扁平化增量必须大于 `NO_LUMEN` 或 `NO_ECM_ATTACH` 中至少一个对照；
- `FULL` 的心肌长轴化增量必须大于 `NO_CYTOSKELETON`；
- 自由节点末态最大合力相对本条件峰值降至 `<=5%`；若显式松弛在预算内未达到，记为 `unknown` 或 `failed`，不得只凭图像通过。

接触路径的网格收敛尚未在非仿射组织形态中认证，因此即使上述筛查门全部通过，状态最高为 `passed_screening`，不升级为接触本构或组织材料验证。

## 资源、输出和停止

- CPU 最多 4 线程，墙钟上限 1200 s；不使用 GPU、不安装软件、不联网、不提交推送、不删除旧结果。
- PRL 中保存合同、运行器、验证器和 create-only 结果；本门不修改唯一 `E:\MeshCell3D\code\muse_dcm` 内核。
- 输出预登记、参数、迭代指标、细胞级指标、实际网格快照、模型结构图、形态演化图、定量对照图、曲率/节点力/压力图、独立复核、报告和离线 HTML。
- 任一条件出现翻面、非有限值或体积失控即冻结失败状态并停止该条件。完成本门后停止，不自动进入主动周期、完整 Z3/Z4、CFD 或 FSI。
