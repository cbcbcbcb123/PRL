# F6-S0｜FEniCSx 圆环压力—主动应力资格合同

## 目标与门禁

F6-S0 只验证开源 FEniCSx 后端能否在理想圆环上正确处理近不可压有限变形、闭合随动腔压和
局部心肌纤维主动应力。它不能推翻或修复 F5，也不是斑马鱼真实心室或实验拟合。

按顺序执行三个门：

1. `G0 runtime`：只核验本机已有 FEniCSx 镜像、版本、资源、JIT 和微型装配；
2. `G1 passive`：圆环两网格被动压力解析、平衡、局部体积和网格门；
3. `G2 active`：只有 G1 全部通过才运行压力×主动应力四工况。

G0 或 G1 失败即保全并停止，不能通过改参数、放宽门或直接加入主动张力取得通过。

## 运行时

只允许本机已存在的 `dolfinx/dolfinx:v0.11.0`，`--pull=never`、CPU 1、内存 8 GiB、
禁网、只读根、只读项目挂载、0 GPU、0 Docker socket。运行前实查 image ID，不以历史值
代替。FFCx 使用独立 512 MiB、`rw,exec,nosuid,nodev` 的 `/root/.cache` tmpfs；`/tmp`
使用 256 MiB、`rw,noexec,nosuid` tmpfs。保留退出容器用于审计，不使用 `--rm`。

宿主 Python 不安装 DOLFINx/PETSc/Gmsh。若镜像不存在、版本漂移、Docker 不可用或资源门失败，
状态为 `blocked`，0 科学求解。

## 几何、区域与网格

二维单位轴向厚度的平面应变圆环：

`A=20/27, R1=21/27, R2=22/27, B=1`。

- `A<=R<R1`：心内膜标签；
- `R1<=R<R2`：ECM 标签；
- `R2<=R<=B`：心肌标签。

三层比例沿用 F5 仅为可比数值基准，不是实测解剖。采用共形连续 Taylor--Hood 三角形：
位移 `[CG2]^2`、混合压力 `CG1`。网格为确定性同心环、交替对角剖分：

| 网格 | 周向区间 | 三层径向区间 | 三角形数 |
|---|---:|---:|---:|
| M0 | 64 | 1/1/5 | 896 |
| M1 | 128 | 2/2/10 | 3584 |

两级是仿射直边三角形，不把多边形边界称为精确圆弧。体积分和边界积分均至少六阶。

## 被动与主动方程

二维位移嵌入三维平面应变，`F33=1`、其余面外剪切为零，`J=det(F)`，
`Cbar=J^(-2/3) F^T F`。全层暂用同一未标定材料 `mu=1, kappa=1000`：

`Psi_pass = mu/2 (tr(Cbar)-3) + p_m (J-1) - p_m^2/(2 kappa)`。

`p_m` 是混合体积应力未知量，不是给定腔压。压力弱式对应
`integral q (J-1-p_m/kappa) dA = 0`。

参考环向纤维为 `f0=(-Y/R, X/R, 0)`。只在心肌标签加入

`Psi_act = chi_myo Ta/2 (f0.C.f0-1)`，

等价主动一阶 Piola 项为

`P_act = chi_myo Ta (F f0) tensor f0`。

这是规定激活下的方向性内部张力，不是节点力、规定缩短或生物化学储能。闭合腔压通过当前
腔面积势 `Pi_p=-p_cav A_cav(u)` 形成随动残量和一致切线；独立验证仍核对
`delta W_p=p_cav delta A_cav`。

## 边界条件与工况

内壁受当前构形腔压，外壁零牵引；无端盖、弹簧、ECM外支撑或实验夹持。外壁点
`(B,0)` 固定 `ux,uy`，点 `(-B,0)` 只固定 `uy`、`ux` 自由。这三个 DOF 只去除二维
刚体模态，其规范反力必须近零。没有独立 `uz` 自由度。

G1 两网格计算 `p_cav/mu=[0,.02,.04,.06,.08]`、`Ta=0`。

G2 冻结 `p*=.04 mu`、`T*=.10 mu`，终态为：

| 工况 | 腔压 | 心肌主动张力 |
|---|---:|---:|
| P0A0 | 0 | 0 |
| P1A0 | p* | 0 |
| P0A1 | 0 | T* |
| P1A1 | p* | T* |

P0A1 与 P1A1 使用 `lambda=[0,.25,.5,.75,1]` 延拓；P1A1 同步增加压力和主动张力。
`lambda=0` 共用 P0A0，P1A0复用G1的`.04`态，不重复求解。两网格最多26个唯一平衡态。
这些是算法载荷状态，不是生理时间。

## 冻结资格门

- 参考单元面积全正、标签和边完整；M0/M1圆面积误差分别 `<=0.2%/0.05%`，最小角 `>=20 deg`；
- PETSc SNES正收敛，最多30次Newton更新，不自动换求解器或重跑；
- 归一自由残量 `<=1e-9`，独立自由力 `<=2e-6`，压力弱残量 `<=1e-8`；
- 所有求积点 `J>0`，所有非零载荷态最大局部 `|J-1|<=0.01`；
- 保存 `F/J` 与独立重算误差 `<=1e-10`，应力误差 `<=2e-7`；
- 压力项、主动项和总 Jacobian 方向差分相对误差分别 `<=2e-6/2e-6/2e-5`；
- 闭合压力合力/力矩和三个规范反力归一值均 `<=2e-6`；
- G1用不可压NH厚壁圆柱解析关系独立求根；M1/M0各正压腔面积响应相对解析误差
  `<=1%/2%`，M1径向位移归一L2误差 `<=1%`；
- 两网格峰值腔面积响应绝对差 `<=0.002` 且相对差 `<=5%`；
- 主动应力在心内膜和ECM严格为零；P1A0腔面积增加 `>=1%`，P0A1减少 `>=0.5%`；
- 固定主动张力时加压使腔面积增加至少0.5个百分点；固定压力时加主动张力使其减少至少
  0.5个百分点；两主动终态的网格差仍同时满足上述 `0.002/5%` 门。

被动解析关系为 `a^2=A^2+c, b^2=B^2+c` 与
`p/mu=ln(Ba/(Ab))+c/2(1/a^2-1/b^2)`。它是不可压参照，不是有限 `kappa` 问题的精确真解。
独立验证器不得导入生产 UFL 形式或生产力学实现作裁决。峰值应力只报告，不宣称热点收敛。
