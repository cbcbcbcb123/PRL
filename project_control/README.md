# `project_control/` 项目治理记录

本目录保存当前状态、用户决定、采纳记录、执行合同、门禁、执行日志、偏差、审查和失败冻结。历史记录保持原路径，避免破坏既有交叉引用。

## 文件识别顺序

1. `CURRENT_STATUS.md`：当前状态索引；
2. 最新且适用的 `*_decision*`、`*_authorization*` 或主线计划；
3. 对应 `*_contract*`；
4. `*_execution*`、`*_report*`、`*_review*`；
5. `*_failure*`、`*_freeze*` 和 manifest。

文件名不能替代正文中的 `status`、`scope`、`supersedes` 和证据边界。旧失败、旧版本和历史授权不得因为出现新文件而被覆盖或删除。

外部专家指导原件存放在 `plan/`；这里只保存其采纳、修改、拒绝、暂缓或待裁决结果。
