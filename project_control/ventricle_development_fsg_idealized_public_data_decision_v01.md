# 发育—流固耦合主线：理想化三维起步，公开资料约束，后续自有实验替换

## 用户决定与适用范围

用户明确：“我们目前还没有实验，可以先用理想化三维模型及 morphoHeart 工作，
后续我们会补充自己实验替换。你把目前这个思路记录下来，然后继续项目。”

据此采纳以下研究路线。当前只用 FEM 连续体，不恢复 DCM；精确逐细胞分割不是前提。
本决定记录研究方向，不把理想化计算或公开资料比较标成自有实验验证，也不自动授权无限参数扫描。
已有二维失败、原始资料与外部专家原件全部保留；本记录是内部项目决定，不写入 plan/。

## 核心科学问题与首个范围

研究发育中心肌主动收缩、血流、组织生长和 ECM 重塑的反馈如何协调心室形态与泵血功能。
候选首个窗口为 48–96 hpf 附近，实际年龄以可用资料元数据为准，不伪造连续纵向样本。
先研究心室扩张、壁厚和功能，不同时承诺完整 looping、瓣膜生成、小梁细胞出芽和拓扑变化。

首个可检验假说：暂时降低收缩能力后的发育轨迹，可能同时受即时泵血下降及累积的
生长/ECM 反馈影响；恢复收缩后是否恢复正常轨迹取决于反馈强度与重塑时间尺度。
这是待检验假说，不能从模型设定直接推出已证实的生物学因果。

## 最小模型与分层对照

1. 快时间：三维有限变形心肌加主动应力，与腔内不可压血液双向耦合；界面速度协调、
   牵引平衡；通过进出口及简化循环负载实现充盈与射血。实测壁运动用于校准/验证，
   不能在全部壁面强制规定运动后仍称双向 FSI 预测。
2. 慢时间：以代表性周期的应力、应变、剪切及振荡特征更新组织生长和 ECM 状态。
   使用小发育步长及周期代表性检验，不要求逐一求解几十小时的全部心跳。
3. 生长候选采用 F=Fe Fg；近不可压约束作用于弹性部分。区分材料增量、重塑与
   可逆受力变形；腔体膨胀不是组织生长，现有无生长算例的 J 误差不是生长证据。
4. 生长含基础发育程序与力学调节，不假定血流解释全部形态；心内膜剪切信号与
   心肌直接受力路径分开。反馈函数、方向、阈值和参数须注明假设及来源。
5. ECM 区分体积/含量、几何铺展与材料变化。变薄不等于降解，不预设全部心腔遵从
   同一种“力越大、生长越快”规则。初版不堆叠完整基因网络。

对照顺序：A 固定发育状态 FSI；B 加基础生长但关反馈；C 开力学生长反馈；
D 加动态 ECM。保持同一初始几何与基础参数，比较容积、壁厚、应变、净流量、
反流及泵功等可观测量。三维/FSI/生长的组合本身不宣称首创。

## 数据层与日后替换规则

- **idealized**：无量纲三维腔体/层状组织，用于数值资格、机制对照及敏感性分析。
  几何、材料、纤维和时间均明确是设定，不能贴上真实标本标签。
- **public_morphoheart**：先核查原始文件、许可、年龄、个体、尺度、标记和心动相位。
  静态三维形态可约束几何与发育统计，不自动提供心动周期、压力、材料或连续生长率。
  不同个体横断面不能当成同一个体轨迹。当前已用的 72 hpf Fish 4 二维外轮廓，
  不等于真实三维心腔、壁厚或三层界面已合格。
- **own_experiment**：日后另建版本输入包，通过同一几何/材料/激活/循环负载/验证
  接口替换假设或公开数据。保留来源、单位、年龄、相位、个体与不确定性；缺失字段
  保持 unknown。不覆盖旧结果，不静默更换材料或阈值后继续使用旧结论。
- 参数拟合与验证分开：预留后期年龄或扰动组作预测检验。没有自有实验时，允许
  理论机制与公开数据趋势比较；物种/标本特异性验证和生物学因果保持 not_run/unknown。
