# NCS-M1：三层全 FEM 可核验基线执行方案

本阶段回答“规定周期主动应变经过黏弹 ECM，怎样传到被动心内膜”，同时验证未来替换心内膜表示所需的参照。**M1 通过只表示这一基线可信，不证明 DCM 优势、分裂机制、新物理或投稿水平。** 这里的 M1 与旧 Route H M1 无关。

1. M0 完成能力审计、参考推导和 `ncs_m1_frozen_spec_v01.md`，读取现有运行权限。

4. 写实际报告并更新驾驶舱。M1a 或 M1b 未解析时停在对应门，不扩展几何，不进入 M2。

代码开发与正式证据分开：开发输出不充当正式结果；正式运行采用新 create-only 包，失败也保留。不得重用旧 P1 结果目录，不自动调用旧 runner，不自动 S4。

## 2. 物理规格：有意简单且可独立核对

所有数值是**无量纲合成基准**，不是已校准斑马鱼参数。长度标度 L、模量标度 E0、周期 T 均取 1；出平面单位厚度；二维平面应变、小应变、准静态平衡，无流体与背景拖曳。去掉旧背景阻尼是新基准的明确模型选择，旧结果不因此重新获证。

| 层 | 平面范围 | 本构及基准参数 |
|---|---|---|
| 心肌 | x∈[−0.5,0.5], y∈[0,0.20] | 线弹性 FEM，E=2.5，ν=0.30；规定主动应变 |
| ECM | 同 x，y∈[0.20,0.50] | SLS：平衡支路 Eeq=1，νeq=0.45；Maxwell 弹簧 EM=0.7，νM=0.30；τ/T=0.20 |
| 心内膜 | 同 x，y∈[0.50,0.55] | 有限厚度被动线弹性 FEM，E=1，ν=0.30 |

三层先使用共形界面，位移连续、牵引平衡。心内膜不是零厚度链或细胞层；其厚度和模量没有从旧链刚度自动换算。M2 匹配时必须重新验证有限厚度与细胞层的可比性。

记 ε=sym∇u，z 为 ECM Maxwell 支路的黏性应变：

```
∇·σ = 0
心肌：σm = Cm : (ε−εa)
ECM： σe = Ceq : ε + CM : (ε−z),  τ ż = ε−z
心内膜：σn = Cn : ε
εa(x,t) = −α(t) p(x) ex⊗ex
α(t) = 0.005 [1−cos(2πt/T)]    # 峰值 0.01
```

U 案例 `p=1`；H 案例 `p=1+0.2 cos(2πx/L)`，只有这一种平滑非均匀输入，不扫描波数。初始 α=u=z=0，求启动响应并与周期稳态分开报告。全周期最大应变若超过 0.05，判小应变假设不适用；不能边运行边改成有限应变。

### 平面约束

用 `ux=ē(t)x+wx(x,y), uy=wy(x,y)`，w 在 x 周期，平均 wx=0；底面 uy=0，顶面自由。宏观轴向应变 ē 为未知广义自由度，其共轭广义轴向力为零（对整个周期单元积分，不能只用一个截面的点值替代）。底部法向支持不做功。通过约束消元或精确乘子去除刚体自由度，不使用任意大罚参数。

均匀案例无弯曲，提供易核对的材料传递；H 案例用于非均匀局部力学和界面传递。该边界是理想支承壁，不声称真实心室边界；自由弯曲另属后续问题。

### 能量和参考

单位厚度储能为三层积分之和：心肌 `½(ε−εa):Cm:(ε−εa)`，ECM `½ε:Ceq:ε+½(ε−z):CM:(ε−z)`，心内膜 `½ε:Cn:ε`。耗散率 `D=∫ECM τ ż:CM:ż ≥0`；主动输入功率 `Pa=−∫myo σm:ε̇a`。满足 `dΨ/dt + D = Pboundary + Pa`；本基准边界功为零，但仍输出约束反力与功以核验。

用 e^(iωt) 约定，`Ce*(ω)=Ceq+[iωτ/(1+iωτ)]CM`。在完整平面应变刚度上作横向零应力消元：`D*=Cxxxx*−Cxxyy*Cyyxx*/Cyyyy*`。均匀平面轴向谐波参考为

```
ē_hat = hm Dm εa_hat / (hm Dm + he De*(ω) + hn Dn)
```

DC 分量采用松弛刚度，不能和谐波共用复模量。M0 须补齐横向应变、应力及相位符号推导。参考不能调用被测二维 FEM 组装矩阵。CN 中点的离散能量收支与相对连续参考的时间误差分别检验，前者闭合不能替代后者收敛。

## 3. M1a 运行设计与读出

三档网格 G0/G1/G2：沿 x 为 16/32/64 个区间；各层厚向分别为心肌 4/8/16、ECM 6/12/24、心内膜 2/4/8。三角形采用成对严格镜像 `/`、`\`；均匀输入用主取向，H 的 G1/G2 增加另一取向。G 标签为新基准编号，不是旧 S 门的延伸。

时间步 Nt=64/128/256 每周期，CN；空间检验使用 Nt256，时间检验使用 G2。每条启动轨迹最多 20 周期；末两周期状态与核心读出相对周期差≤1e−6 才报告稳态，否则 NOT_RESOLVED，不无限延时。可用独立谐波解校验周期输出，不得把谐波计算伪装成已执行时域轨迹。

固定输出：宏观 ē；心内膜上表面的位移 L2 范数与周期基频；三层平均 εxx；各层储能、周期主动功/耗散；ECM 及心内膜局部区域平均应变/应力；界面弱反力与功率。局部区域取 x/L∈[−3/8,−1/8] 和 [1/8,3/8]，纵向分别为 ECM 全厚和心内膜全厚，面积积分定义。网格改变不改变区域。上下表面的有限元点应力最大值不作为主门。

平面镜像 x→−x 下，ux 奇、uy 偶，σxx/σyy 偶、σxy 奇；应力以张量变换比较，不比较镜像前后同名节点编号。镜像对局部区域同步映射，不把材料异质性加入此基准。

建议正式协议清单（冻结时逐项列命令和预期输出，复用完全相同协议的轨迹，不重复计数）：

| 协议 | 新轨迹数上限 | 用途 |
|---|---:|---|
| U/H × G0/G1/G2，Nt256 | 6 | 空间与主要响应 |
| U/H × G2，Nt64/Nt128 | 4 | 时间收敛，复用上述 Nt256 |
| H × G1/G2 镜像取向，Nt256 | 2 | 镜像与网格方向误差 |
| 零输入、纯被动仿射 patch、关闭 Maxwell 支路 | 3 | 零响应、常应变、弹性极限；patch 是独立边界单元验证 |
| τ/T=0.01 与 10，各一个 U 粗网格 | 2 | 与完整复模量比较快/慢松弛；只检周期参考，不要求慢松弛 20 周期内完成启动稳态 |
| 合计 | 17 | 不含小型参考代数；少做需说明删减不损失覆盖 |

快/慢松弛协议可直接求频域周期解；必须标明求解类型。启动稳态门仅适用于时域轨迹，不能将 τ/T=10 未达到稳态归类为方法错误。所有协议的矩阵分解、RHS 数量须在冻结清单给出预计值并与实际逐项对账，不沿用旧门 20/24 的账本。

## 4. 验收门：运行前冻结，近零量不硬算百分比

固定标度：εref=0.01，uref=εref L，σref=E0 εref，Wref=E0 εref²×单元参考面积×单位厚度。定义 `err(q)=|q−qref|/max(|qref|,qscale)`；场量用相应区域 L2 范数与固定场标度。网格差用细网格场投影到统一物理积分点后计算，禁止只比较节点序号。比例与实际绝对误差同时保留。

| 必需门 | 接受标准 | 失败含义 |
|---|---|---|
| 零输入/patch | 归一化位移/应变误差≤1e−8；无非法值 | 实现或约束问题，FAIL |
| 线性代数 | 缩放后 backward residual≤1e−10；报告约束残差 | 求解不可信，FAIL |
| U 独立参考 | G2/Nt256 位移、平均应变与周期功误差≤1e−3；非零基频相位差≤0.2° | 分离时空/启动/公式误差；未定位则 UNKNOWN |
| 时间收敛 | 对非零且高于误差底的参考误差，Nt64→128→256 观测阶1.8–2.2；最终参考误差达上门 | 高于误差底仍不收敛则 FAIL；低于门限100分之一时仅记误差底，不伪报阶 |
| 空间解析 | H 的 G1→G2：整体读出≤0.5%，局部面积读出≤1%；G0→G1 到 G1→G2 差值比≤0.7，低于各门限100分之一可记误差底 | NOT_RESOLVED，不自动 G3 或更换读出 |
| 镜像 | 变换后归一化位移、区域应变误差≤1e−8 | 对称性/网格/映射实现 FAIL |
| 物理收支 | 累积离散能量残差/max(累计绝对主动功+绝对边界功,Wref)≤1e−8；D≥−1e−12 Wref/T | 符号、实现或时间收支缺陷；不能用重新定义功闭合 |
| 界面 | 基于弱反力的两侧合力/合力矩与功率失配≤1e−8（按相应固定力、力矩、功率标度归一化） | 组装/约束问题；总平衡通过不证明局部应力精度 |
| 稳态/假设 | 时域周期差≤1e−6；max|ε|≤0.05 | 前者未解析；后者模型适用范围失败 |

相位仅对幅值≥1e−3×该读出标度的基频评价；更小者记不适用及绝对复幅误差，不能报“0°通过”。谐波/时域/积分量门分别列出，周期功的参考需包含 SLS 完整张量耗散，不能只用横向约化刚度回填全部储能。

## 5. M1b：一个曲率基准

二维圆环：内半径1，心内膜 r∈[1,1.05]，ECM [1.05,1.35]，心肌 [1.35,1.55]；材料与周期不变，主动应变为 `−α eθ⊗eθ`。内外边界自由，无血流/腔压；用零平均平移及零平均刚体转动约束去除刚体模态。此为平面应变圆环/长圆柱截面的理想化，不能称真实球形或心脏泵血。

三档周向32/64/128区间；各层径向2/4/8、6/12/24、4/8/16。周期频域三网格，对 G2 补 Nt64/128/256 三条时域轨迹；G1 增加一次整个模型旋转17°的坐标协变检查，共最多7协议。独立径向参考须在 M0/M1 冻结规格中完成并说明误差≤相应验收阈值的1/10。

读出为内边界平均径向位移、各层径向/环向应变、周期功与耗散。沿用 M1a 的数值/能量/空间门、独立参考1e−3/相位0.2°门；旋转检查采用场的向量/张量协变，阈值1e−8。网格的多边形几何误差包含在总误差中，不通过时报告几何离散贡献，不能把其扣除后称总门通过。
