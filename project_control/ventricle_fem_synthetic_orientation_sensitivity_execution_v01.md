# F1-S 合成长轴方向场敏感性执行记录 v01

## 裁决

F1-S 的工程门和预注册合成方向敏感性门均为 `passed`。唯一一次正式单线程 CPU 调用完成 `uniform` 与 `synthetic_random` 两个条件、G0/G1 两级网格，共 4 条轨迹；每条保存 41 个真实准静态状态。独立验证器重新生成冻结方向场，并从保存状态重算应变、应力、面内压力、腔面积和 KKT 平衡残差，全部门通过。

该结果只说明当前连续体 FEM 对合成的心肌长轴方向排列具有可解析响应。`2×24` 区域是材料赋值斑块，不是带细胞膜、接触、面积或体积自由度的显式细胞，也不是实验测得的斑马鱼细胞形态。真实细胞形态场、斑马鱼标定、生物验证、组织生长、ECM 反馈、心内膜增殖、FSI 和 DCM--FEM 优势仍为 `not_run`。

## 输入配对

- 两组坐标、三角连接、三层材料、相位、峰值主动应变 `0.03`、自由内外边界和刚体规范逐项一致。
- 唯一改变是心肌主动本征应变的长轴方向。
- 随机场固定种子 `20260916`；48 个斑块方向偏移均值 `-7.40e-17°`、RMS `7.65536°`、最大绝对值 `18°`。
- 每个心肌单元的主动本征应变迹和张量范数在两组之间严格匹配；未加入面积、体积、刚度、主动幅度或几何随机性。

## 主要结果

| G1 指标 | uniform | synthetic_random |
|---|---:|---:|
| 峰值腔面积变化 | -5.93222% | -5.88572% |
| 最大绝对应变 | 0.045593 | 0.046427 |
| 最大二维等效应力 | 0.039239 | 0.040287 |
| 心肌峰值应力 CV | 0.35219 | 0.34994 |
| 外边界位移幅值 CV | 0.36525 | 0.33086 |

G1 峰值配对差异：

- 位移场相对 L2 差异 `D_u=0.0794714`，即 `7.947%`；G0--G1 漂移为 `0.00137139`，其两倍为 `0.00274279`。
- 心肌等效应力场面积加权相对 L2 差异 `D_sigma=0.125968`，即 `12.597%`；G0--G1 漂移为 `0.00813517`，其两倍为 `0.0162703`。
- 两项均超过 1% 绝对门和两倍离散漂移门，因此方向场敏感性为 `passed`。
- 峰值腔面积变化只相差 `0.00046505`（0.0465 个百分点）。因此当前最直接的解释是：合成方向扰动明显重分配局部位移与应力，但对这一自由、无压椭圆环的整体腔面积响应影响较小。
- 随机组的应力 CV 和外边界位移 CV 没有增加，后者反而降低；不得把非零场差异解释成“随机性必然增加力学不均匀”。
