# Z1-C 接触面积测度与离散修复合同 v01

## 目标

修复 Z1-C v06 已复现的两个接触离散缺陷，同时保持原冻结科学门不变：

1. 当前目标面面积进入接触能量，但接触力缺少面积变化的变分项，导致面积变化路径工作不共轭；
2. 每个源节点对同一目标细胞的多个相邻面重复施力，且权重采用目标面面积，造成接触积分随源节点密度和面片划分变化，medium→fine 反力不收敛并可变号。

## 预注册修复

在 `ContactSpringBased` 增加显式接触积分模式：

- 保留既有 target-face/all-candidate 路径作为兼容模式，旧默认、C6 与优化后端语义不静默改变；
- 新增对称参考节点面积模式：每个源节点对每个目标细胞只选择一个最近的合格三角面；源节点采用由显式参考表面度量导出的固定顶点面积；双向 node→surface 积分各乘 `1/2`，避免同一物理界面重复计数；目标三角面的反力仍按最近点重心坐标分配；
- 若细胞没有显式参考度量，新模式必须在加力前失败关闭，不得退回当前面积或静默改变能量测度；
- 新模式的接触能量由同一牵引势和同一固定参考节点面积重建。

## RED→GREEN 工程门

1. 新模式对每个源节点/目标细胞至多一个活动接触；
2. 刚性平移和面积变化规定路径的接触能量—力相对误差均 `<=1e-10`；
3. 交换细胞 ID 后反力、能量和活动计数不变；
4. 逐对作用—反作用残差 `<=1e-12`；
5. 未捕获参考态时在任何节点力改变前抛出明确错误；
6. 既有兼容模式聚焦测试保持通过。

## Z1-C 原门重跑

修复通过工程门后，对球形、心肌端对端/侧对侧、心内膜边对边/面对面五例及 80/320/1280 面网格重跑。所有 v06 阈值原样保留，尤其：
