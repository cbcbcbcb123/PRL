# PRL：斑马鱼心室FEM核心模型与进展（专家评审稿）

快照日期：2026-09-18。当前代码基线：main / 1913bfb；最近科学提交：69d2d47。
这是精选技术评审包，不是完整仓库备份、投稿结论或新实验。所有 failed / not_run 状态保留。

## 1. 想回答的科学问题

研究斑马鱼发育过程中，心肌主动收缩、血流、组织生长和ECM重塑怎样共同影响心室形态与泵血功能。
首个拟研究问题是：暂时抑制收缩及随后恢复，是否通过累积的生长/ECM反馈造成不同的发育轨迹。
这是待检验假说，不是当前计算已经证明的生物学机制。

项目现在只采用FEM连续体，不恢复DCM。尚无自有实验；先用理想化三维模型及公开morphoHeart资料，
后续将自有几何、壁运动、材料和纤维数据逐项替换。目前的三维半椭球尚未用morphoHeart拟合。
既有二维外轮廓来自公开72 hpf Fish 4资料，但内腔/层界由缩放构造，不能当作真实三层分割。

## 2. 当前三维模型：到底算了什么

| 项目 | 当前实现与边界 |
|---|---|
| 几何 | z≤0的半椭球壳，外半轴(1,1,1.5)，径向层界(20/27,21/27,22/27,1) |
| 组织 | 构造的心内膜、ECM、心肌三域；当前三层同被动材料，并非实验校准的组织差异 |
| 材料 | 有限变形、近不可压混合Neo-Hookean；μ=1、κ=1000，均为无量纲设定 |
| 自由度 | 仿射四面体几何；P2三分量位移/P1连续压力；六阶体/面积分 |
| 约束 | 基底环z=0全位移固定；外壁自由 |
| 加载 | 内壁随动压力p_lumen/μ=0.01；已计算的三维态Ta=0 |
| 腔体积 | 由内壁加固定z=0虚拟平盖定义；平盖不是组织或瓣膜 |
| 主动项 | 心肌域的切平面分散主动张力已编码，但尚未运行三维主动状态 |
| 时间 | 准静态加载级/数值延拓；没有标定生理心动周期 |
| 后端 | 固定本地FEniCSx镜像，PETSc/SNES Newton线搜索与MUMPS；Gmsh用于候选网格 |

明确区分混合压力变量 p_m 和施加的腔压 p_lumen：二者不是同一个场。

```
F = I + Grad(u),   J = det(F)
W_pass = μ/2 [J^(-2/3) tr(F^T F) - 3] + p_m (J-1) - p_m^2/(2κ)
A = (I - n0⊗n0)/2
W_act = Ta/2 [tr(F A F^T) - tr(A)]        仅心肌域
P_act = Ta F A
σ_act = Ta F A F^T / J
Π_pressure = -p_lumen V_c
V_c = -(1/3) ∫inner (X+u)·cof(F)N dS
```

A是理想化等权切向分散张量，不是实测心肌螺旋纤维。三维主动项尚未经载荷资格验证。
原始模型合同、生产形式和独立NumPy验证器均随包保留，便于专家直接对照公式。

## 3. 已完成的证据与尚未过关之处

### 二维低压主动加载：数值资格passed，不是实验验证

F6-S1-S9：P2位移/DG2压力，两个轮廓网格；p/μ=0.02固定，Ta/μ从0至0.1。
8个新增平衡态通过该阶段验收；最大激活相对同压力零激活基线缩腔约1.85%。
这是二维平面应变准静态结果，不是三维心跳，不证明任意压力/网格稳定性。
此前高压工况仍failed；低压passed不是对高压失败的修复或掩盖。

M1零载passed，压力态3次Newton达到平衡，独立残差和场量重算通过；但局部体积误差仍超过预设1%。
M1超限全部邻接固定基底：心内膜72个、ECM48个、心肌0个。不能用整体体积响应接近代替局部质量。
M0→M1同时改变了曲面离散；不是同几何的纯h细化，也不能声明应力热点或渐近收敛。

### 网格质量审查：不能把“网格规则”认定为单一病因

M1比M0总体形状指标改善，但仍有基底超限。M1的120个超限中，72个没有触发形状筛查；
384个远区形状标记单元又没有超体积门。位置、薄层、约束与压力空间的影响尚未分离。
筛查阈值和相关性只用于诊断，不是普适正确性证明；单元也不是独立生物学重复。

### 最新非结构化候选：几何保持，质量门failed，FEM not_run

最差q反而从0.2220降至0.0292，少数ECM单元变差。最小内二面角6.638°→6.811°。

原执行在网格生成后因Gmsh节点重编号发生读取错误；候选MSH已完整保存。
只读解析保存的MSH后得到上述质量判断；原失败不改写。当前代码已修订精确坐标映射并补测，
但修订后的完整容器路径尚未重跑。本阶段新增FEM为0，没有候选应力/变形结果。
最新132项测试及21项子测试passed属于项目回归，不代表三维加载或生物学通过。

## 4. 当前判断与优先路线

目前主要瓶颈是三维近不可压局部体积控制，而非Docker启动、Newton不收敛或图片显示。
具体根因仍unknown：三维混合空间的局部约束能力、薄层分辨率、基底强约束及其组合均需检验。
不应根据现有证据简单断言某一种网格或压力空间“必然正确”。

拟先设计小型三维混合离散基准，审查稳定性、锁死、体积误差与自由度成本，再回到同载心室。
是否保留1%采样门、是否同时需要弱约束误差/能量误差/场收敛指标，请专家独立评价；
当前包没有事后放宽旧门，也不把门的讨论当作旧失败通过。

后续顺序：可靠三维被动/主动固体 → 生长公式基准及规定式三维生长 → 双向FSI →
周期平均力学生长反馈 → ECM反馈 → 公开数据检验 → 自有实验验证。
生长将采用F=Fe Fg，近不可压约束针对Je，不应把总J≈1误用于禁止真实生长。
生长、ECM反馈、三维血流、双向FSI、真实心动时间及物种特异性校准均not_run/unknown。
