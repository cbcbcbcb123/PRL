# 请专家优先裁决的问题

希望得到：主因优先级、推荐的最小下一步基准、可量化通过/停止指标，而不只是增加参数扫描。

1. **三维近不可压离散是否合适？** 当前仿射四面体/P2位移-P1连续压力、κ/μ=1000。
   对薄层强夹持情形，如何区分弱约束不足、离散不稳定、锁死和合理的局部弹性体积变化？
   若建议更换压力空间，请给出相应网格条件、稳定性依据和必要基准；二维DG2结果不能直接证明三维资格。
2. **局部体积验收怎么定义更科学？** 现用积分点与额外56点的max|J-1|≤1%。
   它应怎样与p_m/κ的投影误差、能量误差、网格收敛及边界热点配套？
   哪些指标属数值安全、哪些属生物校准？如建议修改未来门限，如何保留旧失败、避免事后选门？
3. **基底边界是否造成主导混杂？** 当前整个基底环固定，所有超限单元都邻接基底。
   应先做何种解析/制造解或厚薄层基准，再考虑弹性支撑、局部夹持或真实连接部？
   希望区分“改善物理边界”与“通过松约束降低数值误差”。
4. **薄层与网格路线怎么选？** 内膜/ECM当前各一个径向区间；同边界非结构化候选未达门。
   建议优先薄层法向分辨率、棱柱/六面体、高阶几何，还是实体-壳混合？如何隔离几何、DOF和本构变化？
   q05提高5%的候选工程门是否抓住了真正重要的质量风险？本包没有将其等同FEM正确性。
5. **材料和主动收缩是否是合理起点？** 三层同NH只为首轮数值资格，非真实组织校准。
   三维等权切平面主动张力与后续纤维向横观各向同性本构，应以哪些可测量约束和独立测试衔接？
6. **发育—FSI—ECM的最小机制模型是什么？** 在没有自有实验的阶段，哪些假设可由公开数据约束，
   哪些参数不可辨识？哪组关反馈/开反馈及抑制-恢复对照最有价值？
7. **验证与创新边界如何收紧？** 请区分数值资格、公开数据趋势一致、标本预测和生物学因果。
   三维/FSI/生长的组合本身不作为创新，请指出可证伪的机制问题及其最低证据要求。

建议回复格式：问题编号 → 证据位置 → 判断/置信程度 → 最小验证 → 通过/失败标准 → 是否需新实验。
原始专家回复将另存plan/外部方案包，本评审材料属于内部汇报，不伪装为专家意见。
