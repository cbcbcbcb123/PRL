# 心室模型细胞几何分工决定 v02

## 1. 最新用户决定

用户确认将长轴心肌细胞与扁平心内膜细胞提前纳入 Z1 验证，并明确回复“同意，开始”。因此 Z1 不再是纯球形阶段，而是以下递进矩阵：

1. `Z1a-SPHERE`：球形/icosphere，承担能量—力、刚体、Laplace、体积与细化基准；
2. `Z1b-MYO`：等体积长轴椭球心肌细胞，验证沿长轴和横向的被动响应；
3. `Z1c-ENDO`：等体积扁椭球心内膜细胞，验证面内和厚度方向的被动响应；
4. `Z1d-CONTACT`：同类双细胞的端对端/侧对侧受控接触，验证接触状态、穿透与作用—反作用。

球形不删除，因为 `Δp=2γ/R` 仍是低歧义解析基准。长轴和扁平细胞不得套用球形 Laplace 式；它们使用独立能量导数、压力功、刚体客观性和网格/时间收敛验收。

## 2. Z1 几何冻结

三类细胞具有相同目标体积，以球形等体积半径 `R0=0.45 L0` 为基准：

- 球形：半轴比 `1:1:1`；
- 心肌长轴椭球：半轴比 `3:1:1`，长轴为材料 `x` 方向；
- 心内膜扁椭球：半轴比 `4:4:1`，薄层法向为材料 `z` 方向。

这些比例是合成数值探针，不是生理测量或生物标定。Z1 优先使用光滑椭球，以避免圆角长方体/棱柱的棱边曲率与接触奇异性混入基础内核验证。圆角长方体、扁平棱柱和真实铺砌仍留给 Z4，在 Z4 授权前另行冻结。

## 3. 通过范围

如果 Z1 最终通过，只说明唯一 `muse_dcm` 在上述三类合成几何及受控双细胞路径上满足冻结的数值/力学门；不代表真实心肌/心内膜参数已标定，也不代表共享界面、连续组织或液密腔壁已经通过。

任一必需几何或力学子门未完成/未通过时，Z1 不得整体标记为 `passed`。内核缺少能量分项、参考构型或可独立核验接口时，按 Z1 合同停止为 `blocked`，不得以静态几何图替代力学验收。

## 4. 后续组织阶段

- Z4 复用 Z1 已验证的长轴/扁平几何身份、材料方向和网格质量门，进一步建立共享界面或受控接触账本；
- Z4b 单独验证共同腔面、壁—细胞映射和受压功；
- 独立闭合壳的相互穿透始终不得解释为组织连续性。

本决定只授权当前 Z1，不授权 Z2、Z4、Z4b、GPU、外部仓库修改或外部发布。
