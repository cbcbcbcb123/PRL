# Z1-BIOFORM-MYO-R｜心肌自由态数值资格修复合同 v03

在不使用目标末态和逐边/逐面参考形状能的前提下，修复 v02 的弯曲伪力、刚体漂移、坏面和时间步/扰动分支问题，重新检验方向性细胞骨架是否能形成稳定的长轴—横轴—厚度轴分离。

## 2. 冻结模型

- 单个自由闭合心肌 DCM；无邻居、ECM、腔压和夹持；
- 被动项：SimuCell3D 体积压力、标量总面积弹性、各向同性皮质张力；
- 当前 SimuCell3D 离散弯曲项因未通过平移/转动不变性诊断，冻结为 `bending_modulus=0`；曲率仍计算和输出；
- `reference_edge_shape_terms=0`、`reference_face_metric_terms=0`、`target_geometry_used=false`；
- 主动方向张量保持 `Sigma=s[p⊗p-0.15q⊗q-0.85r⊗r]`，应力幅值保持 v02 已选的 `s=0.060`；
- 面上形态驱动仍为 `n(n·Sigma·n)`，面积分配到顶点并投影到顶点法向；不再用会改变形态的逐节点等力/转动修正；
- 对总过阻尼速度做面积加权最佳拟合，移除唯一的 3 个刚体平移和 3 个刚体转动速度。该操作只固定自由细胞的坐标规，不改变一阶内禀形变；原始主动/被动净力和所移除速度均记录；
- 单个外层步内若预测最大节点位移超过当前最短边的 10%，自动缩小实际子步并重算力；不得以子步替代门禁。

- 8/8 正式轨迹完成；9 个保存状态全部有限、闭合流形、Euler 特征数 2；
- 最大体积相对误差 `<=0.02`；保存态及逐步最小三角角均 `>=15 deg`；
