# Z1-TF2-B｜SimuCell3D 致密三层形态形成与维持筛查合同 v01

## 1. 本阶段只回答什么

在已通过 Z1-TF2-M0 换核资格门后，检验由以下环境机制组成的致密三层组织，能否在**不使用细胞方向性参考形状膜能**时：

1. 从近各向同性细胞起步，形成方向正确的长轴心肌与扁平心内膜；
2. 从已经拉长或压扁的细胞起步，在小扰动后维持或恢复相应形态；
3. 通过消融对照区分方向性胞内承载、腔压、同层黏附、细胞—ECM 黏附和 ECM 支撑的贡献。

本阶段是合成静态/准静态筛查。最高裁决为 `passed_tf2b_screening`，不等于生理参数标定、真实发育过程、周期收缩、父 Z1 解决或完整心室验证。

用户于 2026-09-12 明确确认“冻结并执行 Z1-TF2-B”。本文件现为冻结合同；执行权限以单独授权记录为准。

## 2. 必须分开的两个试验臂

### 2.1 FORMATION：形态形成臂

- 每层为 `4×4` 个闭合细胞；心肌与心内膜分别从等体积近球形网格起步，而不是预先画成长轴或扁平形；
- 心肌等效球半径冻结为 `3.42215355382543`，目标体积为 `167.875410364543`；心内膜等效球半径冻结为 `2.82492551731944`，目标体积为 `94.4299183300554`；
- 同层中心距冻结为 `2r-0.25`，细胞—ECM 初始表面重叠为 `0.12`，接触截断为 `0.35`；因此所有预期邻居在初态即接触或处于接触截断内，不能用跨空隙弹簧冒充组织连续性；
- 使用固定细胞 ID、网格取向、中心位置和确定性种子；所有消融条件从同一份初始状态开始；
- `FULL-MIRROR` 将组织关于 `y=0` 镜像，作为离散网格偏置检查，不作为第二个生物重复。

### 2.2 MAINTENANCE：形态维持臂

- 从 M0 已保存的长轴心肌与扁平心内膜几何开始；这些只是规定的初始几何，不作为“已形成”的证据；
- 对每个细胞施加幅值为其等效半径 `2%` 的确定性、零均值、无优选方向表面扰动，随后重新校正质心和目标体积；
- 检验 `FULL` 是否恢复/保持形态，并用相同消融条件判断这种维持依赖哪些环境机制；
- 维持臂不得替代形成臂。即使维持通过而形成不通过，也不能裁决为完整 TF2-B 通过。

## 3. “不用参考态膜能”的精确定义

- 心肌和心内膜的逐边、逐面或逐节点方向性参考度量必须不存在；输出字段 `reference_edge_shape_terms` 必须精确为 `0`；
- 不得捕获初始非球形网格的边长、曲率或主轴，作为细胞的无应力参考形状；
- 允许使用 SimuCell3D 已有的**标量**体积—总面积稳态项、皮质张力和弯曲。它们不携带长轴方向或扁平方向，不能单独指定细胞朝哪个方向变形；
- 为避免“球体已经是给定体积下最小面积，因而根本没有可变形面积余量”，FORMATION 臂使用角色特异的标量面积储备。候选值来自 M0 初始几何的独立重算：

| 角色 | 内核参数 `A^3/V^2` | 归一化 `A^3/(36πV^2)` | 解释 |
|---|---:|---:|---|
| 心肌 | `141.674572586949` | `1.25267825209136` | 提供无方向的表面积储备；方向必须来自胞内承载和组织约束 |
| 心内膜 | `209.181549089029` | `1.84957097450771` | 提供无方向的表面积储备；扁平方向必须来自 ECM/腔面边界 |

这些标量是数值稳态目标，不是已验证的细胞骨架模型或生理参数。ECM 继续采用 v05 决定的 `surface-only` 分支；本阶段不为细胞或 ECM 新增逐边参考度量。

## 4. 模型、载荷与边界条件

- 对象固定为 `16` 个心肌细胞、`1` 个连续闭合且可变形 ECM 对象和 `16` 个心内膜细胞，共 `33` 个闭合三角曲面对象；
- 仅允许真实 SimuCell3D 面—面接触/黏附装配。心肌—心内膜直接接触必须始终为 `0`，两层之间只经 ECM 传力；
- 心肌使用沿组织 `x` 轴的零合力、零合矩方向性胞内表面载荷，`FULL` 幅值冻结为 M0 的 `0.035` 模型单位；该项是静态极化承载代理，不是周期收缩；
- 心内膜腔面使用有向压力牵引，`FULL` 末值冻结为 M0 的 `0.50` 模型单位；
- 组织左右两端采用有限顶点区夹持：外侧心肌/心内膜边界细胞的端面顶点以及 ECM 最外侧 `2.5%` 宽度顶点固定，其余顶点可变形；
- M0 的表面参数保持不变：心肌 `(surface_tension,bending,area,bulk,repulsion)=(0.010,0.0010,0.020,0.20,0.16)`，心内膜为 `(0.008,0.0008,0.018,0.18,0.16)`，ECM 为 `(0.002,0.0004,0.010,0.12,0.20)`；黏附强度为 `0.04`；
- `SOFT_ECM` 只把 ECM 的表面张力、弯曲、面积和体积支撑系数同时降为 `0.25×`，接触截断、排斥、几何和细胞参数不变。该对照只解释为“降低当前 surface-only 支撑”，不得称为真实 ECM 杨氏模量扫描。

## 5. 冻结工况矩阵

两个试验臂均运行同一组条件：

| 条件 | 唯一改变 | 目的 |
|---|---|---|
| `FULL` | 全部机制开启 | 主筛查 |
| `FULL_MIRROR` | 初始组织关于 `y=0` 镜像 | 检查网格/编号伪方向 |
| `NO_DIRECTIONAL_SUPPORT` | 心肌方向性胞内载荷为 `0` | 检验心肌长轴形成/维持的方向来源 |
| `NO_LUMEN` | 腔面压力为 `0` | 检验心内膜腔面载荷贡献 |
| `NO_CELL_ECM_ADHESION` | 细胞—ECM 黏附为 `0`，ECM 与排斥保留 | 检验 ECM 连接，不改变三层拓扑 |
| `NO_SAME_LAYER_ADHESION` | 同层细胞黏附为 `0`，排斥保留 | 检验组织连续性来源 |
| `SOFT_ECM` | ECM surface-only 支撑系数为 `0.25×` | 诊断 ECM 支撑敏感性 |

除表中唯一改变外，初始网格、ID、参数、边界、步长、随机种子和停止规则必须一致。不得通过删掉 ECM 对象来做消融，因为这会同时改变拓扑并允许两细胞层直接接触。

## 6. 路径与“不同时间点”输出

- 载荷和黏附按 `λ=0,0.25,0.50,0.75,1.00` 逐级开启，每级达到冻结的力残差或步数上限后再进入下一级；
- 在 `λ=1` 的保持段保存归一化求解器时间 `s=0,0.25,0.50,0.75,1.00` 和最终收敛/停止状态；
- `λ` 是载荷延拓坐标，`s` 是归一化数值松弛进度。由于阻尼和单位尚未生理标定，两者都不得标为毫秒、心动周期相位或真实生物时间；
- 每个保存点必须包含同一持久 ID 的网格、曲率、细胞内压、节点总力、主动/压力/接触分量和面积归一界面牵引。

## 7. 形态与连续性指标

对每个闭合细胞由三角面独立重算面积加权形状张量。令固定组织坐标上的 RMS 半径为 `r_x,r_y,r_z`，主轴为 `e_1,e_2,e_3`：

- 心肌长轴指标：`E_m = r_x/sqrt(r_y r_z)`；方向一致性：`C_m = |e_1·x_hat|`；
- 心内膜扁平指标：`F_e = sqrt(r_x r_y)/r_z`；法向一致性：`C_e = |e_3·z_hat|`；
- 同时输出每个细胞的体积、总面积、目标面积误差、邻居数、细胞—ECM 接触面积、最小间隙、曲率分位数、压力和各力分量；
- 组织级输出层厚度、覆盖率、裂隙面积、ECM 位移/曲率、夹持反力、接触作用—反作用残差与工作—耗散账本；
- 主判据使用中央四个细胞的中位数，另报告全部 `16` 个细胞的分布，禁止只挑最好看的细胞。

## 8. 冻结验收门

### 8.1 共同数值门

- 所有量有限；33 个对象始终闭合，无开边、非流形边、翻面或持久 ID 漂移；
- 每个细胞最终相对目标体积误差 `<=5%`，全程最小三角形角 `>=15°`；
- 固定顶点最大位移 `<=1e-14`；自由节点末态最大合力相对本条件历史峰值 `<=5%`；
- 压力积分、主动净力/净矩、接触作用—反作用和工作—耗散采用 M0 的独立重算定义，分别保持在冻结容差内；
- 心肌—心内膜直接接触为 `0`；中央细胞在 `λ>=0.5` 的保存点中至少 `80%` 保持同层邻接与细胞—ECM 接触；
- `FULL` 与 `FULL_MIRROR` 的中央细胞中位形态指标相对差 `<=10%`，且方向向量按镜像规则变换。

### 8.2 FORMATION 形态门

- `FULL` 中央四个心肌末态中位数 `E_m>=1.20` 且 `C_m>=0.90`；至少 `12/16` 个心肌满足 `E_m>=1.10`；
- `FULL` 中央四个心内膜末态中位数 `F_e>=1.50` 且 `C_e>=0.90`；至少 `12/16` 个心内膜满足 `F_e>=1.30`；
- `FULL` 与 `NO_DIRECTIONAL_SUPPORT` 的中央心肌末态中位 `E_m` 差值 `>=0.10`；
- `FULL` 与 `NO_LUMEN` 的中央心内膜末态中位 `F_e` 差值 `>=0.15`；
- `FULL` 与 `NO_CELL_ECM_ADHESION` 的中央心内膜末态中位 `F_e` 差值 `>=0.10`；
- `NO_SAME_LAYER_ADHESION` 与 `SOFT_ECM` 作为机制诊断必须完整报告，但不单独决定主 PASS，避免在未知参数区强行预设单调性。

### 8.3 MAINTENANCE 形态门

- 对 `FULL`，心肌 `E_m-1` 与心内膜 `F_e-1` 的中央中位数分别保留初始未扰动值的至少 `80%`；
- `FULL` 末态 `C_m>=0.95`、`C_e>=0.95`，且扰动后到末态的形态误差下降；
- 关键消融对照必须按形成臂的方向改变相应指标；若维持通过但消融不区分，维持臂只能记为 `unknown_mechanism`。

旧 MeshCell3D Z1-TF 的 `+10%/+50%` 门只作为历史信息，不自动继承为本合同通过证据。上面的阈值已随本合同冻结。

## 9. 互斥裁决

- `passed_formation_screen`：FORMATION 的共同数值门、形态门和关键消融差异全部通过；
- `passed_maintenance_screen`：MAINTENANCE 的共同数值门、恢复门和关键机制方向全部通过；
- `passed_tf2b_screening`：两个试验臂均通过；
- `unknown`：计算可信并收敛，但形态或消融效应不足，不能确认机制；
- `failed_numerical`：非有限值、翻面、体积/网格/守恒/收敛门失败；
- `blocked_dependency`：当前受控核心缺少本合同必需且不能在适配层内建立的能力；
- `not_run`：正式求解未开始。

不得把好看的图、单个细胞、维持臂或某个局部门替代完整裁决。
