# PRL Figure 2 空间与容差验证合同 v02（修订草案）

## 1. 合同身份与修订结论

本文件是等待人类终审的修订草案，不授权实现或计算。v01 因边界网格相位、容差
覆盖、跨网格重构和离散功率定义不足而被独立审阅判为 `REVISION_REQUIRED`。

v02 的核心修订是：

- 用嵌套 `F200N` 取代重新居中铺网的普通 F200；
- 每个控制空间比较端点同时有 C0 与 C1 证据；
- C1 通过唯一配置贯穿 worker、父审计和 provenance；
- 按场类型冻结共同求积与守恒投影；
- 用与指数 SLS 更新一致的算法耗散建立离散功率账本；
- 把终局细网格 T128 设为联合时间—空间主张前的强制触发门。

## 2. 科学问题与允许结论

本阶段检验：在固定三层物理模型中，主要响应沿预登记细化路径对 ECM 体网格、
DCM—界面联合表面离散、横向边界和代数求解误差是否稳定。

本合同不承诺构造可加的完整误差预算，也不解析所有交互项。全部门通过后，只能
声称“沿冻结细化路径达到合同级数值稳健”；不得称材料已标定、DCM–FEM 优于全
FEM、获得普适控制律、解释 EFE 或达到严格连续极限。

## 3. 冻结物理与参考尺度

物理输入保持 P6 不变：周期 `T=1`、峰值激活 `0.20`、同一波形和相位原点，
`mu_ve=eta_ve=0.5`，同一心肌/心内膜能量、体积约束、双界面、支承和安全门。

统一参考尺度为：细胞轴向参考长度 `L=1`、应力/牵引尺度 `mu_eq=1`、能量尺度
`mu_eq L^3=1`。所有相对范数的近零保护使用相应参考尺度，不从被比较的两个近零
量自身构造分母。

## 4. 冻结离散族

### 4.1 DCM 与 F150 ECM

| 标签 | 定义 |
|---|---|
| `D0` | 每个细胞 `162` 顶点、`320` 面 |
| `D1` | 每个细胞 `642` 顶点、`1280` 面 |
| `E0/F150` | `(8,4,6)`；`315` 顶点、`1152` 四面体 |
| `E1/F150` | `(12,6,9)`；`910` 顶点、`3888` 四面体 |
| `E2/F150` | `(15,8,12)`；`1872` 顶点、`8640` 四面体 |

D0 与 D1 当前参考 bounds 均为 x `[0,1]`、y `[0,0.6]`、z `[0.2,0.76]`；
ST0 必须把这些绝对 bounds 作为输入冻结，不能由目标 DCM 网格重新推导。

当前整面选择规则下，D0 的心肌—ECM/ECM—心内膜 tether 数为 `52/60`，D1
为 `182/242`。它们是 DCM—界面联合离散的一部分，不解释为纯 DCM 几何误差。
ST0 必须同时冻结选择规则、计数、总面积权重及零/一阶空间矩；任一漂移即停止。

### 4.2 嵌套边界网格 `F200N`

E2/F150 的 ECM 绝对域为 x `[-0.25,1.25]`、y `[0.64,0.94]`、z
`[0.06,0.90]`。`F200N` 扩大到 x `[-0.5,1.5]`、z `[-0.08,1.04]`，但必须
逐点、逐四面体原样保留中央 E2/F150 网格：

- 中央 x 网格保持 `0.1` 间距；两侧各增加两个 `0.125` 宽的壳层单元；
- 中央 z 网格保持 `0.07` 间距；两侧各增加两个 `0.07` 宽的壳层单元；
- y 网格保持 8 层不变；
- 候选计数为 `(19,8,16)`、`3060` 顶点、`14592` 四面体。

ST0 必须证明中央所有节点坐标、四面体连接、参考体积和材料编号 byte-exact
嵌入；未通过时不得用普通 F200 插值代替，也不得开始周期。

## 5. 时间与求解配置

空间阶段使用 `T64`。T64 只在 D0/E0/F150 上通过了与 T128 的时间门，因此在
终局细网格上不能自动继承该结论。

求解配置必须成为一个序列化、不可静默回退的对象，并由 worker 和父审计读取
同一份值：

| 配置 | C0 | C1 |
|---|---:|---:|
| coupling tolerance | `1e-4` | `1e-5` |
| max coupling iterations | `12` | `24` |
| L-BFGS `gtol` | `2e-7` | `2e-8` |
| Newton `fatol` 与跳过阈值 | `1e-7` | `1e-8` |
| follower tolerance | `1e-7` | `1e-8` |
| KKT 接受门 | `1e-5` | `1e-6` |
| L-BFGS `ftol` | `1e-14` | `1e-14` |

当前基线压力/WSS 为零，follower tolerance 标记为 `not_exercised_zero_load`，
不得作为 C1 已验证项。C1 不允许 Aitken/Anderson、新预条件器、新后端或门限
回退；24 次后仍失败即 fail closed。

## 6. 最小路径矩阵

`R0=D0/E0/F150/T64/C0` 只读保留为已接受时间锚点。新的控制矩阵为：

| 标签 | DCM | ECM/边界 | 容差 | 作用 |
|---|---|---|---|---|
| `A1` | D0 | E1/F150 | C0 | ECM 中网格、常规容差 |
| `A2` | D0 | E2/F150 | C0 | ECM 细网格、常规容差 |
| `A3` | D1 | E2/F150 | C0 | DCM—界面细化、常规容差 |
| `A4` | D1 | E2/F200N | C0 | 嵌套边界扩大、常规容差 |
| `B1` | D0 | E1/F150 | C1 | A1 的严格容差副本 |
| `B2` | D0 | E2/F150 | C1 | A2 的严格容差副本 |
| `B3` | D1 | E2/F150 | C1 | A3 的严格容差副本 |
| `B4` | D1 | E2/F200N | C1 | A4 的严格容差副本 |

主要空间裁决使用严格容差路径 `B1→B2→B3→B4`。每个 `Ai→Bi` 同时给出该
工况的代数容差误差。该设计是路径式分离，不声称识别 DCM×ECM 的全部交互。

每个新工况最多两个完整 T64 事务周期；第二周期相对第一周期的冻结五条周期门
均须 `<=1e-3`。暖启动不计为目标证据，不自动追加第三周期。

## 7. 共同求积与跨网格硬门

### 7.1 ECM 体场

- P1 位移在参考四面体内用重心插值重构；
- `J`、应力、应变、能量密度、SLS `Z` 和算法耗散作为 DG0 场，在包含点的目标
  四面体上取值；
- 共同求积点固定为 E2/F150 每个四面体的质心，权重为其参考体积；
- F150/F200N 只比较 byte-exact 中央共同四面体，禁止外推。

### 7.2 DCM 表面场

- P1 位移用参考三角形重心坐标重构；三角形场按包含面取值；
- 共同求积点固定为 D1 参考三角形质心，权重为 D1 参考面积；
- D1 材料方向映射回 D0 参考面；全部点必须有唯一包含面。

### 7.3 界面牵引

离散 tether 力先通过保守 L2 投影重构为共同材料表面上的牵引密度。投影必须同时
保持界面总力与关于固定参考中心的总矩；不得用最近 tether 或最近节点替代。

定义
`R_F=||sum f||/max(sum ||f_i||,F0)`，
`R_M=||sum (r-r0)×f||/[L max(sum ||f_i||,F0)]`，其中 `F0=mu_eq L^2=1`。
两者均须 `<=1e-10`；近零情况下同时报告有单位绝对余量。

### 7.4 映射与范数

- 共同点覆盖率必须为 100%，最大参考坐标定位残差 `<=1e-10 L`；
- 牵引投影的总力/总矩保持误差 `<=1e-8`；
- 相对场差定义为加权
  `||a-b||_w / max(||a||_w,||b||_w,S_abs)`；
- `S_abs` 分别取 `1e-8 L`（位移）、`1e-8 mu_eq`（应力/牵引）、
  `1e-10 mu_eq`（能量密度）、`1e-10 mu_eq L^3`（积分能量）和 `1e-10`
  （无量纲场）；
- 场比较相位固定为 `0,0.25,0.5,0.75,1`，使用通过周期的 cycle 2；
- 标量波形仍用 4097 个公共相位和既有周期圆相位规则。

### 7.5 热点

对 p95 以上共同求积点同时报告：加权质心移动、加权 Jaccard 重叠和归一化一阶
传输距离。通过门为质心与传输距离均 `<=0.1L`、Jaccard `>=0.5`。热点分裂或
交换即使质心不动也不得判为稳定。

## 8. 离散功率账本

现有 `dt*eta*||Delta Z/dt||^2` 只保留为非负耗散代理，不作为严格功率闭合项。
ST0 必须按实际 staggered/exponential 更新建立逐步恒等式：

`W_active + W_pressure + W_WSS = Delta U_recoverable + D_SLS_alg + R_num`。

- `W_active` 使用模型已有 `g=activation_derivative=partial E_active/partial a`；
  每步冻结为 `0.5*(g_n+g_{n+1})*(a_{n+1}-a_n)`，并用中心差分验证导数和
  符号；不得事后改用能产生更小闭合余量的积分公式；
- `U_recoverable` 唯一包括心肌被动/主动纤维、心内膜、ECM 平衡/黏弹、双界面
  和弹性支承能；
- 基线 `W_pressure=W_WSS=0`，但端口显式输出为零；
- 每个界面分别报告细胞侧功、ECM 侧功与界面能变化；
- 对固定终步变形，指数更新的算法耗散定义为
  `D_SLS_alg=Psi_ve(F_{n+1},Z_n)-Psi_ve(F_{n+1},Z_{n+1})>=0`；
- 不允许“其他物理耗散”或未命名修正项吸收残差；
- 逐步恒等式先在单四面体制造路径及完整三层零载/循环路径验证；
- 周期 `|sum R_num|/max(W_active_positive,1e-12)<=1%`，且不得用正负残差抵消
  掩盖大逐步误差；同时报告逐步绝对值积分余量。

若主动功的冻结积分规则不能随 T32→T64→T128 稳定，功率门失败，不能进入
空间周期。

## 9. 数值裁决

### 9.1 单工况硬门

无缺步、NaN/Inf、哈希不符或 PID 复用；满足对应 C0/C1 残差、体积
`<=1e-8`、`min J>=0.5`、`min gap>=-1e-12`、最小面面积比 `>=0.05`、
作用—反作用/合矩、非负算法耗散、周期稳定和功率闭合门。

### 9.2 严格容差路径的空间门

- ECM：`B1→B2`；
- DCM—界面：`B2→B3`；
- 边界：`B3→B4`，只在 byte-exact 中央共同域比较。

每个比较均要求：细胞全局读数 `<=1%`；能量积分、p95 应力/牵引和共同域场差
`<=10%`；热点门通过。E0→E1→E2 非单调时可报告有限敏感性，但不得报告观察阶
或连续极限。两档 DCM 只能称 D0→D1 联合离散稳定。

### 9.3 容差门

对 A1/B1 至 A4/B4 的每一对，非近零 QoI 的容差差必须同时：

- 不超过相应空间门的 20%：全局 `<=0.2%`，场/能量/牵引 `<=2%`；
- 不大于该 QoI 在相关严格空间比较中的最后一级差；
- 满足全部 C1 硬门。

对应关系冻结为：A1/B1 与 A2/B2 对照 B1→B2；A3/B3 对照 B2→B3；
A4/B4 对照 B3→B4。若相关空间差为近零，则改用第 7.4 节绝对尺度。

近零量使用第 7.4 节绝对尺度。任一空间端点未通过容差门，就不能把对应差异解释
为空间或边界误差。

## 10. 终局细网格时间触发门

`D1/E2/F200N/C1/T128` 是形成联合时间—空间稳健主张前的强制候选。它不在本
草案的默认执行授权内。

ST2 后必须返回人类门：若批准，执行两个 T128 严格容差周期并按 P6 同名规则比较
T64→T128；若不批准，则 Figure 2 后续版本只能并列报告“粗基线时间门”和“固定
T64 的细化路径敏感性”，不得声称终局网格时间已验证。

仍不授权 T256。

## 11. 分阶段执行与停止点

### ST0 — 唯一候选下一步

只允许：

1. 实现并测试绝对 ECM bounds 与 F200N byte-exact 嵌套；
2. 参数化 C0/C1 并贯穿 worker、父审计、summary 和 provenance；
3. 实现逐场共同求积、保守牵引投影和映射硬门；
4. 推导并测试离散功率恒等式与算法 SLS 耗散；
5. 对每种网格做零载/单步成本与存储预检；
6. 提交网格嵌套图、映射图、功率制造解图和资源预算。

参数化后的 C0 还必须在冻结 R0 的相位 `0,0.25,0.5,0.75,1` 上复演审计，
确认输入 digest、接受的 variables/vertices/Z 数组 bitwise exact，门限布尔值完全
一致。若不能复现，R0 不得只读复用，必须返回人类门决定是否建立新的空间阶段
基线。

ST0 不得运行 A1–B4 完整周期。完成后停在 ST0 Human Gate。

### ST2 — DCM—界面与嵌套边界

离散阶段 FINAL，v03 不得覆盖 v02，并须经过独立检查与人类 Figure Decision Gate。

## 12. Fail-closed 条件

任一情况立即停止：输入/网格/配置指纹不符；F150 中央网格不能 byte-exact 嵌入；
映射覆盖或守恒投影失败；功率恒等式存在开放残差桶；任一硬门/周期门/容差门
失败；普通 F200 被用于替代 F200N；C1 发生静默回退；空间非单调却报告阶；边界
失败却报告边界无关热点；未做终局 T128 却声称联合时间—空间稳健。

不得自动追加网格、周期、T256、参数扫描、N1-2d、N1-3、GPU、新求解器、
Active-Foam 或双向 FSI。

## 13. 当前待人类决定

v02 完成独立只读复核后再提交人类终审。即使批准，建议只授权 ST0；到 ST0
Human Gate 停止，不授权 A1–B4 周期。
