# F3-B｜三维有限变形FEM的首次资格与失败保全

## 结论与范围

已实现有限变形运动学、等容Neo-Hookean / Guccione型材料、连续Q2位移/Q1压力混合六面体、方向性主动张力及独立验证。本轮正式调用仅一次，单线程CPU、0 GPU、0 DCM，139.046秒后按失败门停止。预登记14工况、82状态，实际13工况完整、最后刚转工况保留1/5状态，总共78个有效平衡状态。**整体failed；不能进入真实心室计算。**

三维指规则实心块/梁，不是真实三维斑马鱼心室。材料和主动幅度仍为无量纲工程参数，无Pa标定；激活相位不是秒或bpm。不新增图像、分割、压力、血流、生长或ECM反馈，不恢复DCM。

## 完成与失败分开记录

完整求解了六组被动拉伸、三组主动循环和四组非仿射弯曲。每一状态保存节点位移、压力自由度、Gauss点F/P/Cauchy/Green/J/能量、约束、外力、反力与Newton记录。主动循环九个状态全部保存，展示选取五个真实状态，不生成缺失帧。

最后刚体旋转工况只完成0°；15°初猜被拒绝，30°/45°/60°未尝试。终端中的“state 2/5”是在求解前打印，不是该状态完成证明。

详见[独立验证](../results/ventricle_fem/f3b_finite_strain_v01_20260917/verification.json)、[原始失败](../results/ventricle_fem/f3b_finite_strain_v01_20260917/failure.json)和[结果页](../results/ventricle_fem/f3b_finite_strain_v01_20260917/index.html)。验证器的`complete_frozen_case_matrix`只核对配置是否为预登记矩阵，不能解释为82状态全部完成；执行完整性由实际raw状态数及失败记录裁决。

## 根因：非零位移边界缺少可行初值提升

前一0°平衡解被直接带入15°工况。边界目标旋转计算正确，但求解器仅替换固定自由度：98个边界节点已转动，27个内部节点仍以零位移为初猜。因此试猜并非整体刚体转动。

独立从保存坐标重建Q2形函数得到216个Gauss点中12个J≤0，涉及4/8单元，min J=-1.1839272303。保存向量与“前态＋仅替换边界”逐项差为0；内部正确刚转位移最大约0.437798，试猜却为0。对全体节点一致旋转的纯算术对照给出J=1±1.3e-15；这不是新的平衡求解。

失败发生在初态正J检查，早于材料函数、Newton与线搜索，故没有证据把它归因于本构失稳。`last_newton_history.json`为空。`last_newton_state.npz`是被拒绝的不合法初猜，**不是最后有效检查点**；最后有效0°状态在`raw/nh_rigid_rotation.npz`中。见[只读诊断](../results/ventricle_fem/f3b_finite_strain_v01_20260917/diagnostics/rotation_initial_state_v01.json)。

现有测试检查了边界值正确、非法J拒绝和材料客观性，但没有覆盖“上一平衡态＋下一非零位移边界”的正式串联过程。不能以运行前85项开发测试通过替代这项集成资格。
