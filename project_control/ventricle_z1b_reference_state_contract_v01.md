# Z1-B 长轴与扁平细胞参考态合同 v01

## 目标与裁决范围

在唯一 E:\MeshCell3D\code\muse_dcm 内核中加入通用、显式捕获的表面参考度量，并验证合成长轴心肌探针和扁平心内膜探针可以作为无载参考态保持，而不是由各向同性表面张力自动球化。

本合同只验证**非球形参考态及围绕该参考态的小幅被动响应**。它不修复旧弯曲能量，不验证接触，不标定真实心肌/心内膜参数，也不授权 Z1-C、多细胞桥接、Z2 或组织模型。

## 冻结本构

每条参考表面边保存参考长度 \(l_{e0}\) 和参考双重面积权重 \(A_{e0}\)。每个三角面向三条边各贡献其面积的三分之一，因此 \(\sum_e A_{e0}=A_0\)。参考态能量与节点力为

\[
E_{ref}=\frac{\mu_{ref}}{2}\sum_e A_{e0}
\left(\frac{l_e-l_{e0}}{l_{e0}}\right)^2,
\qquad \mathbf F=-\frac{\partial E_{ref}}{\partial \mathbf q}.
\]

reference_shape_modulus 的单位为 N/m，冻结为合成值 5e-4 N/m。参考态必须由调用者显式捕获；模量非零但参考态缺失、边退化或拓扑改变时必须失败关闭。Z1-B 中体积、恒表面张力、全局面积、弯曲、接触、主动、ECM 和流体全部关闭，避免用其他项掩盖参考态行为。

## 冻结几何

- 三档闭合 icosphere：80、320、1280 面；
- 等体积半径：R0=4.5e-6 m；
- 心肌合成探针：主轴比 3:1:1，材料长轴为 x；
- 心内膜合成探针：主轴比 4:4:1，材料法向/厚度轴为 z；
- 上述比例只用于算法验证，不是生理测量或标定值。

## 必需检查与门

1. **REF**：参考态最大相对边应变 <=1e-14；最大节点力除以 F0=mu_ref*A0/R0 后 <=1e-12；参考能量除以 E0=mu_ref*A0 后 <=1e-24。
2. **GRAD**：两种几何、三档网格、四个固定随机方向的中心差分；每例最佳相对误差 <=1e-6。
3. **RIGID**：非坐标轴旋转和平移后的能量、力协变、合力和合矩相对残差均 <=1e-10。
4. **DIRECTION**：心肌比较长轴 x 与横向 y；心内膜比较面内 x 与厚度 z。采用等体积 1% 和 5% 仿射应变；所有储能和共轭恢复反力为正，5% 储能高于 1%，并报告 5% 两方向刚度比。只把该比解释为参考几何的结构响应，不声称材料模量已各向异性标定。
5. **UNLOAD**：从 5% 形变移除外载后，以明确标注的算法性过阻尼线搜索最小化 E_ref；能量逐步不增，最终 RMS 相对边应变 <=1e-6，主轴长度相对参考误差 <=1e-4，最终归一化能量 <=1e-10。迭代坐标不是物理时间。
6. **REFINE**：三档网格的 5% 归一化储能按参考面积归一；medium 到 fine 的方向刚度变化 <=5%。
7. **FAIL-CLOSED**：聚焦内核测试必须覆盖缺失参考态和拓扑变化错误；默认 reference_shape_modulus=0 不改变旧路径。

任一必需门失败则本子阶段为 FAIL_NUMERICAL；依赖、定义或运行缺失分别用 BLOCKED_DEPENDENCY、BLOCKED_SPEC 或 NOT_RUN。通过只可记为 PASS_REFERENCE_STATE，父 Z1 仍需结合弯曲/面积处置与 Z1-C 接触裁决。
