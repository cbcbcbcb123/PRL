# M1 多周期极限环记录 v01

## 1. 阶段结论

无外载单细胞模型的周期极限环门通过。

20步/周期的6周期探索和40步/周期的5周期正式复核均在第4周期满足“连续两次相邻周期转移通过”的预设条件。40步正式计算中，第4周期与第3周期的整周期缩短波形最大差为 `3.19e-9`，周期末全节点加权状态差为 `5.96e-9`；第5周期波形差进一步降至 `1.84e-9`。

因此，周期末约1.3663%的非零缩短是连续周期激活下稳定极限环在零激活相位处的状态，不是逐周期累积的塑性变形或数值漂移。

## 7. 科学边界

本阶段已经证明：

- 当前无外载单细胞模型存在稳定的周期吸引子；
- 首周期之后没有逐周期形态漂移；
- 稳定周期的峰值、相位、零相位缩短和能量滞回可重复；
- 1.3663%周期端点缩短不是塑性残余。

本阶段尚未证明：

- 真实心肌细胞必然有相同的周期端点缩短；
- 模型阻尼和周期已经完成实验标定；
- 加入ECM、心胶或外部负载后仍有相同极限环；
- 正弦式激活足以描述真实钙瞬变和主动张力波形。
