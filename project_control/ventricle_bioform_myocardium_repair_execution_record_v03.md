# Z1-BIOFORM-MYO-R v03 心肌自由态数值资格修复执行记录

## 裁决

依照冻结的[修复合同](ventricle_bioform_myocardium_repair_contract_v03.md)和[授权记录](ventricle_bioform_myocardium_repair_authorization_v03.md)，create-only 正式结果包已完成 8/8 个 CPU 工况，独立验证的失败门数为 0。阶段裁决为 **`passed_synthetic_mechanism`**。

该 PASS 只覆盖“单个自由闭合心肌 DCM 在合成无量纲参数下，由方向性细胞骨架法向牵引形成稳定长轴、横轴和厚度轴分离”的机制资格。生物学验证仍为 **`blocked_data`**，父 Z1 仍为 **`blocked`**；心内膜、ECM、三层组织、周期收缩、物理时间、CFD 和 FSI 均未由本阶段执行或验证。

## 修复内容与因果边界

[v03 诊断](ventricle_bioform_myocardium_repair_diagnosis_v03.md)把 v02 的失败分成两个实现问题：当前 SimuCell3D 离散弯曲力在本阶段网格上不能保持平移/转动不变性，产生非零被动合力和合矩并驱动长程漂移；旧的逐节点等量主动合力/合矩修正在面积加权阻尼下又会加入非刚体切向速度，使扰动轨迹分叉。

本阶段没有放宽门限，也没有恢复目标末态或参考形状能。生产实现采取：

- 将未通过刚体不变性诊断的旧弯曲项隔离为 `k_b=0`；曲率继续计算和映射。这里不主张真实细胞弯曲刚度为零，弯曲核心仍待单独修复；
- 保留原始无迹方向性骨架张量 `s[p⊗p - 0.15q⊗q - 0.85r⊗r]` 的法向形状牵引；
- 对总面积加权过阻尼速度仅投影掉 3 个整体平移和 3 个整体转动，不做逐节点形状修正；
- 以当前最短边的 10% 限制单子步最大节点位移，必要时自适应细分；
- 继续使用体积压力、标量总面积弹性和各向同性皮质张力；逐边参考形状、逐面参考度量和目标几何均保持关闭。
