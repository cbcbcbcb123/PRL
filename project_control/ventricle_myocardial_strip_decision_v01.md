# 五细胞心肌条带桥接阶段决定 v01

- 决定日期：2026-09-13
- 状态：`adopted_for_execution`
- 阶段标识：`Z1-MYO-STRIP-L5-A`
- 用户输入：先建立一个心肌层，将 4–5 个心肌细胞并列并施加边界条件，观察是否与实验现象吻合。

## 对“并列”的执行解释

本阶段将五个心肌细胞沿其长轴 `p` 首尾串联成一条单细胞厚条带，而不是把五个细胞各自独立夹持后平行摆放。这样中心细胞产生的主动张力必须跨越四个细胞间界面才能到达外侧夹持端，能够直接检验细胞间力传递。

## 本阶段采用的模型

1. 每个细胞的初始网格来自冻结的 `Z1-BIOFORM-MYO-R v03` 自由态终态；初始几何不是后续求解中的目标形状。
2. 五个细胞均保留 v03 的主动形态维持应力，且不启用参考边长、参考面度量或目标终态几何。
3. 相邻细胞之间建立固定材料点对黏附弹簧；本阶段不允许链接生成、断裂或重配对。
4. 最左与最右细胞的外侧有限面积端帽夹持；条带侧面自由。
5. 细胞内部用成对、等大反向的长轴收缩单元表示粗粒化肌节/细胞骨架收缩，目标长度随数值激活相位变化。
6. 采用 CPU 单线程、过阻尼、准静态一个激活循环；相位不是生理时间。

## 证据边界

- 可判定：几何稳定性、体积误差、网格质量、端部反力、界面力平衡、中心细胞到边界的力传递、不同数值相位的形态和场量。
- 只做定性文献一致性：长轴排列、等长夹持下随激活增加的反力、细胞连接介导的力传递。
- 不可判定：真实力值、真实频率、鱼胚具体发育时刻、材料参数反演、完整心室壁或心内膜耦合。
- 因缺少登记的同一实验体系边界轮廓与力学时序数据，实验定量验证保持 `blocked_data`。

## 与既有路线的关系

本阶段是单细胞自由态与完整双层/三层组织之间的独立桥接阶段，不等同于原 v03 方案中的 Z4。即使本阶段通过，也不自动解除父级 Z1 阻断，不授权心内膜、ECM、完整心室层或 GPU 运行。
