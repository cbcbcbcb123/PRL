# Node 1–3 单篇 Nature Physics 主论文决策 v01

## Decision

Node 1、Node 2、Node 3 共同构成一篇固定发育时期快速心搏力学主论文，目标期刊为 `Nature Physics`。三者不是三篇独立论文，也不是可以相互替换的工程阶段。

统一论文证据链为：

1. **Node 1：单细胞物理内核。** 建立主动细胞—黏弹性 cardiac jelly 的无量纲传力、记忆和耗散规律；
2. **Node 2：集体涌现。** 证明单细胞规律如何在心肌细胞层中因细胞—细胞连接、激活相干性和空间尺度竞争而改变；
3. **Node 3：跨层功能。** 证明 cardiac jelly 如何把心肌层的时空激活转换为心内膜位移、层间距重排和折叠状态。

## Consequences

- 每个 Node 均须完成物理对照、数值收敛、参数/几何敏感性、替代理论或反事实检查和可验证预测；不能因后续 Node 更接近在体而降低前一 Node 的证据要求。
- 单细胞、细胞层和三层结构必须共享一套守恒/功率账本、无量纲参数、材料定义和证据边界。
- Node 1 的结果必须成为 Node 2 的可预测基线；Node 2 的结果必须成为 Node 3 的输入或对照。若后续节点只增加几何复杂度而没有产生新的物理规律，论文路线不通过。
- EFE 只作为潜在扰动场景或生物学意义，不自动成为主张；除非有独立疾病数据或实验验证，否则不得把正常三层力学直接解释为 EFE 机制。
- 慢发育生长、ECM 分泌和重塑继续留在本论文范围外；不因三节点合并而混入第二时间尺度。

## Publication gate

只有 Node 1–3 的共享物理主张、统一相图、数值证据链和至少一个实验/影像可证伪验证均成立后，才启动正式投稿图和稿件写作。工程完成或单个阶段图通过不等于达到投稿条件。
