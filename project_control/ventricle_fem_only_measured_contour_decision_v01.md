# FEM唯一主线与真实外轮廓试算

用户最新决定：本项目前向建模只采用FEM，所有DCM运行、恢复、扩展和DCM--FEM比较均退出活动路线。既有DCM文件和结果仅为历史证据；本决定不授权删除它们。外部专家原件保持原样，其DCM内核及顺序条款不再约束当前FEM路线。

逐细胞实例分割资格保留在原证据等级，暂停为可选后续数据接口。它不再阻断真实组织外轮廓的FEM试算。上一建议将DCM重新列入下一步的内容撤回。

本次采纳一个有界FEM切片：用已验收的72 hpf Fish 4组织填充mask提取一个真实二维截面外轮廓，将既有F0/F1-S三层连续体材料和主动收缩移植到该轮廓。只把外轮廓标为图像来源；内腔、层界、材料、激活和零牵引负载为构造/合成假设。精确逐细胞分割不作为前置。

见[本次合同](ventricle_fem_measured_contour_contract_v01.md)。通过仅支持实测轮廓上的FEM工程可行性，真实三维跳动和生物验证仍需另外的证据。
