# NCS-M0：方法定位、能力审计与 M1 规格

## 1. 目标与交付物

用最少工作回答：拟建方法解决什么尚未被可靠解决的问题？目前仓库有哪些可用资产？第一个全 FEM 基准怎样独立判定正确？本阶段只读审查源码/已有证据，允许推导和项目内文档，不启动求解器、Docker、安装或计算测试。文献查找限公开资料，不上传本地未公开材料、不接入新服务。

收到执行指令后，在 `project_control/ncs_m0_report_v01.md` 形成下列内容，并在 `project_control/ncs_m1_frozen_spec_v01.md` 冻结下一阶段规格。路径存在时先读并新建版本，不覆盖既有报告。只需两份连贯文档及必要附件，不建立新管理平台。

| 工作 | 必须回答的内容 | 验收证据 |
|---|---|---|
| A 仓库基线 | 当前分支/HEAD/dirty；现有 FEM、SLS、网格、主动应变、线性代数、DCM、FSI 资产到底可用到哪一步 | 文件与关键行号/哈希、既有结果的覆盖范围；区分实现存在与数值验证 |
| B 方法近邻 | 至少覆盖显式细胞组织模型、细胞–流体模型、通用分区耦合、守恒重映射/事件转移四类 | 每类至少一个最相关原始来源；可合并重叠，不堆文献数量 |
| C 可证伪缺口 | 候选方案在哪一类事件/网格变化中比强基线更有价值 | 明确基线、测量量、反例、无优势时如何收缩主张 |
| D 数学闭合 | 力/功/物质/状态如何定义；M1 方程及参考解是否闭合 | 完整单位、符号、边界、主动功、SLS 储能/耗散与参考推导 |

## 2. 仓库审计的范围

遵循 AGENTS 阅读顺序。优先复用原主动 FEM、SLS 本构及线性代数；不用本阶段重构整个仓库。记录旧背景阻尼、离散链、边界和变量定义与新 M1 的差别。旧代码“数值通过”只在原覆盖范围有效。

旧 runner 的关键参考入口为 `scripts/run_paper2_lineage_odd_mode_gate_v01.py` 及 v03 实际执行记录引用的版本；若路径/哈希变化，按实际记录，不修正历史。此处不是重做旧门全审计，更不是运行该 runner。原用户 Figure2 合同仅核对保护哈希。

能力表字段固定为：能力、文件/函数、理论假设、已有验证、适用限制、可直接复用/需适配/缺失、状态。DCM 必须说明闭合细胞几何、身份与事件能力分别在哪里；被动链不能填作 DCM 已完成。FSI 必须核实是否真的求解流体守恒方程，腔体/压力载荷不自动等于 FSI。

## 3. 方法缺口与公平比较

逐个近邻记录：细胞表示、连续域、界面、拓扑事件、状态/历史转移、离散功率、物质收支、误差/成本基准、代码可用性。把“原文未报告”与“不具备能力”分开；原文未读记 UNKNOWN。

优先检验的假说：在同等细胞事件与状态信息下，候选事件一致转移降低非物理功/物质漂移，且该改善在局部场误差或所需计算成本上有实质价值。候选反例：成熟守恒投影或既有分区算法已经在相同事件上达到同等质量，新增方案没有优势。

M0 不需证明新算法已经成功；需要确认至少一个可执行、非稻草人的比较。若最强基线就足够，允许将项目收缩为可靠应用平台或寻找另一具体方法缺口，不能继续使用“新型守恒方法”的成果措辞。

## 4. M1 必须闭合的数学项

采用方案中二维小应变、准静态、规定主动应变、SLS ECM 的新基线。以下推导完成后才允许数值执行：

1. 列出三层本构、应力单位、出平面约束、界面与边界条件、初值、无量纲标度；不能混用平面应力和平面应变。
2. 从变分平衡推导主动功符号及储能—耗散收支，明确边界反力和周期宏观自由度的功。
3. 对均匀平面层推导复模量与串/并联关系；先组装 ECM 完整复刚度，再施加横向零应力消元。不同泊松比支路不能先独立约化再相加。
4. 明确 CN 的内变量离散、主动输入中点处理、能量检验的离散恒等式与参考时间误差的区别。
5. 圆环采用独立径向方程参考：推导 `dσ_rr/dr+(σ_rr−σ_θθ)/r=0`，包含主动环向应变产生的非齐次项，连续位移与径向牵引，内外自由边界。可以解析分段解或高精度独立一维解，后者须给自身误差界；不得把同一个二维组装算子当独立参考。
6. 定义每一个局部读出对应固定物理区域和分量；定义近零量绝对误差、非零量归一化和相位判定下限。

若准静态、零背景阻尼基准与旧生产代码的算子不兼容，允许新增小型独立基准适配层，不能悄悄保留背景阻尼后仍使用零阻尼参考。若环境缺少必要库，记录 BLOCKED，不自行安装。

## 5. 数据与模型扩展的早期约束

首个生物预测候选：给定全局心室运动或激活与少量校准参数，预测未参与校准的局部心内膜形变/应变；加入 FSI 后才预测血流/剪切。若全局运动作为边界输入，就不能把其重现当独立验证。优先个体/阶段留出，记录成像分辨率、分割误差和参数可辨识性。

尚无合适数据不妨碍 M1 数值基线，但阻塞生物验证主张。第二组织需独立数据与边界/材料语义；换成另一个椭圆不能称跨组织复用。ECM 源与疾病机制保持开放，M0 不估计未获证据支持的分泌定律。

## 6. 门禁与执行空间

| 条件 | 判定及后续 |
|---|---|
| 方法比较可执行，M1 数学/参考/阈值/环境/预算闭合 | M0 PASS；在后续任务已明确授权 M0+M1 时可直接进入 M1a |
| 数学基准闭合，但新意尚不能判断 | M0 方法定位 UNKNOWN；仅可进行定位清单中明确保留的 M1 基础验证，不称方法创新进展 |
| 参考、物理边界、能量公式或可运行环境缺失 | 对应依赖 BLOCKED；补文档/推导，不能先跑再补门 |
| 已有强基线解决目标问题且没有可信改进目标 | 方法主张 FAIL；交付反例与收缩建议，不自动扩建 DCM/FSI |

执行者可选择文献、组织报告、定位代码、推导参考、在不变更物理含义的前提下细化实现规格。允许修正方案中明确证明的代数笔误，须列原式、修正和证明；改变物理、本构、边界、验收阈值或主张必须单列变更，不能静默处理。

M0 收口报告必须包含“做了什么/未做什么、最强反例、下一唯一切片”。能力存在、文档完成、数值 PASS、方法优越及投稿水平分别列状态。同步驾驶舱，但不建立定时任务。
