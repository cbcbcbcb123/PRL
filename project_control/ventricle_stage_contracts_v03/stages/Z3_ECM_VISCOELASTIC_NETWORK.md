## 2. 单连接定义与解析检查

\[
E=\frac12 k_\infty x^2+\frac12k_1(x-z)^2,\quad
f=k_\infty x+k_1(x-z),\quad
\dot z=\frac{x-z}{\tau},\quad \eta=k_1\tau.
\]

独立合成例设 k∞=1、k1=2、τ=1，采用自洽无量纲尺度；x0=0.01。正伸长的反力 f 是维持该伸长所需外力；两端网络内力的方向与之相反，求和时保持作用反作用。

固定 x0、z(0)=0 时：

\[
z(t)=x_0(1-e^{-t/\tau}),\quad f(t)=x_0[k_\infty+k_1e^{-t/\tau}],\quad D=\int\eta\dot z^2dt\ge0.
\]

阶跃 t=0 的瞬间外功要明确计入；数值使用平滑斜坡时，不能再将上述理想阶跃全程视作精确解。可将阶跃后的已知状态作为初值，从 t=0+ 比较松弛。另做平滑加载用于全程能量账本。

正弦伸长的稳态复刚度为 `K*(ω)=k∞+k1 iωτ/(1+iωτ)`；实部 `k∞+k1(ωτ)^2/[1+(ωτ)^2]`，虚部 `k1ωτ/[1+(ωτ)^2]`。采用一致的 exp(iωt) 约定，比较幅值和相位。循环耗散按力—位移积分独立检查。

## 3. 法向/剪切网络的代表面积

取参考薄层厚度 t0 和面积 A_total。每条连接有明确 A_e 或求积权重，覆盖规则使同一材料不重复计数。目标法向与切向响应分别由 E_n、G 和 t0 标定，黏性支路采用同一代表面积/取向缩放。

首选由原有锚点映射建立法向和成对交叉连接。对相同均匀应变 ε，比较网络总能与目标薄层能；法向加载和两个独立方向剪切都需通过。斜连接同时贡献多个方向刚度，不能各自套 `E A/t0` 后宣称标定完成。

标定需要的微观参数可由线性方程/受约束拟合求出，但只用独立网络材料试验，不用后续心室目标流量。要求非负刚度/黏度及已声明材料对称性；无法同时拟合目标张量时说明网络拓扑限制，不用负弹簧掩盖。

锚点基于材料坐标/面内重心权重，不随当前最近节点任意跳动。相邻层刚体运动时连接几何随动；切向分量采用客观材料框架，不能投影到固定世界坐标后误产生恢复力。

## 7. 验收、故障定位与交接

单连接解析误差目标≤1% 且显示时间收敛；恢复 τ 的相对误差≤2%；整体/局部遵守 2%/5%；耗散非负、能量残差≤1%；客观性/反作用代数目标≤10^-10。密度细化后有效材料不随数量系统性增长。

剪切过硬先查交叉连接重复计数；整体旋转后有力先查局部框架和参考向量；τ 随密度变化先查 k1 与 η 的缩放；重启后突变先查 z/参考态未保存。没有三项法向/两剪切标定，不进入组织实验。

专属交付：`ecm_constitutive.md`、`anchor_and_area_weights`、`effective_modulus_calibration.csv`、单连接解析验证、网络参数与重启包。Z4 接收冻结的 E_n/G/τ 及从材料到离散连接的转换，不接收特定网格的任意弹簧列表作为材料定义。
