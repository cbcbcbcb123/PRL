## 1. 本阶段的限定问题

在给定实测壁运动、几何和边界负载后，CFD 能否解释对应血流及其不确定度？壁运动是输入，不评估主动 DCM 是否会产生该运动。没有足够动态壁数据时不合成全周期冒充测量。

## 2. 数据入场与实际读取

复用 Z0 清单但重新确认实际可读文件、哈希和版本。核对年龄、鱼/实验 ID、标记、体素大小、速度单位、相位参考、周期、有效视野与配准变换。元数据缺项保持 UNKNOWN，不凭论文示意或文件名补齐。

把原影像、分割腔面、处理速度与误差分别保存。腔面若由分割获得，记录方法/参数、人工修正和分割不确定度。分割光滑前后体积差、壁位移变化和最小特征尺寸必须可查。

只见两静态壁相位时允许检查两个几何及配准，动态 CFD 比较标 `BLOCKED_DATA`；两个几何之间的任意插值可作“假定运动敏感性探索”，但不在本阶段必需验证内、不称实测动态验证。

## 3. 壁运动与边界条件

动态壁面需连续几何对应或明确表面速度重建；不能仅用每相位体素分割编号当材料追踪。CFD 必需法向运动和无滑移全速度的来源分别写清；只有法向位移时，切向速度模型属于额外假设，必须列入敏感性。

使用固定端口和预登记的负载/入口信息。实测域可能只有部分心腔，截断边界不确定性不可忽略。不能一边根据流量反推边界，一边用相同流量做独立验证。记录观测用于几何/壁运动/负载校准/验证的具体角色。

壁重建的体积变化与可测进出流量先做数据层面的相容性检查。若不相容超过不确定度，不强行补液以让 CFD 满足两套矛盾数据；报告配准/分割/边界误差。

## 4. 观测算子 H

定义 `y_pred=H(u,wall)`：空间采样位置、PIV interrogation window 或有效平均核、光学/遮挡掩码、时间/相位平均、配准、速度分量和单位。先把模拟场投影到实验观测尺度，再计算误差。

PIV 窗口尺寸不一定等于真实点扩散函数或独立采样尺度，未知时使用明确简化 H 并做窗口/配准敏感性。不把密集插值位置当独立数据点。红细胞追踪作为速度代理时说明单相连续模型的尺度限制，不强解释近壁个别细胞轨迹。

配准位置变换 `x'=R x+t` 时向量 `u'=R u`（另有单位/时间尺度换算）；协方差 `C'=R C Rᵀ`。不确定度只有分量标准差时不要凭空构造独立完整协方差为事实，可在“对角近似”下比较并限定结论。

## 5. 校准/保留与误差统计

以鱼或独立实验条件划分；同鱼相位是相关观测，不是生物重复。只有一条鱼，明确个例/工况或时间外推。先冻结保留集和观测量，再校准可支持的最少边界参数，不在保留集上选模型/调光滑。

报告物理单位 RMSE/MAE、方向误差（仅非零速度可靠区）、局部/整体流量、覆盖率及带不确定度残差。可用 `rᵀ C^-1 r` 的标准化指标，但 C 的来源、秩/相关性及有效自由度须明确；不把它无条件当卡方检验。

数值误差、分割/配准误差、边界不确定度、测量噪声分别评估。实验通过阈值根据数据能力预登记，不套数值 2%/5% 门槛。没有可信不确定度时可报告误差，但不能宣称统计上验证。
