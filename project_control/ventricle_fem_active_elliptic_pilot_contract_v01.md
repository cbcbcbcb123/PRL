# 二维椭圆三层主动 FEM 首次可行性合同 v01

## 本轮问题与裁决边界

本轮只检验：在当前无需安装的新 Python/SciPy 环境中，能否用独立有限元装配得到一个数值稳定、可审计、随规定主动应变完成一个收缩—舒张周期的简化心室截面。该试验优先于当前 DCM R0-C，但不取消或改判任何 DCM 证据。

现有 Glasgow 舒张/收缩 GFP 栈缺少已确认的鱼龄、体素尺度、轴手性、共同鱼身份、跨相位配准和可靠心室分割，故只作为公开实验资料入口登记，不参与本轮几何或参数拟合。本轮通过不等于斑马鱼生物标定、实验吻合、三维心室、流固耦合或 FEM 优于 DCM。

## 模型与加载

- 二维平面应变、三层共形椭圆环：内侧心内膜、中间薄 ECM、外侧心肌；所有量为无量纲合成量。
- 内边界椭圆由单位圆在 x 方向放大 1.25 倍获得；归一化径向层界为 `1.00, 1.05, 1.10, 1.35`。
- 各层采用小应变各向同性线弹性：心内膜 `E=1.0, nu=0.30`，ECM `E=0.5, nu=0.30`，心肌 `E=2.5, nu=0.30`。
- 仅心肌施加沿局部椭圆切向的规定主动本征应变；激活为 `alpha(phi)=0.015[1-cos(2*pi*phi)]`，峰值 0.03，`phi` 是归一化算法周期相位，不是生理时间。
- 内外表面均无牵引、无腔压、无血流、无电生理；只用三个精确 KKT 约束去除整体 x/y 平移和刚体转动，不夹持心室。
- 该自由、无压模型只检验主动变形与层间传力。不得把其体积/面积变化解释为真实射血或压力—容积环。

## 离散、运行和资源

- `G0`：48 个周向区间，心内膜/ECM/心肌厚向区间为 2/2/4。
- `G1`：96 个周向区间，心内膜/ECM/心肌厚向区间为 4/4/8。
- 每级保存 41 个相位的节点位移、单元应变、应力、二维等效应力、面内压力和几何状态。
- 唯一正式调用；单线程 CPU、0 GPU、0 自动重跑、无网络、无安装、无项目外写入。
- create-only 结果目录：`results/ventricle_fem/f0_active_elliptic_pilot_v01_20260916`。
- 本阶段最大新增 64 MiB，另保留 64 MiB 停止空间；项目总量继续低于 3 GiB。

## 预注册工程门

1. 所有线性系统归一化后向残差不高于 `1e-10`，刚体约束残差不高于 `1e-10`。
2. 全周期所有三角形保持正面积且全部状态有限。
3. 全周期最大绝对应变不超过 0.05，维持小应变试验范围。
4. 峰值激活时 G1 腔面积相对初态至少缩小 0.5%，证明主动加载产生非零整体响应。
5. G0 与 G1 的峰值腔面积相对变化绝对差不超过 `2e-3`。
6. 独立验证器从保存坐标和位移重算单元应变、腔面积及翻转状态；不得只读取求解器 `passed` 字段。

任一门失败，状态为 `failed`，保留失败结果，不更改门限、不自动重跑。
