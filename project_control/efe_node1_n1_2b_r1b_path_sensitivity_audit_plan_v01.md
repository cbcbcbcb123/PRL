# EFE Node 1 N1-2b-r1b 冷/热路径敏感性审计计划 v01

## Goal

在不改变模型、离散、门限和失败步工况的前提下，区分三类可能来源：

1. FEniCSx ECM 能量/力装配对后端历史状态有依赖；
2. 同一输入下机械/固定点求解本身不可重复；
3. 求解器可重复，但极小的历史路径差异被非线性全局化放大并进入不同轨迹。

## Inputs

- 周期 3 `accepted_step_003.npz`；
- 历史周期 runner 的 step 4、12 次失败轨迹；
- r1a 新 Picard 3 次通过轨迹；
- 历史周期 1 至周期 3 step 3 可恢复的接受态和耦合态；
- 固定 `dolfinx/dolfinx:v0.11.0` 环境。

历史优化器的每一次内部函数调用没有被原 runner 逐项封存，因此不能逐调用
重建完整历史。r1b 将按时间顺序重放全部可恢复状态，并确保预热终态与周期 3
step 3 完全相同；该限制必须进入最终证据边界。

## Outputs

1. 后端纯度审计：同一 ECM 几何和 `Z` 在冷后端、历史预热后端及重复调用下
   的能量、力、`J` 和切线对照；
2. 同一失败步的 3 个冷 Picard 与 3 个历史预热 Picard 完整复演；
3. 各组逐轮输入、捕获输出、稀疏输出、`r_Z`、KKT 和终态的成对差；
4. 历史失败与新复演间的局部差异放大诊断；
5. 派生 JSON、阶段诊断图、执行报告和下一人类终审请求。

## Implementation Steps

1. 新增可测试的对称相对差、最大绝对差、稀疏切线差及重复性汇总工具；
2. 新增 r1b 审计 runner，按冻结顺序读取可恢复历史状态并预热同一 FEniCSx
   后端；预热不得改变失败步初始变量、`Z` 或接触乘子；
3. 在冷后端和预热后端上，对同一关键状态分别执行至少 3 次能量/力/`J`
   装配，并比较切线；
4. 使用未松弛 Picard，分别执行 3 个独立冷复演和 3 个独立预热复演；每次
   从同一 step 3 文件加载，沿用 r1a 的捕获、稀疏及第 8/12 轮回退安排；
5. 比较组内重复性、冷/热组间差异以及相对历史失败轨迹的放大倍数；
6. 生成诊断图并提交人类终审，不自动采用任何恢复策略。

## Impacted Files Or Modules

- 新增 r1b 后端纯度/路径复演脚本及绘图脚本；
- 必要时仅把 r1a 单步 runner 的“历史预热”做成显式参数；
- 新增对应纯 Python 比较工具测试；
- `project_control` 中的授权、计划、执行和终审记录。

## Test Plan

- 比较工具的零差、尺度不变性、非有限输入和稀疏矩阵差测试；
- 审计清单能完整识别且只读取目标时间之前的冻结状态；
- 预热前后传给失败步的变量、`Z`、接触乘子逐元素相同；
- 相关 pytest 与 Ruff 通过；
- 六条复演均形成根级摘要和逐轮 NPZ/JSON；
- PNG/SVG 非空，PNG 人工视觉核验。

## Risks

- 原执行没有保存每个优化器内部评价点，只能审计“全部可恢复状态历史”，
  不能严格复现逐调用级热历史；
- 非线性 L-BFGS/Krylov 对极小输入差可能高度敏感，但敏感性不等于后端错误；
- 六次复演可能全部通过，此时结果仍有价值：它会把 blocker 收窄到历史进程
  特有路径，而不能证明完整周期已稳定。

## Acceptance Criteria

审计完整性：

- 冷路径和历史预热路径各 `n>=3`；
- 所有失败步初始数组逐元素相同；
- 所有运行保持原 Picard 固定点、12 次上限和硬门。

后端纯度候选门：

- 同一输入的总能量绝对差 `<=1e-12`；
- 力、`J` 和稀疏切线的对称相对差 `<=1e-12`；
- 三次重复均为有限值。

路径可重复性候选门：

- 组内终态变量与完整 `Z` 对称相对差 `<=1e-10`；
- 逐轮分支、通过轮次、`r_Z` 和 KKT 一致到记录精度；
- 冷/热组间若超过门，必须定位首个出现差异的层级；若不超过门，必须把
  历史失败保留为未复现的路径特有负结果。

无论结果是否通过，不得放宽门或追加未批准工况。
