# F6-S1-R：同几何 P2/CG1 与 P2/DG2 压力空间对照

原混合能量 mu/2*(J^(-2/3)*I1-3)+p_m*(J-1)-p_m^2/(2*kappa) 保持不变。
仅为新配置显式启用逐单元不连续二次压力 DG2；旧默认 CG1 路径保持。
仿射三角形、P2 位移和平面应变下 J 是单元内二次多项式，因此 DG2 能表示 J-1。
这不意味着 P2/DG2 在严格不可压极限 inf-sup 稳定，也不排除大 kappa 下体积锁死。
有限 kappa=1000 的本轮只检验局部约束和响应，不能直接推广到三维四面体
（三维 P2 位移的 J 一般是三次）或直接定为永久方案。

## 冻结范围

- 一次正式容器，最多四次新平衡：理想圆环 M0（64段、径向1/1/5，896单元）
  的 p/mu=0、0.02；均通过后，原轮廓 candidate_0（3541单元）的同两态。
- 原 CG1 对照仅读取 F6-S0 与 F6-S1-P 已保存状态，不重算；不补细网格、不加压、不主动。
- 轮廓网格哈希 157265c350367a95f36c40c5951117272ceeccac9f273ec65e5000eb81627f65；
  直接加载，不调用 Gmsh、不平滑边界、不改源几何/层界/固定点。
- mu=1、kappa=1000、六阶积分、平面应变、A固定ux/uy和B固定uy、内壁随动压力、
  外壁自由及原 Newton 设置完全相同。
- 所有原逐态门保持，包括 max|J-1|<=1%、独立 F/J/应力/力平衡、反力及压力虚功。
  新增压力局部基函数坐标/不共享自由度检查；DG2 点值约束 max|J-1-p_m/kappa|<=1e-9。
- 圆环非零载另要求与不可压解析参照的腔面积变化相对差<=5%（参照不是有限kappa精确解），
  并与旧同网格 CG1 的腔面积变化相对差<=5%。失败即停止后续工况。
- 轮廓与旧失败解的面积/位移差只报告，不要求追随失败解；仅一个新网格级别不能证明收敛。
