# 心室模型细胞几何与多细胞成形策略决定 v03

## 1. 用户决定

用户确认采用“单细胞本构基准 + 多细胞拥挤/接触 + 组织边界”的分层路线，并要求更新方案后继续 Z1。该决定不改写 `plan/active/` 中的外部专家原件，也不把既有 Z1 失败包提升为通过。

## 2. 更新后的几何逻辑

实验中的细胞形态被拆成两个来源，必须分别验证：

1. **细胞自身参考态与各向异性**：决定解除外部限制后细胞趋向球形、长轴形还是扁平形；
2. **组织环境成形**：细胞间排斥、黏附、共享/受控界面、拥挤和曲面边界进一步产生多边形铺砌、局部扁平化和区域差异。

只有体积、各向同性表面张力和排斥接触时，孤立细胞仍趋向球形；拥挤可以形成接触面，但不能单独定义稳定的心肌长轴、心内膜厚度或层间拓扑。

## 3. Z1 子门

### Z1-A｜球形数值基准

- 对象：闭合球形 `muse_dcm` 网格；
- 只启用体积保守力与恒表面张力，弯曲、全局面积弹性、主动、黏附和 ECM 关闭；
- 验证独立工作共轭能量、方向导数、刚体客观性、合力/合矩、Laplace 压差与网格趋势；
- 可独立裁决，但通过只覆盖该各向同性力路径。

### Z1-B｜孤立各向异性参考态

- 心肌：有材料长轴的圆角杆/椭球探针；
- 心内膜：有材料法向和首选厚度的扁平探针；
- 必须验证无载保持、轴向/横向或面内/厚度响应，以及卸载恢复；
- 2026-09-11 已在唯一内核加入显式捕获的表面参考度量；3:1:1 长轴和 4:4:1 扁平合成探针完成无载、方向响应和卸载恢复验证，参考态子门为 `PASS_REFERENCE_STATE`；
- 当前通过的是非球形参考几何的结构响应，参考材料模量仍为各向同性；真实参数、重网格/分裂参考态转移及独立纤维各向异性尚未验证。

### Z1-C｜受控双细胞接触

- 保留端对端、侧对侧、边对边和面对面路径；
- 必须在 Z1-B 参考态成立后重跑加载—分离、穿透和作用—反作用账本；
- 既有 v01 静态接触探针仅作为历史预检。
- 2026-09-11 已按单独授权完成球形对照及四种非球形方向的规定矩阵；作用—反作用、ID 交换、可逆性、体积和压力门通过，但工作共轭与网格细化门失败，Z1-C 裁决为 `FAIL_NUMERICAL`；
- 独立诊断将工作共轭失败定位到当前面片面积随形变变化却未进入接触力变分，将细化失败定位到当前 node–face 采样/接触面积离散；在这两个门修复并按原阈值重跑前，不得进入多细胞桥接。

## 4. 多细胞拥挤桥接门

在 Z1-B/Z1-C 通过后、正式 Z4 双层组织前，增加一个单独授权的 `Z1-MULTICELL-BRIDGE`：

- 约 7–20 个固定细胞数的被动小群体；
- 逐渐施加封闭边界或曲面限制，再卸载边界；
- 对比“只有拥挤”与“拥挤 + 各向异性参考态”；
- 输出接触网络、细胞压力/体积、长宽厚分布、穿透和卸载后形态。

该桥接门不能替代 Z4 的心肌—心内膜连续双层、共享腔面和区域纤维方向，也不占用既有 Z2（主动单细胞）或 Z3（ECM）编号。

## 5. 几何先验与证据边界

- `1:1:1` 球形继续承担 Laplace 解析基准；
- 既有 `3:1:1` 心肌与 `4:4:1` 心内膜只保留为合成算法探针，不作为真实生理比例；
- 成年分离斑马鱼心室肌细胞可非常细长，而胚胎原位心肌具有曲率区域差异；两者不得混合标定；
- 原位心内膜应优先表示为顺应腔面的薄多边形连续层，而不是相互穿透的独立扁球。

## 6. 当前授权边界

Z1-A、Z1-B 参考态与 Z1-C 受控接触授权均已消费。Z1-C 当前为 `FAIL_NUMERICAL`。当前不授权修改 `E:\MeshCell3D\code\muse_dcm` 接触内核，不授权执行修复后的重跑、Z1-MULTICELL-BRIDGE、Z2/Z4、启动 GPU、安装软件、提交推送或外部发布；下一步须先另行确认接触离散修复合同。
