# PRL 大型公开数据外置存储决定 v01

## 决定

用户明确允许今后把与项目有关的大型公开数据包分类下载到 `E:\Data`。该授权解决“项目工作区外不得新建文件或目录”的默认限制，但只覆盖公开科研数据及其必要来源元数据，不扩展到软件安装包、虚拟盘、网络驱动器、持久服务、GPU 任务或其他外部路径。

推荐稳定布局为：

```text
E:\Data\<project>\public\<provider>\<stable_record_id>\
```

本轮斑马鱼心肌形态数据使用：

```text
E:\Data\PRL\public\zenodo\15509350\
```

## 仓内与仓外职责

- `E:\Data` 保存上游原始压缩包、必要的同源代码快照和后续经资格审查的解包数据。
- PRL 工作区只保存来源、许可、版本、稳定标识、远端与本地哈希、字节数、文件清单、资格结论、派生小数据和可复算脚本；不复制大型原始包。
- PRL 工作区的 `2.4 GiB` 预警和 `3 GiB` 硬上限继续有效。外置数据不计入工作区体量，但每次获取仍须检查目标盘可用空间、冻结最大新增量，并在项目记录中登记。
- 上游压缩包未通过哈希前不得标为取得；公开可下载不自动等于适合标定或验证。
- 下载来的代码默认只做静态审计，不自动执行。风险反序列化格式优先安全读取。
- 不同论文、鱼、阶段、成像条件或坐标系的数据不得静默拼接为同一实验对象。

## 安全与清理

- 本决定授权在 `E:\Data` 下为相关公开数据新建分类目录和文件，不授权在其他项目外路径写入。
- 不授权删除、覆盖已有数据或清理下载失败的残片。任何删除仍须按 `AGENTS.md` 提交精确清单并重新确认。
- 同名目标已存在时先核对大小和哈希；仅使用可续传方式继续同一上游文件，不用新文件覆盖来源不明的既有内容。
- 解包前先列出归档成员、路径和预计展开体量，防止路径穿越与无界膨胀；只提取任务需要的子集。
