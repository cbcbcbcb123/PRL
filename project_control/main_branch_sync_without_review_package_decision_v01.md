# 默认只同步，不另做评审包

用户原话：“每次与远端同步默认不需要有评审包，仅仅是同步就行”。

- 阶段工作完成并经必要检查后，仍直接提交main、普通推送origin/main、回读核验；无需逐次请示。
- 默认同步本阶段正常代码、导航和必要验证记录，不为同步额外建立评审包、docs/review新目录、ZIP或桌面副本。
- 只有用户明确要求专家评审、打包或指定交付时才另外制作。此决定不取消真实结构/结果图和科学验证；图件及大结果按既有存储规则保留。
- 不删除、回滚或改写已经存在的评审资料，不补推本次尚未发布的评审目录。
- 本次澄清前已生成的`docs/review/mixed_cube_controls_v01_20260919/`保留本地、从暂存区撤出、不纳入此次推送；没有删除文件。
- 替代`main_branch_stage_push_decision_v01.md`中“默认另建最新在线审阅包”的要求；其余唯一main、非强制推送、限定路径及不上传大型原始数组的规则不变。
