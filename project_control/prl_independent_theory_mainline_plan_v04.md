# Paper 2 v04：先判断科学主线，再完善模型与工程

## 1. 目标、授权与科学边界

人类已明确要求实施本计划。总管可下发、验收并衔接本轮边界明确的工作，不再逐工况请求批准。
本计划取代旧主线中“完整 Figure 2 认证后才可探索”的执行顺序，不降低或修改正式 Figure 2 的验收标准。
旧合同、失败包、已封存证据保持原样；旧 PRECHECK-only、C1-only 禁令不再约束本轮独立探索。

中心问题：心肌驱动经过有限厚度的黏弹 ECM 后，整体收缩与心内膜局部机械负荷何时一致、何时分离，能否用简洁理论预测？
目标期刊固定为 Nature Physics，不自动以降档为出口；目标不等于成熟度或录用判断。
阴性结果、反例或无新意结论均为有效交付，用来修订科学假设而不是包装阳性。

- 心肌只有主动 FEM，目前为规定主动应变，不是完整主动张力调控；不恢复心肌 DCM 或 comparator。
- ECM 为黏弹 FEM，心内膜为离散弹性链；不声称真实细胞形变、重排、纤维化或疾病发生已可预测。
- 当前仅二维理想体、线性三层力学；器官方向为心室/EFE，旧主线的整心房表述不再有效。
- 不加入流体、真实三维几何、新生物反馈或非线性；不从线性响应声称分岔、不可逆重塑或相变。
- 先排除经典黏弹滤波、平均与非线性观测量运算造成的平凡差异；粗粒化和传递是否不对易必须定义算子再检验。

## 3. 首轮执行设计（最多 30 个工况）

先推导可区别的预测与明确反例，同时允许数值 agent 准备 runner 并开展非留出基础计算。
两工作日是工作预算，不承诺阳性结果。默认每次最多 1 CPU、8 GiB，无 GPU，串行计算；累计计算墙钟超过 7200 秒先停止并由总管重估，不自动扩额。
使用已验证本地 FEniCSx 镜像和运行方式；工作代码只读挂载，仅本轮输出目录可写，容器缓存放内存临时区；不拉取新镜像、不联网、不挂载 Docker socket。

固定 L、T、h_m/L、材料比、泊松比、界面刚度、支撑、阻尼、激活幅值及空间对比度。
De=τ/T，只改变 τ；H=h_e/L，只改变 h_e。不是扫描频率，不能据此声称完整频谱规律。

| 时间复核 | 相同三个点，S1；S2、T256 | 3 |

留出不得提前计算、读取或用于调整解释。理论 agent 先将预测写入简报并通知总管；总管在首次留出前记录该简报摘要值，随后明确释放这 4 个工况。
若先发现明确无新意或数值失败，可提前停止；30 为上限，不是必须凑满。重试消耗计入总预算，不建立额外扫描轴。

观测量：整体短缩、局部心内膜应变和两界面牵引的时间基频幅值/相位与空间分布、循环主动输入功、ECM 黏弹与其他耗散及其分配。
报告原始输入功；相同平均激活不冒充相同输入功。派生比值必须说明分母；近零幅值相位标为不可解释，不伪造为零。
每工况保存实际参数、观测量、结构检查、运行耗时及代码版本。保存重算所需数组；不把大数组加入 Git。

## 4. 验证、失败与科学裁决

保留现有残差、功率闭合、作用反作用及非负耗散检查；不放宽阈值制造通过。
零驱动检查零响应；半幅驱动应为状态/牵引幅值 1/2、功与耗散 1/4，在既有残差和浮点误差范围内比较。
三个代表点的幅值相对变化 ≤5%、相位差 ≤5°，仅为探索性分辨率标准，不替代正式数值认证。
近零量使用有单位的绝对量和误差，不计算失真比值。候选效应必须与实测数值误差并列；低于或接近误差的不作为机制证据。
快/慢松弛、薄层、均匀场的理论极限需说明固定量与 DC/周期分量的区别。

- 继续：明确预测经数值及留出支持，且不能仅由经典滤波或平均运算解释；总管再下发有限稳健性验证。
- 收缩：结果可靠但只是已知规律的应用；收缩的是当前科学主张，不自动降低目标期刊。
  保留结果，转向与研究目标一致、具有可区分预测的最小新假设，不靠堆复杂度抬高定位。
- 暂停该主张：效应随分辨率消失、对照不公平或被理论否定；保留失败，解释原因，不自动加流体/非线性。

独立核查以重推关键关系、极限和观测量解释为重点，不将工程检查数量视为科学进展。
