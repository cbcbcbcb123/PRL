# Z1-C 接触离散修复合同 v03：共同参考接触代理面

## 前两版诊断结论

- v01 参考顶点面积消除了面积变分缺项和重复面计数，但 4/5 各向异性方向未过
  `medium→fine <=5%`；
- v02 参考面求积降低积分误差不是唯一来源；PN 弦高修正改善了部分方向，但长轴
  端部和扁平细胞边缘仍对力学网格方向敏感；
- 原因是 320 面和 1280 面力学网格同时承担接触几何离散，窄接触区在高曲率
  端部由不同数量、不同方向的弦面表示。继续增加单个弦面内的求积点不能消除
  这类几何误差。

## 冻结修复

增加显式 `symmetric_reference_quadric_proxy` 模式：

1. 捕获参考态时，除边长/双对偶面积外，保存参考节点坐标，并拟合
   `x^T Q x = 1` 的正定椭球；拟合不满足严格残差或正定条件时不建立代理面；
2. 接触几何统一采用固定 1280 面单位二十面体球，经参考椭球矩阵变换得到的共同
   代理面，不再随力学网格 80/320/1280 面改变；
3. 每个代理节点由参考力学节点的仿射完备线性权重重建，要求参考位置重建误差
   `<=1e-12 m`；当前代理位置始终由同一权重映射当前节点；
4. 接触势按固定参考代理顶点双对偶面积积分，双向 surface→surface 各乘 `1/2`，
   每个源代理顶点对每个目标细胞只选一个最近目标代理面；参考顶点求积确保高曲率
   长轴端点和扁平边缘进入已规定的排斥区；
5. 接触力按源映射权重和目标最近点重心权重回传到力学节点。由于位置映射线性、
   面积固定，节点力必须与独立重建势能严格功共轭；
6. 黏附与排斥表型缩放均采用两侧几何平均；
7. 未捕获参考态、非椭球参考态、拓扑改变、非正定拟合或映射误差超限均在任何
   力或接触诊断改变前失败关闭；不得静默退回弦面接触。


该模式当前只验证球形、长轴椭球和扁平椭球参考细胞，不授权推广到任意非椭球、
重塑后非仿射表面或组织级接触。既有 `legacy_target_face_all` 仍为默认兼容路径。

## 工程门与科学门

- 聚焦新模式测试必须全部通过：缺失参考态、独立能量—力、ID 交换、逐对平衡、
  唯一最近面、五方向完整路径峰值 `medium→fine <=5%`；
- 既有 spring 接触与参考态力学测试必须保持通过；
- 通过后才允许按 Z1-C v06 的全部原阈值重跑。阈值、工况、五个方向和三档力学
  网格不变；任一门失败仍为 `FAIL_NUMERICAL`；
- 保存 11 个加载/卸载路径点；`lambda` 仍是路径参数，不称为真实时间。
