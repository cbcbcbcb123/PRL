# T1.2 ECM 面积、厚度与网格密度解耦执行记录 v01

## 执行范围

本阶段在相同细胞、相同单侧接触区域、相同 52 个界面 tether、相同材料参数与峰值激活 `0.20` 下，比较：

- `B0`：基准 ECM，面积比 `1.0`，厚度 `0.30`，`480` 个四面体；
- `A15`：ECM 面内线尺度 `1.5x`、面积 `2.25x`，厚度不变，`1008` 个四面体；
- `T15`：ECM 厚度 `1.5x`，面内面积不变，`720` 个四面体；
- `M15`：几何完全不变，仅网格加密至 `1512` 个四面体。

所有新工况均完成三个激活水平的固定拓扑三维 DCM–FEM 联合平衡求解，KKT 残差约为 `3.3e-6–4.1e-6`，ECM Jacobian 保持为正。

## 相对 B0 的几何效应

### A15：扩大 ECM 外延面积

- 最大 ECM 位移降低 `44.53%`；
- ECM 总储能降低 `32.39%`；
- 体积平均能量密度降低 `69.95%`；
- von Mises 应力 p95 降低 `39.83%`；
- 细胞缩短仅变化 `-0.00034` 个百分点；
- 曲率绝对值增加约 `5.83%`。

解释：在细胞—ECM 实际接触面积不变时，扩大 ECM 外延区域提供了更大的连续介质载荷扩散通道。局部位移、能量密度和应力明显降低，但全局细胞缩短基本不变。本方向与纯网格加密效应相比幅值更大，可作为稳健的几何敏感性结论。

### T15：增加 ECM 厚度

- 最大 ECM 位移增加 `12.77%`；
- ECM 总储能增加 `9.52%`；
- 体积平均能量密度降低 `26.99%`；
- von Mises 应力 p95 降低 `5.31%`；
- 细胞缩短增加 `0.00236` 个百分点；
- 曲率绝对值增加约 `3.05%`。

解释：远端固定边界被推远后，ECM 的可变形空间增大；同时承载体积增加，使总能量与单位体积能量不必同向变化。由于当前网格总储能门未通过，厚度引起的总能量和应力变化只视为趋势，不作定量收敛声明。

## 纯网格加密审计

`B0 → M15` 的五项预注册网格门结果为：

| 指标 | 观察差异 | 阈值 | 结论 |
|---|---:|---:|---|
| 缩短 | 0.00196 个百分点 | 0.10 个百分点 | 通过 |
| 曲率 | 1.60% | 5% | 通过 |
| ECM 总储能 | 11.33% | 10% | **未通过** |
| ECM 最大位移 | 2.76% | 10% | 通过 |
| VM 应力 p95 | 8.89% | 10% | 通过 |

因此本阶段总状态为 `completed_with_mesh_gate_failure`，不能声称所有 ECM 场量已经网格独立。失败是单项、边界性的，但必须保留；尤其不能把 T15 的 `+9.52%` 总储能解释为已证实的厚度效应。

## 当前可支持的科学陈述

1. 在本模型和单侧接触条件下，扩大 ECM 外延面积会显著摊薄局部变形、能量密度和应力，而细胞全局缩短几乎不变。
2. 增加 ECM 厚度倾向于提高可达到的位移并降低单位体积能量密度；总储能与应力幅值仍需更高一级网格确认。
3. 全局细胞缩短对本轮 ECM 几何改变不敏感，局部 ECM 场与曲率比缩短更敏感。
4. 当前结果是固定发育阶段、准静态峰值激活的三维模型敏感性分析，不代表动态黏弹性心搏，也不代表已完成实验标定。
