## 为什么这个诊断有区分力

在相同精确形变F*下构造B*[q,v]=∫q cof(F*):Grad(v)。将精确压力的节点虚功向量f_p
拟合到P1压力能产生的力空间：z=f_p−B*ᵀc。结果B*z≈0，但f_p·z=||z||²>0。
这给出一个明确的虚位移方向：离散压力对它不做功，精确压力载荷却做功。
此证书是固定解析几何与积分下的线性代数诊断，不是新的平衡解、连续Helmholtz分解或稳定性定理。

解析体力/牵引与应力虚功一致，高阶6/8点积分结果一致；42项针对性检查通过。
相关压力鲁棒性思想见[Linke等的Stokes工作](https://arxiv.org/abs/1609.03701)，仅作类比，不直接外推固体定理。
