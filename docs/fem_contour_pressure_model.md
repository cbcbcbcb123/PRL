# F5图像来源外轮廓的被动有限变形模型

## 这个阶段回答什么

F5只回答：已经通过圆柱基准的曲线Q2/Q1有限变形与随动压力实现，能否在一个图像来源的斑马鱼组织外轮廓上形成闭合、正向、平衡且厚向离散稳定的被动响应。

它不是斑马鱼真实心室重建。图像只提供72 hpf Fish 4某一XY切片的组织外边界；内腔、层界、参考应力、材料、压力和面外运动均没有由该图像测得。

## 冻结外曲线和构造壁

F2保留的平滑物理轮廓记为`b_um(s)`，几何核中心为`c_um`，长度尺度为`L=45.10550160766466 µm`。沿平滑轮廓等弧长取72个控制点，组成36段周期Q2曲线。计算坐标通过一个刚体转动确定：

`b(s) = R [b_um(s)-c_um] / L`。

其中`R`只让相隔半周的两个外壁锚点连线成为计算x方向，不改变长度、面积、应变或应力。结果图可以用保存的逆变换叠回图像坐标。

径向比例为

`rho = [20/27, 21/27, 22/27, 1]`。

三条内曲线均定义为`rho*b(s)`。20/27是构造腔面，21/27和22/27是未来心内膜/ECM/心肌接口；它们不是图像分割，也不是恒法向厚度。参考三维映射为

`X(rho,s,z) = [rho*b_x(s), rho*b_y(s), z]`，`0<=z<=0.5`。

对每段Q2曲线，平面方向量为`b(s)×b'(s)`。它是二次多项式，可通过端点和区间内极值作全段检查，而不只查看Gauss点。冻结36段的最小归一化方向量为0.01267290743，因此正径向比例和正挤出高度下参考映射全段正向。正式验证仍会从保存输入独立复算。

## 周期离散和厚向检查

周向首尾使用同一组节点编号，不建立两套坐标相同但拓扑断开的切缝。位移为周期Q2，混合压力为周期连续Q1。

- `radial_coarse`：三段构造层分别1/1/2个厚向单元，共144个六面体；
- `radial_fine`：分别2/2/4个厚向单元，共288个六面体。

两级使用完全相同的36段Q2外曲线和同心缩放域，只细化厚度方向。因此两级差只能解释为本场景的厚向离散敏感性；周向分辨率和局部峰值应力收敛没有在本阶段检验。

## 有限变形、混合压力和腔压

被动材料与F4相同：单一Neo-Hookean `mu=1`、`kappa=1000`。全部构造层标签使用相同材料，不把旧小应变E比例静默改成NH参数。

混合势采用

`W_iso(F) + p_m (J-1) - p_m^2/(2 kappa)`，

其中`p_m`是体积约束的未知混合压力，不是给定腔压。内壁外载为当前表面积上的随动压力

`t = -p_cav n_solid`，

`p_cav/mu=[0,0.02,0.04,0.06,0.08]`。法向和面积随当前曲面更新；外壁无牵引，没有端盖压力、主动张力或弹簧。保存的energy是内部材料能量密度，不包含开放表面随动压力功，不能用它宣称总势单调下降。

## 边界条件

所有位移节点固定`u_z=0`，模型因此是三维实体单元实现的平面应变挤出，不是自由三维心室。完整非对称轮廓没有人为对称切面。

平面内只去除三个刚体模态：外壁中面锚点A固定`u_x=u_y=0`；相隔半周、参考连线已旋转至x方向的锚点B只固定`u_y=0`，其`u_x`自由。若闭合压力、装配和参考系选择一致，这三个规范DOF不应承担有限物理载荷；所以独立验证要求其反力近零。

## 主读出和证据边界

任意中心下的“径向位移”不适合作为非圆轮廓的首要指标。F5采用实际Q2闭曲线积分得到的构造腔面积变化`Delta A/A0`，并报告外轮廓面积、局部`J`、Green应变、总三维Cauchy应力、独立残差以及闭合压力的合力/力矩。

压力虚功用z向Gauss积分的腔体积变化核对；中面面积只有在各z层面内位移一致且中面/高度平均面积通过门后才用于主图。五个载荷级是准静态延拓状态，不是心动周期。

即使全部门通过，也只能说明：冻结外轮廓、构造腔面和上述假设下的被动数值模型可用。真实内腔、层厚、残余应力、材料、血压、自由三维运动、主动收缩、泵血、生长和ECM反馈仍未验证。
