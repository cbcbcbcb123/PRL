# 曲线壁段FEM与随动压力

本页说明F4的数学模型和适用边界；执行裁决以[合同](../project_control/ventricle_fem_curved_pressure_contract_v01.md)及对应结果为准，不以代码存在替代数值验证。

## 为什么需要新的几何映射

旧块梁采用直方块常Jacobian，不能只把节点改成心室轮廓就继续使用。新分支由Q2节点定义参考曲线几何X(ξ)，每个单元每个Gauss点计算DX/Dξ，并以其逆映射形函数梯度，以正det(DX/Dξ)积分。位移也使用Q2，混合压力仍是连续Q1；材料和有限变形运动学不变。

实际曲面是分段Q2插值，并非数学上的精确圆弧。参考Jacobian非正会被拒绝，不通过取绝对值隐藏翻转。旧直方块分支和F3-C初值提升的适用范围保留。

## 场景及边界

本阶段为四分之一圆柱壁段：内半径1、外半径1.25、高度0.5；比较径向/周向/轴向为(2,4,1)及(3,8,1)的两档网格。

- theta=0固定uy，theta=pi/2固定ux，所有节点固定uz=0，其他位移自由。
- 内壁承受逐步增大的正腔压，外壁零牵引，没有主动收缩、端盖压力或支撑弹簧。
- NH等容mu=1、体积模量kappa=1000。压力0→0.08是无量纲准静态加载，不是血压或心动周期。

因此这是**3D实体单元的平面应变资格**，不是自由三维心室，更没有实测材料或心率。

## 压力究竟如何作用

腔压不同于混合未知量p。腔压在边界提供外牵引：t=−p_cav n，其中n为固体的当前外法向；内壁的固体外法向朝向腔内，因此正腔压把壁向外推。

在Q2表面的自然坐标s、t上，以当前坐标x=X+u计算有向面积向量dx/ds×dx/dt，并据面方向修正符号。节点力是形函数乘压力和有向面积的积分；法向和面积都会随变形变化。Newton切线同时包含该外力对位移的解析导数，不能把初始压力向量一直当作固定载荷。

开放压力面一般不能直接赋予全空间标量势。本接口因此明确标记`energy_is_total_potential=False`：保存能量只表示内部材料/混合项与可能的固定外力功，不是包含压力功的总势。求解用残差下降，而不假装通过了压力能量下降门。

## 可比较的解析参照

独立参照是不可压、无限长、轴向伸长为1的Neo-Hookean厚壁圆柱。若参考内外半径为A、B，变形后为a、b，则由不可压得到r²=R²+c、c=a²−A²、b²=B²+c。

主伸长为λr=R/r、λtheta=r/R、λz=1。用径向平衡和外壁零径向牵引消去不可压压力乘子，可得：

`p_cav/mu = ln(B*a/(A*b)) + c/2*(1/a²−1/b²)`。

独立验证器不调用生产材料/压力实现，而由径向平衡积分并标量求根获得a−A；再与FE内壁参考面积加权径向位移比较。有限kappa=1000的FE与这个kappa→∞参照并非完全相同问题，因此预设5%近似对照门，并另检查两网格差和弱压力残差。不把解析参照叫作真实心脏实验。

## 离真实心室还差什么

该壁段只能验证曲线映射、压力方向/面积/切线和有限变形平衡。真实外轮廓、真实内腔、壁厚、逐层材料、纤维方向、激活、生理负载、轴向自由变形与实验时间仍需分别处理。下一步把这套已检查的接口接回已有真实外轮廓时，必须明确哪些内腔/厚度/层界是构造假设；不能把本次圆柱检查直接称为心室拟合。
