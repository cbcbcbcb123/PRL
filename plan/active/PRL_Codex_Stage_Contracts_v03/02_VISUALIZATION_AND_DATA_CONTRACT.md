# 可视化与原始数据交付合同

## 1. 用户应该怎样检查每个阶段

每阶段必须有 `index.html`，页面固定顺序为：**这一步问什么 → 模型与假设 → 当前难点 → 实际结果 → 验收证据 → 下一步但不执行**。首屏显示阶段 ID、run_id、状态、物理/可视化/主张状态和代码版本。缺资料、失败、未运行应在首屏可见，不藏在日志末尾。

页面不是一个只有按钮的空壳。最小交付包含一个已加载的代表状态、至少一张来自真实数据的定量图、字段定义和原始证据入口。用预计算快照播放，不从浏览器启动求解器。合成、实验、重建、校准、保留和参考解必须有不同文字标签；不要仅靠颜色区分。

## 2. 离线双击可用，不依赖互联网

`file://` 双击打开是最小浏览要求。浏览器读取本地文件有安全限制，不能把 `fetch('./data.json')` 在开发服务器上可用就当离线通过。采取以下实际可行的一种：将小型展示数据嵌入 HTML；用本地经典脚本携带静态数据；或让用户通过文件选择器加载数据包。JS、字体替代方案与渲染资源本地化，不依赖 CDN。

完整大数据可单独保存，首页只加载降采样的**显示副本**。原始网格和原始曲线不能因浏览性能被覆盖。可提供本地 HTTP 浏览作为附加选项，但不能把它当成“双击 HTML”的唯一实现。

Z0 必须建立可复用最小查看器；后续扩展字段而不是每阶段重写前端。优先复用 PRL 已有查看器。库名和具体 API 由 Codex 检查项目实际版本后确定；本合同不声称某个 API 已存在。

## 3. 三维模型视图

### 必需交互

支持旋转、缩放、平移、重置视角、正交/透视说明、坐标轴和比例尺。支持原始三角边显示、透明度、按层开关、剖切/裁剪平面，以及点击细胞/连接/面片显示 ID 和数值。显示几何使用实际坐标；变形放大须默认关闭并醒目标注倍数。

细胞显示 `cell_id`、`cell_type`、`mesh_version`、参考态来源、实际/目标体积；主动阶段加材料方向。流体阶段显示有效流体域、固定端口平面及边界类型；心肌内部数值背景不能画成血液。ECM 为连接网络或经过定义的牵引，不可涂成虚构完整体应力。

有截面时同时说明截取的是求解几何、展示平滑几何还是体图像切片。对称对照保持同视角、同色标和同阈值。单位与数值精度适合实际量级。

### 只有 CFD 时

无需为了统一页面而伪造细胞。显示 Cartesian/切割网格、壁面、端口、速度与压力探针。选择对象改为单元或壁面片 ID；细胞栏显示“不适用：本阶段无 DCM”。

### 没有动力学时

Z0 和 Z6a 的几何扫描可以播放几何位置，但必须标为“几何扫描/规定轨迹”，不是求解出来的生理运动。若只做静态几何，时间控件禁用；可有网格质量分布和数据缺项图，不能出现虚构压力或泵血曲线。

## 4. 时间同步和事件显示

快照须有真实 `physical_time`、`step_id`、`mesh_version`、`event_id`（无事件为 null）、`validity`。动画帧与曲线游标通过同一时间索引对应，不通过“第几张图片”猜。压力或速度处于半步/整步时必须明确对齐方法；不能默认为同一物理时刻。

显示抽帧不影响原始积分频率。插值仅用于显示且标注，不能改变验收数据。分裂/重网格事件前后要有 `t_event^-` 和 `t_event^+` 两个状态；不能在不同拓扑间直接插值三角顶点。保留暂停、逐帧、播放速度、跳到最后有效状态和事件标记功能。

曲线提供当前数值、参考曲线、误差/残差与阈值线。主图可同页并列，但每张独立图有自己的坐标、图注和原始 CSV；不得把不同量纲硬叠在同一纵轴。

## 5. 字段语义与缺失值

| 字段例子 | 单位/定义 | 禁止替代 |
|---|---|---|
| 节点力 | N；每节点积分力 | Pa 应力 |
| 膜张力/面应力合力 | N/m；明确局部定义 | 未除厚度的三维应力 |
| 连接反力 | N；作用端及正负号明确 | 连续 ECM 完整体应力 |
| 面牵引 | Pa；由面反力/面积及定义得到 | 未知面积下的节点力 |
| 表面应变 | 无量纲；相对材料参考态 | 未定义的体应变 |
| 压力 | Pa；记录基准/规范 | 无说明的绝对压力 |
| WSS | Pa；切向流体牵引，需独立通过门 | 流速大小或未经验证的单元差分 |
| 流量 | m³/s；说明方向与相对/绝对通量 | 速度箭头计数 |
| 主动功 | J；使用冻结能量分解 | 代谢功或 ATP 消耗 |
| ECM 材料量 | kg 或明示的无量纲相对量 | 未定义厚度或浓度 |

`disabled`、`not_computed`、`invalid`、`not_applicable` 分开；缺值用 null/NaN 加掩码，不填 0。色标不得把缺值映射为低值正常区域。瞬时流线、时间积分的示踪轨迹和实际红细胞轨迹分开命名。

应变、牵引、WSS 的空间平均支持区域要存到数据中；多个网格间必须使用同一物理区域，不以“三个三角形”作为固定尺度。

## 6. 最小原始数据结构（语义合同，不限定存储库）

建议每次运行如下；适配现有结构时保存对应关系：

```text
<stage>/<run_id>/
  preregistration.json
  run_manifest.json
  commands.md
  report.md
  summary.json
  metrics.csv
  snapshots/           # 几何和场，可用项目原有二进制格式
  checkpoints/         # 含所有历史的独立重启文件
  tables/              # 每步账本、相位、探针及映射
  figures/             # PNG/SVG 与来源 CSV
  viewer/index.html
  viewer/assets/       # 本地脚本和展示副本
  verification/        # 独立复核程序和实际日志
  failures/            # 失败状态、异常堆栈、最小重现
```

几何数据至少能追踪：节点坐标、面连接、细胞/层/材料 ID、壁面标记、端口标记、参考态和版本。流体数据保留速度分量实际交错位置、压力位置、活动单元体积/开口面积与单位；不得导出成“所有量都在中心”的伪原始数据。

记录快照、时间序列、展示抽样各自频率及过滤规则。保存字段字典 `field_dictionary.json`；每项有 `association`（node/face/cell/link/fluid_face/fluid_cell/global）、unit、definition、validity、reference_configuration、time_location。

## 7. 独立可视化验收

至少完成：

1. 断网并以 `file://` 打开，检查首屏、模型、曲线、图例和证据链接；禁止网络外链作为必要运行依赖。
2. 从原始快照随机选 3 个真实有效对象核对坐标/字段/单位；少于 3 个则全部检查。更换时间时 ID 与曲线游标同步。
3. 开关原始边、透明与剖切；确认没有因展示裁剪修改用于体积/通量积分的几何。
4. 对照图保持相同视角/色标；激活关闭等零值场可有全零数据，但“未计算”不可如此表示。
5. 失败运行页面能定位最后有效时刻、首个异常对象和残差；异常状态不得被自动平滑抹掉。
6. 导出至少一张完整页面截图和阶段规定的静态图；检查文字未截断、色标可读、轴标签有单位。动态阶段提供一段从真实快照生成的 GIF/视频预览，或经过实际测试的离线交互播放。

自动浏览器可用时做 smoke test 并保存截图和控制台日志；不可用时执行静态资源/数据一致性检查，并把需要人工查看的部分明确列出，不能谎称已经肉眼看过。只完成静态资源检查不等于交互验收通过。

## 8. 驾驶舱集成

把阶段页面接入原 PRL 驾驶舱，保留原路径与用户修改。若驾驶舱无法定位，生成阶段独立入口和 `integration_pending.md`，不捏造集成成功。首页按阶段显示“可运行合同”和“真实结果”两种不同链接；NOT_RUN 阶段只能进入合同/几何说明，不展示看似成功的模拟卡片。
