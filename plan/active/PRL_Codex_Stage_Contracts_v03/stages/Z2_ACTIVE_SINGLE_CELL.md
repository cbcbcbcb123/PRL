## 1. 核心问题与范围

改变材料方向上主动参考长度，能否产生方向正确、体积受控、能量来源清楚的收缩？只有单细胞和外部测试负载，无 CFD、ECM 周转或电生理。这里是规定激活的机械模型，不是完整肌丝/ATP 模型。

## 2. 主动定义

采用长轴比约 2:1 的合成细胞或已验证兼容构型，主方向来自材料参考态，锚点/材料坐标不依赖任意三角边。主动连接总权重随网格保持，不在各网格“挑几根顺向边”随意加弹簧。

默认 `a(t)=[1-cos(2πt/T)]/2`，`ell0(a)=ell_ref(1-epsilon_a a)`，k 固定：

\[
E_{fib}=\tfrac12 k(\ell-\ell_0)^2,\qquad P_{act}=-k(\ell-\ell_0)\dot\ell_0.
\]

ε_a 依次 0.02、0.05、0.10，是合成探针。V0、被动参考构型和材料定义不随激活变化。已有批准公式优先，但必须推导相同严格的功率分解。

激活能量导数、节点力和功来自同一能量；不能同时再把同一纤维节点力做功计成第二份主动输入。保留正/负主动功，去激活释放/回收储能不能裁成零。

## 3. 必需实验矩阵

| ID | 条件 | 主要证据 |
|---|---|---|
| OFF | a=0，与被动同初始和负载 | 新模块不改变 Z1 |
| FREE | 除刚体规范外自由 | 材料长轴缩短、横向补偿、实际体积 |
| ISO | 有限端区间距固定 | 端反力、外位移功近零、储能变化 |
| LOAD | 冻结外弹簧或恒力负载 | 对外功与循环账本 |
| ROTATE | 细胞和材料方向整体旋转 | 物理响应客观性 |
| REFINE | 网格/时间分别三档 | 长度、反力、主动功均收敛 |

外弹簧推荐 `E_load=k_load(d-d_ref)^2/2`，其刚度按 Z1 被动轴向刚度的冻结比例选定；弹簧储能属于系统内部还是外功二选一，不能双计。恒力负载必须明示施加位置、方向和功。固定端不等于给整个细胞表面规定运动。

## 4. 单元验证后再动态

先固定 q 只改变 a，验证能量差和主动功积分；再固定 a 改 q，验证能量梯度。再组合 FREE 的小幅单周期，之后 ISO/LOAD。幅度逐级通过，不在小幅能量未闭合时增加幅度。

保存每根代表纤维 ell、ell0、激活、反力、P_act、材料权重；总量由权重一致求和。三档网格沿用 Z1；独立 Δt 序列兼顾主动周期和被动松弛时间，不以心跳周期代替所有材料时间尺度。

记录实际 `|V-V0|/V0` 及相对被动起始体积变化。面积与体积约束不相容时写模型问题，不能靠自交或改变 V0 达到自由缩短。

## 5. 观测与能量

长度采用两个材料端区中心距离或冻结材料点距离，不用每帧包围盒。轴向应变相对固定 L_ref，横向两个材料方向分别读出。ISO 测总端反力，LOAD 测端外功。

每周期记录 ΔE_pass、ΔE_fib、主动功、外功、耗散、残差；有结构惯性计 K_s，过阻尼不捏造动能。不同幅度不得重新拟合主动刚度。反力/长度相位只在非零可解析信号下报告。

## 7. 验收、诊断与交接

OFF 复现被动；FREE 缩短方向正确但幅度由方程决定，不强迫等于参考长度幅度；ISO 储能和反力有来源；LOAD 输出由主动/初始/外部能量解释。继承 2%/5%、能量1% 和独立体积阈值。

ISO 能量不闭合先查双计主动功；网格变细反力增大先查纤维材料量；旋转改变响应先查材料方向绑定。禁止速度截断、隐含阻尼或体积驱动修补。

专属输出：`activation_definition.md`、`material_fiber_map`、`active_energy_unit_test.csv`、三负载快照/账本、幅度与收敛表。后续使用同一材料主动定义，不把本阶段参数叫作斑马鱼生理标定。
