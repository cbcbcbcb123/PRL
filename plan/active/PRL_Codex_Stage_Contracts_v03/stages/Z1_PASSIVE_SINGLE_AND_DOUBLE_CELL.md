## 1. 核心问题与边界

实际复用的 DCM 能否产生正确的被动力、平衡、接触与耗散，并在细化后稳定？无主动、无 ECM 网络、无 CFD、无分裂。通过只覆盖本次材料/接触/积分路径，不等于真实心肌已标定，更不等于组织层已液密。

## 2. 实际方程必须可查

写清 E_pass(q) 的面积/面内弹性/弯曲/体积/黏附分解与 F=-∂E/∂q。过阻尼 C(q)v=F 时，每个阻力矩阵对应什么物理对象、是否有刚体零模均登记；不能为可逆而偷偷加背景阻力。刚体规范只去除整体平移/旋转自由度，不抵抗真实形变，反力仍保存。

若体积罚为 `E_V=K_V(V-V0)^2/(2V0)`，其等效压力 `p_V=-K_V(V-V0)/V0`；内核形式不同则推导相应式。目标与实际体积不同。每档网格按同一连续材料意义设置离散刚度/阻尼/接触权重，不能增加边数同时增加材料。

## 3. 必需实验矩阵

| ID | 实验 | 验证 |
|---|---|---|
| GRAD | 非退化姿态、随机方向能量差分 | 光滑项 F=-∂E/∂q |
| RIGID | 整体平移及非坐标轴旋转 | 能量客观性、力随动、内力合矩 |
| LAPLACE | 恒张力近球细胞 | 压差—张力—实际曲率关系 |
| AXIAL | 有限端区小幅轴向加载/持载/卸载 | 反力、形变、功、体积 |
| TRANSVERSE | 横向与剪切探针 | 所声明方向响应 |
| RELAX | 卸载恢复或小幅线性模态 | 松弛机制及非负耗散 |
| CONTACT | 双细胞接近—受压—分离 | 排斥/黏附、穿透、反作用 |
| REFINE | 网格、时间、体积罚分别变化 | 误差来源分离 |

球基准只保留与 `Δp=2γ/R` 相容的恒表面张力和体积约束/压力项；额外弹性或弯曲关闭或明确计入。约束体积时压差由乘子给出，体积罚时检查外施压差与 p_V 合计。不能在额外应力存在时硬要求 p_ext=2γ/R。

恒压自由球可能存在径向稳定性问题，首选固定体积/求压反力的测试，不将不稳定平衡当作应恢复的动态算例。

## 4. 加载和细化默认值

使用合成 L0（初始等体积半径）、F0（冻结被动弹性力尺度）、T0（已定义黏性/弹性时间）。先 1% 形变，后 5%，不追求大变形。有限材料端区加载，不钉单点制造应力奇点。黏附开/关采用相同几何与路径。

建议约 80/320/1280 面三档相似网格或已有三档有效离散，记录 h 和接触解析度。时间可从 T0/50、/100、/200 三档开始，未解析则在预算内加严但不伪装 PASS。空间和时间独立变化；体积罚基准的 0.5/1/2 倍另列，不能混进网格序列。

实际体积容忍度在预登记中单列，例如首轮近不可压缩合成目标 10^-3；若既有物理模型允许更多可压缩性，按批准语义报告，不将可压缩细胞硬叫不可压缩。

## 5. 执行与独立验收

先 GRAD/RIGID，再球与受载平衡，再恢复，最后双细胞。方向差分 ε/L0 从 10^-2 到 10^-7，期待先下降后舍入地板；接触切换点不适用光滑差分。

松弛不得预设全部 DCM 单指数。若线性化可得 `C δqdot=-H δq`，用非刚体广义模态衰减作参考；否则用独立高精度积分/更细参考并标数值参考。没有黏性不能期待松弛。

每步记录各能量、外载功、物理耗散、约束反力、实际体积/面积、接触间隙/状态。独立重算体积和作用反作用合力合矩。双细胞交换 ID 后只重排，不改变物理结果；切向接触如含力偶应明确计入，不能只看净力为零。

穿透容忍度按冻结物理接触尺度和离散误差解释，必须给出具体数值；不能随 h 增大分母来隐藏未解析接触。

## 7. 验收、故障与输出

方向导数≤10^-6，刚体/内力合力合矩代数≤10^-10；整体/局部 2%/5% 并有趋势；能量≤1%；实际体积单独达冻结阈值。动态平衡检验 C v-F 或惯性方程残差，不把动态内力非零当错误。

能量上升先查外功/初始储能；无外功且无主动才要求按模型耗散。接触跳变先查几何和解析度，不先加阻尼。某接触路径不通过会阻断依赖它的组织，不允许换引擎绕开。

专属输出：`constitutive_audit.md`、`passive_parameters.json`、`contact_pair_ledger.csv`、`gradient_check.csv`、`mesh_time_penalty_study.csv`、各实验快照。Z2 接收通过被动参考态、允许主动扩展接口和体积误差。理论线索 [R4] 不提供可直接移植的心肌生理参数。
