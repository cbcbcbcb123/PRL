## 1. 额外风险与范围

这里只研究一次受控心内膜分裂导致的壁面细胞身份/三角剖分变化，首先保持事件瞬间的共同流体几何完全不变。它不同于 Z10 的心肌事件：壁片归属、界面映射、流体牵引分配和可能的切割结构直接受影响。

不是死亡开洞、细胞挤出、屏障修复，也不是允许血液漏出后补液。任何需要瞬间改变腔体占据体积的操作都超出零时长拓扑事件；应设计具有时间路径和做功来源的连续形变并另立合同。

## 2. 两种事件严格分开

**A：几何不变的身份/壁网格/内部细胞界面事件。** 母心内膜细胞被切为两女儿，流体可见外表面的并集不变。CFD 物理域在 t^- 与 t^+ 相同，血液体积和连续流体状态不应产生物理跳跃；壁面反力重新分配需保持合力/合矩/虚功。

**B：真实腔面形状在有限时间内变化。** 只能在 A 和相关移动门通过后另行批准。必须给出 XΓ(t)、墙速度、端口通量、事件驱动力和能量路径；不可从前后两帧几何差直接瞬移细胞后声称已守恒。

本文件默认只授权 A 和其后的正常 FSI 演化，B 仅记录扩展条件，不执行。

## 3. 执行步骤

先在零流/常压静止腔做 A，验证几何/流体零效应；再在 Z8 某个已接受非零流动时刻做同几何事件，检查转移；最后允许新增细胞界面的物理力改变之后的连续演化。

新壁片能追溯原母面/材料点、女儿归属、面积权重与参考态。切割集合相同时尽量保持同一 CFD 状态，不能为改 cell_id 重建全场；若数值实现重建导致状态重投影，必须有独立守恒映射和误差账本。

重新计算 g 与 J 后验证导数、虚功、合力和合矩；不要只检查新的三角面闭合。新细胞侧界面不得露入腔内造成未定义突起或缝隙。端口若受影响须仍有完整标记，不把虚封帽变成细胞膜。

事件事务与 Z10 一致：接受一次、回退全状态、重启不重复。压力规范、流体交错速度和几何版本作为整体检查点保留。

## 6. 验收与停止

共同流体域同几何不变；壁归属覆盖完整；无未解释开边；映射/合矩代数≤10^-10；几何和流体状态转移误差在冻结的独立预算内且低于真实事件信号。后续 FSI 仍满足质量10^-3、能量1%、整体/局部2%/5%。

出现有限腔体积瞬时改变，不做全局补液，也不重置速度使之稳定；本事件规则与不可压缩流体不相容，停为 BLOCKED_SPEC。真实流体响应不能由纯标签操作产生。
