# PRL 阶段执行总合同 v03

**文档日期：2026-09-10。所有实验状态均为 NOT_RUN。** 本包将 v02 拆为单阶段执行合同；没有检查本地代码、没有替用户运行模拟，也没有将资料核查升级为 Z0 PASS。

## 1. 范围与优先级

用户当前选定的路线不变：PRL 管心脏应用，唯一 `muse_dcm` 管 DCM；ECM 为非细胞性薄层黏弹网络；血液为腔内不可压缩牛顿流体；自建最小 CFD 使用交错笛卡尔网格、有限体积和投影，并在后续添加守恒切割单元。固定细胞数优先；生长、死亡、真实瓣叶、电生理、血细胞分辨流变与三维 ECM 占据不在本包默认范围。

优先级：用户最新明确指令 > 已登记的模型/阈值变更 > 本包总合同与指标定义 > 当前阶段具体合同 > Codex 实现选择。发现物理或符号冲突，输出 `change_request.md`，不要静默择一。可先完成不受冲突影响的检查；受影响的正式计算必须停止。

本包的新数值例子、载荷幅度、无量纲尺度和资源上限是**工程测试默认值**，不是斑马鱼参数，也不是已校准结果。第一次执行时将其写入预登记。已有更具体且已批准的物理参数不能被默认值覆盖。

## 2. 一次只执行一个阶段或一个子门

读取全部文档不等于获授权运行全部文档。唯一默认起点是 Z0。Z6、Z9 为总控制入口，实际计算分别由 Z6a/Z6b/Z6c 和 Z9a/Z9b 合同授权。Z4b 为单独腔面门，Z10b 为后续可选拓扑扩展，均不得顺带执行。

阶段内部可以完成所列“必需”子实验，但不得自动启动下一阶段、开放范围之外的参数扫描、或为求 PASS 不断增加运行预算。调试运行与正式运行分离并分别编号。父阶段汇总只有在全部必需子门通过后才能 PASS。

Z9 的数据不足不构成所有合成 Z10/Z11 的逻辑阻断。后两者满足真正数值前置门后仍需另行授权；不借此自动越过编号。

## 3. 本地仓库与唯一内核

首先只读检查用户打开的目录、项目说明、git 状态、现有脚本/测试/驾驶舱与依赖路径。`E:/Temp-Projects/PRL` 仅来自用户历史文字，是候选路径，不是假定已存在的 API 或当前工作目录。Windows/WSL 路径转换须实际验证。

定位并记录：PRL 根目录、`muse_dcm` 唯一实现位置及版本、配置加载器、运行入口、快照格式、已有 PASS 的适用范围、关键 FAIL 的实际依赖。门户汇总不能替代运行包。M1 的 PASS 仍仅限原二维小应变全 FEM 范围。

允许在唯一内核原位置做有测试的兼容修复，或按项目已有扩展点添加功能；不把代码复制到心脏目录形成第二引擎。不得 `git reset --hard`、删除失败包、覆盖用户修改或重新标记旧结果。改动共享力学路径后要重跑受影响回归；无关失败可登记而不一概阻断。

本包中的建议目录、JSON 字段与概念接口并非声称仓库已有这些对象。优先适配现有实现；真实调用命令必须执行验证后写入 `commands.md`。不得报告虚构 CLI 执行成功。

## 4. 每个阶段都采用同一执行闭环

### 4.1 审计和预登记

列出本阶段可用能力、待新增能力、外部数据及阻断项。将以下项目在正式运行前冻结：

- 物理模型与关闭项；参考构型、边界条件、参数单位/来源及主动/耗散语义。
- 必需/可选实验、网格与时间细化序列、参考解、观测区域、误差范数与非零尺度。
- 求解器方法与形式阶次、迭代容差、回退规则、极小单元/接触/事件处理。
- 所有通过阈值、预算、随机种子、输出频率和版本散列。

没有既定绝对材料参数时，模块测试可采用有明确尺度变换的无量纲合成参数。不得把拟合 Z8 目标 PV 曲线当成 Z1 材料标定，也不得为不同几何分别调物理参数。实际需要新增未定义物理机制时交付 `BLOCKED_SPEC` 和最小变更请求。

### 4.2 小规模预检

以最小几何和最短有效历程确认：程序能运行、单位一致、符号方向正确、无 NaN/负体积/异常拓扑、导出可读取、CPU/内存/存储量受控。预检图可展示真实几何和实际发生的短历程，但必须带 `PILOT` 标签，不当作正式收敛证据。

### 4.3 正式执行与独立验收

按冻结矩阵运行，不用全参数笛卡尔积代替有目的的实验设计。分别验证空间、时间、迭代、材料罚参数、物理区域大小与细胞数量；不得混为同一“分辨率”。独立验证器优先从快照重算体积、通量积分、能量差、作用反作用和观测量，另与求解器账本对照。

任何真实失败先缩到可复现最小包，再做不改变物理语义的修复。修复后建立新 run_id；不修改旧日志。若标准本身有错误，记录有版本修订、影响范围及重跑计划；不能看结果调阈值。

### 4.4 交付和停止

交付阶段报告、离线页面、原始证据、独立验证命令及失败信息。报告下一阶段合同的就绪条件，但不启动下一阶段。没有模型计算也可以交付静态检查图；不得生成伪装为结果的期望曲线。

## 5. 资源边界：上限，不是工期承诺

以下为本包默认保护值；机器或项目已有更小上限时从严执行。改变上限只在正式计算前登记；超过冻结上限需新授权，不得无界重试。

| 项目 | 默认保护值 |
|---|---|
| 计算设备 | CPU；不自动切 GPU、云计算或付费服务 |
| 线程 | 最多 4，并不超过可用物理核心数；无法查询则 1 |
| 内存 | 最多 8 GiB 且不超过启动时可用内存的 35%；未知则先用 2 GiB |
| 预检 | 单例最多 120 s，累计最多 600 s；允许更短 |
| 正式阶段/执行子门 | wall time 最多 4 h、CPU core-hours 最多 16 h，先到者停止 |
| 输出 | 默认每阶段最多 4 GiB；先控制展示抽样，不删除验收需要的原始账本 |
| Z0 下载 | 总计最多 256 MiB，先取清单与小文件；不自动申请、下载 37 GB 原始数据 |
| 周期运行 | 首轮最多 20 周期；未达周期态不自动归类数值失稳 |
| 重试 | 单步拒绝/回退默认最多 6 次；单问题自动修复重跑最多 3 轮，之后提交诊断 |

为实际代码设置 timeout、内存监视、停止标记和检查点；不得仅在 README 写上限而不执行。预算耗尽保留 `STOPPED_BUDGET`，不缩短必须的验收项后给 PASS。数据数组优先查看元数据、dtype、形状与小切片，避免整包解压或危险反序列化。

## 6. 物理不变项

细胞目标体积不随激活变化；实际体积罚误差单独报告。闭合细胞、组织连接和血液共同腔面是三项不同检查。共同腔面是细胞自由度的映射，不能成为独立施加运动的隐藏膜。虚拟端口封帽仅用于体积计算，不是实体壁。

每个阻尼项有明确物理对应物、参考速度和功率；不能用隐含背景阻力隐藏耦合不稳定。主动功、端口功、外力功、弹性能、流体/结构动能、物理耗散和事件/材料变化项各记一次。参见指标合同。

第一版只用固定端口平面及压力—流量负载，不同时独立指定同一端口的压力和流量。封闭不可压缩腔不允许被规定整体缩小。没有主动驱动但存在外部压差或初始储能时可以有流动。

## 7. 接口和可回退状态

仅维持三个概念接口：结构状态→几何/力/能量；流体与界面状态→流场/通量/反力；快照→数据/可视化。内部类和函数名由实际项目决定。

结构状态至少包含几何与材料参考态、身份/谱系、主动材料方向、目标量与实际量、黏弹内变量、接触/连接历史、激活时间。流体状态包括交错速度、压力及压力基准、切割几何/版本、负载/阀状态与累计收支。

每次同一时间步内迭代必须从同一个已接受的 t_n 状态重算候选 t_(n+1)。不得重复累积激活、ECM 松弛、阀状态、材料源项和主动功。只有收敛接受后提交一次。拒绝时间步需原子回退全部状态与事件队列。

展示快照不必能重启。真正检查点必须含所有内部历史、随机数发生器状态、版本与单位，能够通过连续运行/中断重启对照。

## 8. 状态与主张分开

`PASS` 必须注明适用对象、参数与范围。`physics_status`、`visualization_status`、`claims_status` 单独登记。缺资料可 `BLOCKED_DATA`，缺必要代码能力可 `BLOCKED_DEPENDENCY`，缺物理定义可 `BLOCKED_SPEC`，分辨率不足为 `UNRESOLVED`。

页面完成不是物理通过；物理通过但离线页面缺失，不是阶段交付完成。无生物数据的合成 PASS 不能支持实验验证。强对照消除差异就停止独占性主张，不靠追加生物过程扩大叙事。

## 9. 变更权限

Codex 可调整文件组织、绘图布局、缓存和不改变数值语义的局部重构；可修复实现错误并重跑受影响测试。不得自行改变模型范围、材料定义、冻结阈值、守恒项、强对照、事件规则或数据层级。

所有影响语义的变更写清：原定义、修改原因、新方程/条款、可能改变的结论、受影响测试和所需重新授权。开发中发现算术或程序 bug 不需要把错误永久冻结，但必须留存旧证据与新版本。
