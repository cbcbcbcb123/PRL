MODEL PRIMER

模型与关键假设

模型类型二维线性过阻尼多层力学模型：主动心肌有限元 + 标准线性固体 ECM 有限元 + 离散弹性心内膜链模拟对象

固定发育时期内，周期性心肌主动缩短通过有限厚度黏弹 ECM 向心内膜离散单元传递位移、应变、牵引、相位和耗散。

核心理论

心肌以给定主动本征应变驱动；ECM 用平衡弹性支路与 Maxwell 支路表示时间依赖；心内膜链以轴向、横向和弯曲弹性响应。三层通过界面连接，在过阻尼动力学中演化并形成整体与局部力学读出。
